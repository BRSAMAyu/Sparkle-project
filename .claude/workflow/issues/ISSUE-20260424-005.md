## [Audit] 证据

`blacklist_token` 函数签名声明返回 `-> None`（security.py:242），但实际在多处返回 `True` 或 `False`：

```python
# security.py:242
async def blacklist_token(jti: str, exp: int | float | datetime | None) -> None:
    ...
    if ttl <= 0:
        return True  # line 259 — 返回 bool，不是 None
    ...
    for attempt in range(max_retries):
        try:
            await cache_service.set(key, "revoked", ttl=ttl)
            return True  # line 268
        except Exception as e:
            if attempt == max_retries - 1:
                ...
                return False  # line 279
    return True  # line 284
```

所有调用方（auth.py:587, 622, 641）都不使用返回值，因此**当前无功能性影响**。但类型注解与实际行为不一致，违反项目 MyPy 配置（`pyproject.toml` 启用了 `warn_return_any`），且对未来的调用者具有误导性。

**期望**：返回类型注解与实际返回值一致。
**实际**：`-> None` 但返回 `True`/`False`。

## [Audit] 建议修复方向

二选一：(A) 将签名改为 `-> bool` 并统一所有分支返回 `True`/`False`；(B) 去掉所有 `return True/False` 改为 `return`（即真正返回 None），调用方原本就不使用返回值。推荐 (A)，因为返回值可用于未来错误处理。
