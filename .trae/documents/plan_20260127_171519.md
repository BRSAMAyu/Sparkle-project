# 修复驾驶舱头像点击事件和我的页面布局溢出问题

## 问题分析

### 1. 驾驶舱左上角头像点击事件
- 当前在 `home_screen.dart` 中，左上角头像没有点击事件处理
- 需要添加点击事件，使其导航到个人资料页面

### 2. 我的页面布局溢出问题
- `profile_screen.dart` 中存在多个固定高度的组件，可能导致布局溢出
- 特别是 RPG角色状态卡片使用了固定高度 250，这可能是导致底部溢出的主要原因
- 按钮也使用了固定高度 50，可能在小屏幕上导致问题

## 修复计划

### 1. 为驾驶舱左上角头像添加点击事件
- 在 `home_screen.dart` 的 `_buildTopOverlay` 方法中，为头像容器添加 `GestureDetector`
- 实现点击事件处理，导航到个人资料页面

### 2. 修复我的页面的布局溢出问题
- **移除固定高度限制**：
  - 移除按钮的固定高度 50，使用 `Expanded` 或自适应高度
  - 移除 RPG角色状态卡片的固定高度 250，使用 `IntrinsicHeight` 或 `LayoutBuilder`

- **优化滚动行为**：
  - 确保 `SingleChildScrollView` 能够正常工作
  - 移除可能限制滚动的固定高度容器

- **响应式布局优化**：
  - 使用 `Flexible` 或 `Expanded` 确保组件能够适应不同屏幕尺寸
  - 为小屏幕设备添加适当的间距和约束

## 实现步骤

1. **修改 `home_screen.dart`**：
   - 为左上角头像添加 `GestureDetector`
   - 实现点击事件，导航到个人资料页面

2. **修改 `profile_screen.dart`**：
   - 移除按钮的固定高度限制
   - 移除 RPG角色状态卡片的固定高度限制
   - 优化布局结构，确保内容能够正常滚动
   - 测试不同屏幕尺寸下的布局效果

3. **验证修复**：
   - 确保驾驶舱头像点击能够正常导航到个人资料页面
   - 确保个人资料页面在所有屏幕尺寸下都没有布局溢出问题
   - 确保所有按钮和内容都能正常显示
