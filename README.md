# Sparkle（星火） - AI 学习助手

> 🎯 **大学生专属的 AI 智能学习伙伴** — 基于认知画像的自适应学习系统

## 📖 项目简介

Sparkle 是一款面向大学生的智能学习助手，以 **Luminous Cognition 认知引擎** 为核心，通过深度理解用户的认知模式、知识状态和学习行为，提供真正个性化的学习体验。

**核心理念**：不只是"回答问题"，而是"理解学习者"

**目标**：2026年2月2日前完成 MVP 版本，参加大学软件创新大赛

### 1. 四维用户画像系统 (Cognitive Nexus)

我们不仅跟踪"用户知道什么"，更深入理解"用户如何思考"：

| 维度 | 测量指标 | 应用场景 |
|------|----------|----------|
| **知识维度** | 知识点掌握度、记忆半衰期、学习速度 | 个性化复习推荐、知识薄弱点预警 |
| **认知维度** | 元认知能力、行为模式（猜测/固执）、认知负荷 | 调整讲解深度、识别学习陷阱 |
| **动机维度** | 自我效能感、学习风格偏好、兴趣图谱 | 激励策略设计、内容推荐优化 |
| **协作维度** | 社群贡献度、求助特征、沟通风格 | 学习伙伴匹配、小组任务分配 |

**实时画像更新**：每次交互都会触发认知模型更新，确保 AI 响应始终基于最新用户状态。

### 2. LangGraph 状态机编排

基于 LangGraph 的智能工作流引擎，实现复杂推理过程的可观测、可干预：

- **FSM 状态流转**：INIT → THINKING → GENERATING → TOOL_CALLING → DONE
- **状态快照机制**：支持状态回溯和断点续传
- **计划版本管理**：防止并发修改冲突，支持计划评审流程
- **PONR 机制**：高风险操作（如删除计划）触发用户确认

### 3. 多智能体协作系统

10+ 专业化智能体，动态协作解决复杂学习任务：

| 智能体 | 职责 | 典型场景 |
|--------|------|----------|
| **Orchestrator** | 总控协调，任务分发 | 复杂问题拆解 |
| **Knowledge** | 知识检索、RAG 问答 | 知识点查询 |
| **Math** | 数学计算、问题求解 | 习题辅导 |
| **Code** | 代码生成、调试 | 编程学习 |
| **Reasoning** | 逻辑推理、深度分析 | 概念理解 |
| **Writing** | 内容生成、改写 | 作文辅导 |

智能体间支持 **Handoff 机制**，自动将请求转交给更合适的专家。

### 4. GraphRAG 双路检索

融合向量搜索和图遍历的混合检索系统：

```
Query ──▶ Vector Search (语义相似)  ──┐
                                       ├▶ Result Fusion ─▶ Ranked Results
Query ──▶ Graph Traversal (关系推理) ─┘
```

**性能指标**：
- 向量检索：< 200ms
- 图遍历：< 500ms
- 综合检索：< 800ms
- 并发能力：15 req/s

### 5. 动态工具注册系统

工具系统支持自动发现和运行时注册，涵盖学习全流程：

| 工具类别 | 核心工具 | UI 呈现 |
|----------|----------|---------|
| **TASK** | 任务创建、状态更新、番茄钟 | 任务卡片、计时器 |
| **PLAN** | 计划生成、版本管理、评审 | 计划时间线、评审卡片 |
| **KNOWLEDGE** | 向量搜索、图遍历、知识点拓展 | 知识星图、关联推荐 |
| **QUERY** | 历史查询、统计分析 | 学习报告、进度面板 |
| **FOCUS** | 专注会话、打断处理 | 专注模式界面 |

**Widget 绑定**：每个工具返回结果可绑定特定 UI 组件，实现无缝的前后端联动。

## 🔄 业务闭环逻辑

Sparkle 实现了完整的学习闭环，每个环节都由 AI 深度赋能：

```
                    ┌─────────────────────────────────────┐
                    │         AI 微导师对话入口             │
                    │     (理解意图 + 画像匹配)             │

            ┌─────────────────────────┼─────────────────────────┐
            │                         │                         │
            ▼                         ▼                         ▼
    ┌───────────────┐         ┌───────────────┐         ┌───────────────┐
    │  智能任务推荐  │         │  知识图谱构建  │         │  计划智能生成  │
    │  (基于画像)    │         │  (RAG 检索)    │         │  (任务分解)    │

    │  (番茄钟)      │         │  (遗忘曲线)    │         │  (进度预警)    │
    └───────┬───────┘         └───────┬───────┘         └───────┬───────┘

                    ┌─────────────────────────────────────┐

```

### 闭环详解

#### 1. 对话 → 理解
- AI 解析用户意图，匹配当前学习场景
- 根据用户画像调整对话风格和讲解深度
- 识别隐性需求（如"我学不会"触发认知诊断）

#### 2. 理解 → 行动
- **任务推荐**：基于知识薄弱点生成个性化任务
- **知识拓展**：通过 GraphRAG 关联相关知识点
- **计划生成**：AI 辅助拆解学习目标为可执行步骤

#### 3. 行动 → 执行
- **专注模式**：番茄钟计时，AI 提供专注激励
- **智能提醒**：根据遗忘曲线推送复习提醒
- **进度追踪**：实时同步学习状态

#### 4. 执行 → 反馈
- **错题归档**：自动分类错题，分析错误原因
- **掌握度更新**：动态调整知识点掌握分数
- **数据沉淀**：记录学习时长、完成率等指标

#### 5. 反馈 → 优化
- **画像迭代**：四维模型实时更新
- **策略调整**：优化后续推荐和讲解策略
- **形成闭环**：下一轮对话更加精准

## 🛠️ 技术架构

### 三层架构

```
┌─────────────────────────────────────────────────────────────────┐
│  FLUTTER (Presentation)  →  UI 渲染、用户交互、本地状态         │
├─────────────────────────────────────────────────────────────────┤
│  GO GATEWAY (Coordination) →  鉴权、路由、缓存、WebSocket      │
├─────────────────────────────────────────────────────────────────┤
│  PYTHON ENGINE (Intelligence) →  AI 编排、RAG、工具调用、LLM   │
└─────────────────────────────────────────────────────────────────┘
         ↕ PostgreSQL + pgvector    ↕ Redis    ↕ gRPC/WebSocket
```

### 技术栈

| 层级 | 技术选型 |
|------|----------|
| **前端** | Flutter 3.x, Dart, Riverpod |
| **API 网关** | Go, Gin, gRPC, WebSocket |
| **AI 引擎** | Python, LangGraph, FastAPI |
| **LLM** | 通义千问 / DeepSeek / GPT-3.5 |
| **数据库** | PostgreSQL 16 + pgvector |
| **向量检索** | Redis (缓存) + pgvector |
| **图数据库** | Apache AGE |
| **任务队列** | Celery + Redis |
| **协议** | Protobuf + gRPC |

## 🚀 快速开始

### 环境准备

```bash
# 1. 克隆项目
git clone <repo-url>
cd sparkle-flutter

# 2. 复制环境变量
cp .env.example .env
# 编辑 .env 配置数据库和 API 密钥
```

### 启动开发环境

```bash
# 终端1: 启动基础设施 (DB + Redis + MinIO)
make dev-up

# 终端2: 启动 Python gRPC 服务 (AI 引擎)
make grpc-server

# 终端3: 启动 Go Gateway (API 网关)
make gateway-dev

# 终端4: 启动 Flutter 应用
make mobile-run
```

### 常用命令

```bash
# === Proto 生成 ===
make proto-gen            # 生成 Go/Python/Dart protobuf
make mobile-gen           # 生成 Flutter protobuf + build_runner

# === 数据库 ===
make sync-db              # 同步数据库 (migrate + dump + sqlc)
alembic revision -m "desc" # 创建新迁移
alembic upgrade head      # 应用迁移

# === Celery 任务队列 ===
make celery-up            # 启动 Celery (worker + beat)
make celery-status        # 查看服务状态

# === 测试 ===
cd backend && pytest      # Python 测试
cd backend/gateway && go test ./...  # Go 测试
cd mobile && flutter test # Flutter 测试

# === 自检 ===
make smoke                # 健康检查
make env-check            # 配置检查
```
