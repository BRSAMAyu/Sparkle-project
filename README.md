## 🏆 Why Sparkle?

| Dimension | Traditional AI | Learning Apps | **Sparkle** |
|:----------|:---------------|:--------------|:------------|
| **User Understanding** | ❌ No memory, starts from scratch | ⚠️ Static tags, basic categories | ✅ **4D Cognitive Profile** — Knowledge/Cognition/Motivation/Social, evolving with every interaction |
| **Interaction Mode** | ❌ Passive Q&A, answers only | ⚠️ Preset paths, one-size-fits-all | ✅ **Goal-Driven** — From "what to ask" to "who to become" |
| **Knowledge System** | ❌ Fragmented info, no connections | ⚠️ Linear notes, manual organization | ✅ **Knowledge Galaxy** — GraphRAG auto-builds your knowledge network |
| **Feedback Loop** | ❌ Single conversation, no follow-up | ⚠️ Static stats, no insights | ✅ **7-Stage Growth Loop** — Sense→Clarify→Plan→Execute→Reflect→Reinforce→Adapt |
| **Forgetting Curve** | ❌ Not addressed | ⚠️ Simple reminders, no strategy | ✅ **Smart Review Engine** — Memory half-life based push, intercept before forgetting |
| **Error Analysis** | ❌ Just gives answers | ⚠️ Error collection, no diagnosis | ✅ **Error Pattern Clustering** — Diagnoses thinking gaps, not just records mistakes |
| **Learning Companion** | ❌ Tool-only, no warmth | ⚠️ Cold check-ins | ✅ **AI Micro-Tutor** — High-EQ coach, empathizes and motivates |
| **Community** | ❌ No community | ⚠️ Random matching | ✅ **Cognitive Profile Matching** — Find truly compatible study partners |

## 🧠 Core Innovation

### Dual-Core Growth OS

Two specialized cores work in concert to deliver personalized growth experiences:

```
┌─────────────────────────────────────────────────────────────────────┐
│                     DUAL-CORE GROWTH OPERATING SYSTEM               │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│   ┌─────────────────────────────┐  ┌─────────────────────────────┐  │
│   │      EXECUTION CORE         │  │      COGNITIVE CORE         │  │
│   │                             │  │                             │  │
│   │  Goal → Sufficiency → Plan  │  │  Profile → Memory → Prism   │  │
│   │    ↓           ↓         ↓  │  │    ↓          ↓         ↓   │  │
│   │  Tasks → Execute → Feedback │  │  Understand → Support → Evolve│
│   │    ↓           ↓         ↓  │  │    ↓          ↓         ↓   │  │
│   │      Adaptive Adjustment    │  │   Continuous Companionship  │  │
│   └─────────────────────────────┘  └─────────────────────────────┘  │
│                    ↘                           ↙                     │
│                      COLLABORATION LAYER                           │
│           (Event Bus · Context Aggregation · Real-time Sync)        │
└─────────────────────────────────────────────────────────────────────┘
```

**Execution Core**: Goal clarification → Sufficiency evaluation → Staged planning → Executable tasks → Feedback loop → Dynamic adjustment

**Cognitive Core**: User profile → Long/short-term memory → Cognitive prism → Emotion/motivation understanding → Personalized support → Continuous companionship

### 7-Stage Growth Loop

Every interaction feeds into a continuous improvement cycle:

```
                    ┌──────────┐
                    │  SENSE   │ ← Passive signal capture
                    └────┬─────┘
                         │
         ┌───────────────┼───────────────┐
         ▼               ▼               ▼
    ┌─────────┐    ┌──────────┐    ┌─────────┐
    │ CLARIFY │───→│   PLAN   │───→│ EXECUTE │
    └─────────┘    └──────────┘    └────┬────┘
         ↑                              │
         │         ┌──────────┐         │
         │         │ REFLECT  │←────────┘
         │         └────┬─────┘
         │              │
    ┌────────────┐ ┌─────────┐
    │   ADAPT    │←│REINFORCE│
    └────────────┘ └─────────┘
         │
         └──────────────→ [Next Iteration]
```

### Evidence-Based Profile

Every dimension of the 4D Cognitive Profile is backed by **behavioral evidence**, not guessing:

| Dimension | What We Track | How It Helps |
|:----------|:--------------|:-------------|
| **Knowledge** | Mastery level · Forgetting curve · Learning velocity | Precision review push · Weak spot alerts |
| **Cognition** | Metacognition · Cognitive load · Thinking patterns | Dynamic explanation depth |
| **Motivation** | Self-efficacy · Learning preferences · Interest map | Personalized incentive strategies |
| **Social** | Community contribution · Communication style | Intelligent study partner matching |

### GraphRAG Knowledge Galaxy

Hybrid retrieval architecture combining semantic search with knowledge graph traversal:

```
                     Query: "What is gradient descent?"
                                  |
              +-------------------+-------------------+
              |                                       |
              v                                       v
      +--------------+                        +--------------+
      | Vector Search|                        | Graph Traverse
      | (pgvector)   |                        | (Apache AGE) |
      +--------------+                        +--------------+
              |                                       |
      Semantic docs                            Prerequisite knowledge
      - Gradient descent def                    - Partial derivatives
      - SGD vs Adam                             - Loss functions
              |                                       |
              +-------------------+-------------------+
                                  |
                          Result Fusion
                                  |
                         Contextualized Response
```

**Performance**: Vector search < 200ms · Graph traversal < 500ms · Combined < 800ms

Adaptive dialogue that recognizes your implicit needs. When you say "this is hard," it doesn't just explain — it diagnoses your cognitive state and adjusts its approach.

Your personal knowledge network visualized as a cosmic map. Each concept is a star; mastery grows brighter; connections form constellations.

6 task types with AI recommendations based on your weak spots. Built-in Pomodoro focus mode keeps you in flow.

### 🏆 Achievement Engine
Gamification that actually motivates — streaks, milestones, contracts, and hidden achievements that surprise and delight.

### 👥 Community Learning
Intelligent matching with study partners based on cognitive profiles. Study squads and sprint groups for collective growth.

### 🔄 Closed-Loop Feedback
Every interaction feeds back into your profile. The system evolves with you, not just for you.

## 🏗️ Architecture

```
┌─────────────────────────────────────────────────────────────────────┐
│                         MOBILE CLIENT                                │
│                  Flutter · Riverpod · Design System V2               │
└──────────────────────────────┬──────────────────────────────────────┘
                               │ WebSocket / HTTP
┌──────────────────────────────┴──────────────────────────────────────┐
│                          GO GATEWAY (8080)                           │
│              Auth · Rate Limit · Connection Pool · gRPC Bridge       │
└──────────────────────────────┬──────────────────────────────────────┘
                               │ gRPC
┌──────────────────────────────┴──────────────────────────────────────┐
│                       PYTHON AI ENGINE                               │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │                    ChatOrchestrator                          │    │
│  │  Context Builder → Router → Validator → Executor → Response │    │
│  └─────────────────────────────────────────────────────────────┘    │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │                 Cognitive Nexus                              │    │
│  │  Profile · Memory · Galaxy · Achievement · Community         │    │
│  └─────────────────────────────────────────────────────────────┘    │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │                  GraphRAG Layer                              │    │
│  │           pgvector + Apache AGE + Redis Cache               │    │
│  └─────────────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────────────┘
         │                    │                    │
    PostgreSQL 16          Redis 7+             MinIO/S3
    + pgvector            (Cache/PubSub)        (Storage)
    + Apache AGE
```

### Tech Stack

| Layer | Technology | Why |
|:------|:-----------|:----|
| **Mobile** | Flutter · Riverpod · Hive | Cross-platform · Declarative state · Local cache |
| **Gateway** | Go · Gin · WebSocket | High concurrency · Low latency protocol bridge |
| **AI Engine** | Python · LangGraph · Celery | AI ecosystem · FSM observability · Async tasks |
| **Vector DB** | pgvector | Unified with business DB, simple ops |
| **Graph DB** | Apache AGE | PostgreSQL native extension |
| **Protocol** | Protobuf + gRPC | Strong typing · Streaming · Cross-language |

## 🔧 Quick Start

### Prerequisites

- Go 1.21+
- Python 3.11+
- Flutter 3.x
- Docker & Docker Compose

### Local Development

```bash
# Clone the project
git clone https://github.com/BRSAMAyu/Sparkle-project.git && cd Sparkle-project

# Configure environment
cp .env.example .env
# Edit .env, add LLM API Key and other secrets

# Start infrastructure (PostgreSQL, Redis, MinIO)
make dev-up

# Start backend (in separate terminals)
make grpc-server    # Python AI Engine
make gateway-dev    # Go Gateway

# Start mobile client
make mobile-run
```

### Common Commands

```bash
make proto-gen              # Generate Protobuf code (buf/protoc)
make sync-db                # DB migration + SQLC generation
make smoke                  # Health check on all services
make celery-up              # Start async task queue
make env-check              # Config + connectivity self-check
```
