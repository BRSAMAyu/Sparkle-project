## 🏆 为什么选择 Sparkle？

| 维度 | 传统 AI 助手 | 传统学习 App | **Sparkle** |
|:-----|:-------------|:-------------|:------------|
| **理解用户** | ❌ 无记忆，每次重新开始 | ⚠️ 静态标签，简单分类 | ✅ **四维认知画像** — 知识/认知/动机/社交，每次交互都在进化 |
| **交互模式** | ❌ 被动问答，只给答案 | ⚠️ 预设路径，千人一面 | ✅ **目标驱动** — 从"问什么"到"成为谁" |
| **知识体系** | ❌ 信息碎片，无关联 | ⚠️ 线性笔记，手动整理 | ✅ **知识星图** — GraphRAG 自动构建知识网络 |
| **反馈闭环** | ❌ 单次对话，无后续 | ⚠️ 静态统计，无洞察 | ✅ **7阶段成长循环** — 感知→澄清→规划→执行→反思→强化→适配 |
| **遗忘曲线** | ❌ 未处理 | ⚠️ 简单提醒，无策略 | ✅ **智能复习引擎** — 基于记忆半衰期推送，拦截遗忘 |
| **错题分析** | ❌ 只给答案 | ⚠️ 错题收集，无诊断 | ✅ **错题模式聚类** — 诊断思维漏洞，而非仅记录错误 |
| **学习陪伴** | ❌ 纯工具，无温度 | ⚠️ 冰冷打卡 | ✅ **AI 微导师** — 高情商教练，共情并激励 |
| **社群学习** | ❌ 无社群 | ⚠️ 随机匹配 | ✅ **认知画像匹配** — 找到真正合拍的学习伙伴 |

## 🎯 愿景

> **帮助用户成为更好的自己，实现目标，减少内耗，获得成就感和幸福感。**

Sparkle 不是又一个 AI 聊天机器人或学习 App。它是一个**成长操作系统**，深度理解你——你的思维模式、知识盲区、动机驱动——并陪你走向目标。

## 🧠 核心创新

### 双核心成长操作系统

两个专业核心协同工作，提供个性化成长体验：

```
┌─────────────────────────────────────────────────────────────────────┐
│                       双核心成长操作系统                              │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│   ┌─────────────────────────────┐  ┌─────────────────────────────┐  │
│   │        执行核心             │  │        认知核心             │  │
│   │                             │  │                             │  │
│   │  目标 → 充分性 → 计划       │  │  画像 → 记忆 → 棱镜         │  │
│   │    ↓         ↓       ↓      │  │    ↓        ↓       ↓       │  │
│   │  任务 → 执行 → 反馈         │  │  理解 → 支持 → 进化         │  │
│   │    ↓         ↓       ↓      │  │    ↓        ↓       ↓       │  │
│   │      动态调整               │  │     持续陪伴               │  │
│   └─────────────────────────────┘  └─────────────────────────────┘  │
│                    ↘                           ↙                     │
│                        协作层                                     │
│           (事件总线 · 上下文聚合 · 实时同步)                         │
└─────────────────────────────────────────────────────────────────────┘
```

**执行核心**：目标澄清 → 充分性评估 → 分阶段规划 → 可执行任务 → 反馈循环 → 动态调整

**认知核心**：用户画像 → 长短期记忆 → 认知棱镜 → 情绪动机理解 → 个性化支持 → 持续陪伴

### 7阶段成长循环

每次交互都汇入持续改进的循环：

```
                    ┌──────────┐
                    │   感知   │ ← 被动信号捕获
                    └────┬─────┘
                         │
         ┌───────────────┼───────────────┐
         ▼               ▼               ▼
    ┌─────────┐    ┌──────────┐    ┌─────────┐
    │  澄清   │───→│   规划   │───→│  执行   │
    └─────────┘    └──────────┘    └────┬────┘
         ↑                              │
         │         ┌──────────┐         │
         │         │   反思   │←────────┘
         │         └────┬─────┘
         │              │
    ┌────────────┐ ┌─────────┐
    │    适配    │←│  强化   │
    └────────────┘ └─────────┘
         │
         └──────────────→ [下一轮迭代]
```

### 证据驱动的用户画像

四维认知画像的每个维度都有**行为证据**支撑，不是猜测：

| 维度 | 追踪内容 | 如何帮助你 |
|:-----|:---------|:-----------|
| **知识** | 掌握度 · 遗忘曲线 · 学习速度 | 精准复习推送 · 薄弱点预警 |
| **认知** | 元认知水平 · 认知负荷 · 思维模式 | 动态调整讲解深度 |
| **动机** | 自我效能感 · 学习偏好 · 兴趣分布 | 个性化激励策略 |
| **社交** | 社群贡献 · 沟通特征 | 智能匹配学习伙伴 |

### GraphRAG 知识星图

融合语义搜索与知识图谱遍历的混合检索架构：

```
                     查询: "什么是梯度下降？"
                                  |
              +-------------------+-------------------+
              |                                       |
              v                                       v
      +--------------+                        +--------------+
      |  向量搜索    |                        |  图遍历      |
      | (pgvector)   |                        | (Apache AGE) |
      +--------------+                        +--------------+
              |                                       |
      语义相似文档                              前置知识关联
      - 梯度下降定义                           - 偏导数
      - SGD vs Adam                            - 损失函数
              |                                       |
              +-------------------+-------------------+
                                  |
                          结果融合
                                  |
                         上下文化响应
```

**性能**：向量检索 < 200ms · 图遍历 < 500ms · 综合 < 800ms

## 🚀 功能亮点

### 🤖 AI 微导师
自适应对话，识别你的隐性需求。当你说"这个好难"，它不只是解释——它诊断你的认知状态并调整方法。

### 🌌 知识星图
你的个人知识网络，可视化为宇宙星图。每个概念是一颗星，掌握度决定亮度，关联形成星座。

### 📋 智能任务
6种任务类型，AI 基于薄弱点自动推荐。内置番茄钟专注模式，帮你保持心流。

### 🏆 成就引擎
真正有效的游戏化——连续打卡、里程碑、契约系统、隐藏成就，带来惊喜和激励。

### 👥 社群学习
基于认知画像智能匹配学习伙伴。学习小队和冲刺群，集体成长。

### 🔄 闭环反馈
每次交互都反馈到你的画像。系统随你进化，不只是为你服务。

                               │ gRPC

│  ┌─────────────────────────────────────────────────────────────┐    │
│  │                    ChatOrchestrator                          │    │
│  │  上下文构建 → 路由 → 验证 → 执行 → 响应                      │    │
│  └─────────────────────────────────────────────────────────────┘    │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │                    认知中枢                                  │    │
│  │  画像 · 记忆 · 星图 · 成就 · 社群                           │    │
│  └─────────────────────────────────────────────────────────────┘    │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │                   GraphRAG 层                                │    │

    PostgreSQL 16          Redis 7+             MinIO/S3
    + pgvector            (缓存/发布订阅)        (存储)

### 技术选型

| 层级 | 技术 | 选型理由 |
|:-----|:-----|:---------|
| **移动端** | Flutter · Riverpod · Hive | 跨平台 · 声明式状态管理 · 本地缓存 |
| **网关层** | Go · Gin · WebSocket | 高并发 · 低延迟协议转换 |
| **AI 引擎** | Python · LangGraph · Celery | AI 生态 · FSM 可观测 · 异步任务 |
| **向量库** | pgvector | 与业务库统一，运维简单 |
| **图数据库** | Apache AGE | PostgreSQL 原生扩展 |
| **协议** | Protobuf + gRPC | 强类型 · 流式传输 · 跨语言 |

## 🔧 快速开始

### 环境要求

- Go 1.21+
- Python 3.11+
- Flutter 3.x
- Docker & Docker Compose

### 本地开发

```bash
# 克隆项目
git clone https://github.com/BRSAMAyu/Sparkle-project.git && cd Sparkle-project

# 配置环境变量
cp .env.example .env
# 编辑 .env，填入 LLM API Key 等配置

# 启动基础设施 (PostgreSQL, Redis, MinIO)
make dev-up

# 启动后端 (分别在新终端)
make grpc-server    # Python AI 引擎
make gateway-dev    # Go 网关

# 启动移动端
make mobile-run
```

### 常用命令

```bash
make proto-gen              # 生成 Protobuf 代码 (buf/protoc)
make sync-db                # 数据库迁移 + SQLC 生成
make smoke                  # 所有服务健康检查
make celery-up              # 启动异步任务队列
make env-check              # 配置 + 连接自检
```
