## 📝 使用说明

### 初始化商城数据

```bash
# 进入后端目录
cd backend

# 初始化商城（首次）
python scripts/init_shop.py

# 查看商城物品
python scripts/init_shop.py --list

# 查看特定类型
python scripts/init_shop.py --list --type skin

# 按价格筛选
python scripts/init_shop.py --list --min-price 100 --max-price 500

# 清空商城数据（测试用）
python scripts/init_shop.py --clear
```
