# 多智能体系统模块

适用对象：需要理解当前编排链路、协作模式和前后端接入点的开发者。

## 当前状态

- 多智能体能力以 Python 编排层为核心，由 Go Gateway 转发，Flutter 负责协作状态展示。
- 当前主链路是“对话请求 -> Orchestrator 编排 -> 工具或专家协作 -> 结果回传 -> 客户端展示”。
- 该模块仍然有效，但历史重构报告和阶段总结已移入深度归档，不再作为主入口。

## 关键路径

1. 协议入口：`proto/agent_service.proto`
2. Python 编排：`backend/app/orchestration/` 与 `backend/app/agents/`
3. Go 接入：`backend/gateway/internal/agent/`、`backend/gateway/internal/handler/`
4. Flutter 展示：`mobile/lib/presentation/widgets/agents/`
5. 集成说明：`../03_功能实现指南/09_多智能体系统集成指南.md`

## 已知边界

- 业务写入仍应以任务、计划、知识图谱等现有服务为准，不应让实验性编排直接接管业务真源。
- 协作可视化属于表现层，不能代替后端执行、审计和状态落库。
- 如果旧的实施报告与当前代码冲突，以现有协议、代码和集成指南为准。
