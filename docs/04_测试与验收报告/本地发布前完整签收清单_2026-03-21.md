## 0. 使用规则

这份文档是本轮发布前验收的唯一主清单。

- 所有验收动作必须映射到某个清单项
- 所有修复动作原则上只服务于未通过项
- 发现新问题时先补录清单，再修
- 一个条目只有在“真实链路走通 + 有证据 + 用户体验可接受”时才可标记 `PASS`
- 如果功能不存在，不允许写成 `PASS`，必须标记为“未实现”或“当前版本不纳入”

建议每项记录以下信息：

| 字段 | 说明 |
|---|---|
| 状态 | `PASS` / `PARTIAL` / `FAIL` / `PENDING` / `NA` |
| 证据 | 截图、录屏、接口返回、日志、数据库记录、WebSocket 流、Crash 日志 |
| 环境 | iOS 模拟器 / Android 模拟器 / 本地服务 / 真机 / 弱网 |
| 责任人 | 谁修、谁复验 |
| 下一步 | 若不是 `PASS`，明确还差什么 |
