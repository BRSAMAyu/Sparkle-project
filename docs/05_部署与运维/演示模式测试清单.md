## 🐛 常见问题排查

### 问题1: 知识星图为空白

**检查**:
- [ ] 确认已通过游客登录激活演示模式
- [ ] 检查控制台是否有 `Demo Mode enabled` 日志
- [ ] 验证 `DemoDataService.isDemoMode == true`

**解决**:
```dart
// 在 auth_provider.dart 的 loginAsGuest 方法中
DemoDataService.isDemoMode = true;  // 确保这行代码执行
```

---

### 问题2: 任务列表为空

**检查**:
- [ ] 验证 DemoDataService 中的 demoTasks 数据
- [ ] 检查任务 provider 是否正确读取 isDemoMode

**解决**:
```dart
// 在 task_repository.dart 或相关文件中
if (DemoDataService.isDemoMode) {
  return NetworkResult.success(DemoDataService().demoTasks);
}
```

---

### 问题3: 认知胶囊不显示

**检查**:
- [ ] 验证 demoCapsules 数据
- [ ] 检查认知棱镜 provider

**解决**: 确保认知棱镜 provider 读取演示数据

---

### 问题4: LLM 对话不工作

**检查**:
- [ ] 确认后端服务正常运行
- [ ] 验证 API 配置（DeepSeek API Key）
- [ ] 检查 WebSocket 连接

**解决**: 演示模式不影响 LLM 对话，应该正常工作
