## 🚀 部署步骤

### 1. 服务器首次部署

```bash
# 1. 克隆代码（自动包含MDX文件）
git clone <your-repo-url> sparkle-flutter
cd sparkle-flutter

# 2. 验证词典文件已下载
ls -lh data/dictionaries/oaldpe.mdx
# 应显示: 73M oaldpe.mdx

# 3. 启动服务
docker compose up -d sparkle_api

# 4. 测试词典功能
curl "http://localhost:8000/api/v1/vocabulary/lookup?word=test"
```

### 2. 后续更新

```bash
# 拉取最新代码（自动更新词典文件）
git pull origin main

# 重启服务
docker compose up -d sparkle_api
```

## 🔧 配置说明

### 环境变量

在 `backend/.env` 或 `docker-compose.yml` 中配置：

```bash
# MDX词典文件路径（本地开发）
MDX_DICTIONARY_PATH=/Users/a/code/sparkle-flutter/data/dictionaries/oaldpe.mdx
MDD_RESOURCES_PATH=

# Docker环境（docker-compose.yml已配置）
MDX_DICTIONARY_PATH=/app/data/dictionaries/oaldpe.mdx
```

### Docker配置

```yaml
# docker-compose.yml
services:
  sparkle_api:
    environment:
      - MDX_DICTIONARY_PATH=/app/data/dictionaries/oaldpe.mdx
    volumes:
      - ./data/dictionaries:/app/data/dictionaries:ro
```

### Python依赖

已在 `backend/Dockerfile` 中添加：
```dockerfile
RUN uv pip install --system --no-cache \
    readmdict python-lzo beautifulsoup4 lxml
```

## ⚠️ 常见问题

### 问题1: 词典文件未找到

**症状：**
```
WARNING: MDX dictionary file NOT found
```

**解决方案：**
```bash
# 检查文件是否存在
ls -la data/dictionaries/oaldpe.mdx

# 如果不存在，重新拉取Git
git fetch --all
git reset --hard origin/main
git lfs pull  # 如果使用Git LFS

# 验证文件
ls -lh data/dictionaries/
```

### 问题2: Docker容器内无法访问词典

**症状：**
```
FileNotFoundError: /app/data/dictionaries/oaldpe.mdx
```

**解决方案：**
```bash
# 1. 检查卷挂载
docker compose exec sparkle_api ls -la /app/data/dictionaries/

# 2. 检查环境变量
docker compose exec sparkle_api env | grep MDX

# 3. 重新构建容器
docker compose down sparkle_api
docker compose build --no-cache sparkle_api
docker compose up -d sparkle_api
```

### 问题3: MDX依赖缺失

**症状：**
```
ModuleNotFoundError: No module named 'readmdict'
```

**解决方案：**
```bash
# 重新构建Docker镜像（包含依赖）
docker compose down sparkle_api
docker compose build --no-cache sparkle_api
docker compose up -d sparkle_api

# 验证依赖
docker compose exec sparkle_api pip list | grep readmdict
```
