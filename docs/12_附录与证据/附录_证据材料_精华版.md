## B. 状态机与工具约束

### B.1 推理状态机

**状态定义**:
```
INIT → THINKING → TOOL_CALLING / GENERATING → DONE
                        ↓
                     FAILED
```

| 当前状态 | 触发条件 | 目标状态 |
|---------|---------|---------|
| `INIT` | 请求验证通过 | `THINKING` |
| `THINKING` | 需要工具 | `TOOL_CALLING` |
| `THINKING` | 无需工具 | `GENERATING` |
| `TOOL_CALLING` | 工具成功 | `GENERATING` |
| `TOOL_CALLING` | 工具失败(可补偿) | `TOOL_CALLING` (补偿) |
| `GENERATING` | 生成完成 | `DONE` |

**代码位置**: `backend/app/orchestration/orchestrator.py`, `state_manager.py`

---

### B.2 工具调用拦截 (三层验证)

**验证流程**:
```
工具调用请求
    ↓
第一层: Schema验证 (参数类型、大小限制)
    ↓
第二层: Allowlist检查 (工具是否在白名单)
    ↓
第三层: 业务规则 (配额、任务数量限制)
    ↓
风险标志计算 (PONR、批量操作)
```

**拦截示例**:

| 场景 | 拦截原因 | 日志输出 |
|------|---------|---------|
| **未知工具** | `hack_database` 不在白名单 | `Tool not found: hack_database`<br>`Security event: unauthorized_tool_access` |
| **参数错误** | `title` 为 None (必填) | `ValidationError: title is required` |
| **配额超限** | 今日创建配额已用完 | `Quota exceeded: 0 remaining`<br>`User quota resets at 2026-02-03 00:00:00` |
| **任务过多** | 待办任务 20+ 个 | `Task limit exceeded: 23/20`<br>`User should complete 3 tasks first` |

**代码位置**: `backend/app/orchestration/grounding_validator.py`, `executor.py`

---

### B.3 关键操作二次确认 (PONR)

**确认流程**:
```
用户请求 → AI生成计划 → 工具验证(PONR=True)
    ↓
风险评估 → WebSocket推送确认UI
    ↓
用户决策 → 执行/取消
```

**确认对话框示例**:
```
┌──────────────────────────────────────┐
│ ⚠️  确认删除计划                     │
├──────────────────────────────────────┤
│ 您确定要删除以下计划吗？              │
│ • Python零基础入门                    │
│ • 包含任务: 20个                     │
│ • 完成进度: 45%                       │
│                                      │
│ ⚠️  此操作不可撤销，删除后无法恢复！ │
│                                      │
│        [取消]          [确认删除]    │
└──────────────────────────────────────┘
```

**PONR标记**:
```python
@dataclass
class ToolCallSpec:
    point_of_no_return: bool = False  # 删除操作=True
    compensation_call: dict | None   # 失败补偿
```

**代码位置**: `backend/app/orchestration/schemas.py`, `mobile/lib/features/plan/presentation/widgets/`
