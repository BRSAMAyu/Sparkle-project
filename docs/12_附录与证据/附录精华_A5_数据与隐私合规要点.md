# 附录 A5. 数据与隐私合规要点

## 一、数据最小化原则

### 1.1 必要字段采集清单

**用户注册/登录阶段**：
```
✅ 必要字段:
  - 用户名/邮箱 (用于身份认证)
  - 密码哈希 (bcrypt 加密, 单向)
  - 设备信息 (用于安全检测)

❌ 不采集:
  - 真实姓名
  - 身份证号
  - 手机号
  - 家庭地址
  - 银行卡信息
```

**学习数据采集**：
```
✅ 采集支撑画像的必要字段:
  - 知识点掌握度 (0-100 分数)
  - 学习时长 (分钟数)
  - 任务完成状态 (pending/in_progress/completed)
  - 聊天消息内容 (用于AI辅导)
  - 知识星图节点数据

❌ 不采集:
  - 生物识别信息 (指纹、人脸等)
  - 精确定位信息 (GPS坐标)
  - 通讯录
  - 相册/文件 (未经明确授权)
  - 后台行为数据
```

### 1.2 数据保留期限

| 数据类型 | 保留期限 | 删除策略 |
|---------|---------|---------|
| **账号信息** | 账号存续期间 | 用户注销后 30 天内删除 |
| **聊天记录** | 180 天 | 超期自动清理,用户可手动删除 |
| **学习数据** | 账号存续期间 | 用户可随时导出/删除 |
| **知识星图** | 账号存续期间 | 用户可导出,删除后 30 天保留 |
| **日志数据** | 90 天 | 超期自动清理 |
| **缓存数据** | 24 小时 | 自动过期 |

```python
# 实现机制 (backend/app/services/compliance/crypto_erase.py):
class CryptoEraseManager:
    """加密抹除管理器"""

    async def destroy_user_key(self, user_id: UUID) -> CryptoShreddingCertificate:
        """
        销毁用户加密密钥

        流程:
        1. 撤销用户 DEK (Data Encryption Key)
        2. 标记密钥为 inactive
        3. 生成 CryptoShreddingCertificate (销毁证明)
        4. 返回证明给用户
        """
        # 查找用户密钥
        key = await self._get_active_user_key(user_id)

        # 标记为 inactive
        key.is_active = False
        key.deleted_at = datetime.now()

        # 生成销毁证明
        certificate = CryptoShreddingCertificate(
            user_id=user_id,
            destroyed_at=datetime.now(),
            destruction_method="crypto_shredding",
            certificate_id=str(uuid4())
        )

        await self.db.commit()
        return certificate
```

## 三、安全保障措施

### 3.1 鉴权机制

**JWT Token 认证**：
```python
# 实现 (backend/app/core/security.py:35-56)

def create_access_token(data: dict, expires_delta: timedelta) -> str:
    """
    创建 JWT access token

    安全特性:
    - HS256 算法 (HMAC-SHA256)
    - 短期有效 (默认 30 分钟)
    - 包含 jti (JWT ID) 用于撤销
    - 包含 iss/aud 声明验证
    """
    to_encode = data.copy()
    expire = datetime.now(UTC) + expires_delta

    to_encode.update({
        "exp": expire,                      # 过期时间
        "iat": datetime.now(UTC),          # 签发时间
        "jti": str(uuid4()),                # 唯一标识
        "type": "access",                   # Token 类型
        "iss": "sparkle-gateway",           # 签发者
        "aud": "sparkle-app"                # 受众
    })

    return jwt.encode(to_encode, settings.SECRET_KEY, algorithm="HS256")
```

**Token 刷新机制**：
```
Access Token (30分钟有效)
    ↓ 过期
Refresh Token (7天有效)
    ↓ 自动刷新
无需重新登录
```

**安全配置** (`backend/app/config/settings.py`):

### 3.3 敏感字段脱敏

**日志脱敏规则**：
```python
# 日志脱敏工具

def mask_email(email: str) -> str:
    """邮箱脱敏"""
    if '@' not in email:
        return "***@***"
    local, domain = email.split('@')
    return f"{local[:2]}***@{domain}"

def mask_token(token: str) -> str:
    """Token 脱敏"""
    if len(token) < 10:
        return "***"
    return f"{token[:6]}...{token[-4:]}"

# 日志输出示例
logger.info(f"User {mask_email(user.email)} logged in")
logger.info(f"Token: {mask_token(token)}")
# 输出: User us***@example.com logged in
# 输出: Token: eyJhbGci...jMzIn0
```

**数据库脱敏存储**：
```python
# 密码哈希 (单向加密, 不可解密)
from passlib.context import CryptContext

pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")

def hash_password(password: str) -> str:
    return pwd_context.hash(password)  # $2b$12$...

# 敏感数据加密存储 (双向加密)
class CryptoEraseManager:
    async def encrypt_payload(self, user_id: UUID, plaintext: str) -> str:
        """
        使用用户级 DEK (Data Encryption Key) 加密

        架构:
        - 用户数据 → DEK (AES-256-GCM) 加密
        - DEK → 主密钥 加密后存储
        - 删除时只需销毁 DEK, 数据永久无法解密
        """
        key = await self.get_or_create_user_key(user_id)
        dek = self._decrypt_key(key.encrypted_key)
        aes = AESGCM(dek)
        nonce = os.urandom(12)
        ciphertext = aes.encrypt(nonce, plaintext.encode("utf-8"), None)
        return base64.b64encode(nonce + ciphertext).decode("ascii")
```

**前端脱敏显示**：
```dart
// Flutter: 敏感信息脱敏显示

class MaskingUtil {
  static String maskEmail(String email) {
    final parts = email.split('@');
    if (parts.length != 2) return '***@***';
    final local = parts[0];
    final domain = parts[1];
    return '${local.substring(0, 2)}***@$domain';
  }

  static String maskPhone(String phone) {
    if (phone.length != 11) return '***';
    return '${phone.substring(0, 3)}****${phone.substring(7)}';
  }
}
```

### 3.4 访问控制

**基于角色的访问控制 (RBAC)**：
```python
# backend/app/core/access_control.py

class Role(str, Enum):
    USER = "user"
    ADMIN = "admin"
    MODERATOR = "moderator"

def require_role(role: Role):
    """角色检查装饰器"""
    def decorator(func):
        async def wrapper(*args, **kwargs):
            user = get_current_user()
            if user.role != role:
                raise HTTPException(403, "权限不足")
            return await func(*args, **kwargs)
        return wrapper
    return decorator

# 使用示例
@require_role(Role.ADMIN)
async def delete_user(user_id: UUID):
    """仅管理员可删除用户"""
    ...
```

**跨租户隔离**：

```python
# 确保用户只能访问自己的数据

async def get_user_tasks(user_id: UUID, db: AsyncSession):
    """查询时强制用户ID过滤"""
```
