### 6. 【P2-次要】10MB清洗后大小限制实现 🟡✅

**文件**: `backend/app/services/document_service.py:499-592`

**实现策略**:

#### 文档大小分类处理
| 原始大小 | 处理模式 | 返回内容 |
|----------|----------|----------|
| < 20KB | 全文模式 | 完整文本 + 摘要 |
| 20KB - 10MB | 全文模式 | 完整文本 + 摘要 |
| > 10MB | 压缩模式 | 仅压缩摘要（Map-Reduce） |

#### 核心逻辑
```python
MAX_CLEANED_SIZE = 10 * 1024 * 1024  # 10MB

if total_chars <= MAX_CHARS:
    # 返回完整文本
    return {"mode": "full_text", "full_text": full_text, ...}
else:
    # 返回压缩摘要
    document_map = await self._run_map_reduce(sections, task_id)
    return {"mode": "compressed", "summary": document_map, ...}
```

**返回字段**:
- `truncated`: 布尔值，指示内容是否被截断
- `size_bytes`: 实际大小（字节）
- `compressed_size_bytes`: 压缩后大小（字节）
- `message`: 超过限制时的提示信息
