## 📋 执行摘要

### 项目概况

Sparkle 是一个功能丰富的 AI 辅助学习和任务管理应用，采用现代化的三层架构：

| 层级 | 技术栈 | 代码量 | 主要职责 |
|------|--------|--------|---------|
| **Flutter Mobile** | Dart + Riverpod | ~373,717 行 | 移动端 UI 和用户交互 |
| **Go Gateway** | Go + Gin + WebSocket | ~58,929 行 | API 网关、实时通信、认证 |
| **Python gRPC** | Python + gRPC + LangGraph | ~209,666 行 | AI 编排、LLM 调用、工具执行 |

### 问题统计

| 优先级 | 问题数量 | 占比 |
|--------|---------|------|
| **P0 - 阻塞性** | 23 | 15% |
| **P1 - 重要** | 48 | 31% |
| **P2 - 一般** | 62 | 40% |
| **P3 - 优化** | 21 | 14% |
| **总计** | **154** | 100% |

### 核心发现

#### 🔴 高危问题 (P0)

1. **安全漏洞**
   - 废弃的 WebSocket 查询参数认证仍可用
   - Redis Fail-Closed 默认值为 false
   - 内部 API 端点缺乏 IP 白名单

2. **数据一致性**
   - Plan 模型重复字段定义
   - ChatMessage 复合主键与 BaseModel 冲突
   - 熔断器未被实际使用

3. **核心功能缺陷**
   - 消息发送无本地预览
   - WebSocket 重连消息丢失无通知
   - 反馈提交静默失败

#### 🟠 重要问题 (P1)

1. **性能瓶颈**
   - 1216 处宽泛异常捕获（Python）
   - 缺少复合索引影响查询性能
   - gRPC 重试策略参数过短

2. **用户体验断层**
   - 消息发送失败无重试按钮
   - 历史消息无法加载更多
   - 专注时钟与任务状态不同步

3. **状态管理**
   - activeTaskProvider 状态丢失
   - 跨 Provider 状态同步依赖手动监听

def _fallback_route_by_heuristics(self, message: str, context: dict) -> RouteDecision:
    """基于简单规则的降级路由"""
    msg_lower = message.lower()
    
    # 复杂度检测
    if any(kw in msg_lower for kw in ["计划", "方案", "分步骤", "拆解"]):
        return RouteDecision(execution_mode="langgraph", reason="heuristic:complex_plan")

class PersonaPlanningConstraints:
    # 集中管理默认值
    DEFAULTS = {
        "max_session_minutes": 45,
        "min_session_minutes": 10,
        "time_multiplier": 1.0,
        "depth_preference": 0.5,
    }
    
    def _validate_preference(self, key: str, value: Any) -> Any:
        """验证偏好值是否在合理范围内"""
        validators = {
            "max_session_minutes": lambda v: max(10, min(90, int(v))),
            "time_multiplier": lambda v: max(0.5, min(2.0, float(v))),
            "depth_preference": lambda v: max(0.0, min(1.0, float(v))),
        }
        return validators.get(key, lambda v: v)(value)

class ToolError(Exception):
    """工具执行错误基类"""
    def __init__(self, message: str, suggestion: str, error_type: str = "execution_error"):
        super().__init__(message)
        self.suggestion = suggestion
        self.error_type = error_type

class ValidationError(ToolError):
    """参数验证错误"""
    def __init__(self, message: str):
        super().__init__(
            message=message,
            suggestion="请检查输入参数是否符合要求",
            error_type="validation_error"
        )

class ResourceNotFoundError(ToolError):
    """资源不存在错误"""
    def __init__(self, resource_type: str, resource_id: str):
        super().__init__(
            message=f"{resource_type} {resource_id} 不存在",
            suggestion=f"请确认 {resource_type} ID 是否正确",
            error_type="not_found"
        )
