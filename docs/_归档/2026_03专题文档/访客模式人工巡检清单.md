# 访客模式人工巡检清单

## 目标

用于核对访客模式是否已经从“通用 demo 列表”升级为“单画像复合型多领域快照”。

本清单按页面组织，每页列出：

- 数据来源
- 关键 demo 字段
- 预期展示结果
- 重点风险

---

## 1. 访客登录与用户信息

- 页面：登录页、访客入口、个人资料页
- 数据来源：
  - `DemoDataService.demoUser`
  - `AuthRepository` demo 分支
  - `UserRepository` demo 分支
- 关键字段：
  - `id`
  - `username`
  - `nickname`
  - `avatarUrl`
  - `flameLevel`
  - `createdAt`
- 预期结果：
  - 访客身份仍使用单账号入口
  - 对外昵称呈现为复合型学习者，而不是纯技术向学生标签
  - 修改头像后刷新仍保留
- 风险：
  - 页面如果直接读 `username`，可能仍显示 `AI_Learner_02`

## 2. 首页 Dashboard

- 页面：首页、预测卡片、今日推荐
- 数据来源：
  - `DemoDataService.demoDashboard`
  - `PredictiveService`
  - `DashboardRepository`
- 关键字段：
  - `flame.today_focus_minutes`
  - `flame.tasks_completed`
  - `flame.nudge_message`
  - `sprint`
  - `growth`
  - `next_actions`
  - `cognitive`
  - `audience_touchpoints`
- 预期结果：
  - 推荐动作同时覆盖学业、语言、恢复或职业任务
  - 文案体现“下午高认知、晚上轻输出”的节律
  - 能看到更细分的人群触点线索
- 风险：
  - 页面若忽略新增字段，`audience_touchpoints` 可能暂时不显示，但不应报错

## 3. 任务页

- 页面：任务列表、任务详情、任务推荐
- 数据来源：
  - `DemoDataService.demoTasks`
  - `TaskRepository` demo 分支
- 关键字段：
  - `title`
  - `tags`
  - `status`
  - `priority`
  - `estimatedMinutes`
  - `difficulty`
  - `userNote`
- 预期结果：
  - 至少可看到六类领域任务：
    - 理工学业
    - 语言表达
    - 艺术创作
    - 阅读反思
    - 健康运动
    - 职业探索
  - 可看到更细分触点任务：
    - 考证计时
    - 内容创作选题
    - 转型能力梳理
    - 运动恢复记录
- 风险：
  - 如果页面只按旧技术标签筛选，可能出现分类错位

## 4. 计划页

- 页面：计划列表、计划详情、计划进度
- 数据来源：
  - `DemoDataService.demoPlans`
  - `PlanRepository` demo 分支
- 关键字段：
  - `name`
  - `description`
  - `progress`
  - `masteryLevel`
  - `isActive`
  - `tasks`
  - `subject`
- 预期结果：
  - 计划不再只围绕技术课程
  - 能看到：
    - 本周复合学习节奏校准
    - 学业理解力主线
    - 语言与表达升级
    - 恢复与复盘习惯回炉
- 风险：
  - 计划详情页如果写死旧 subject 展示逻辑，可能出现空标签

## 5. 星图总览

- 页面：Galaxy 总览、星域浏览
- 数据来源：
  - `DemoDataService.demoGalaxy`
  - `GalaxyRepository` demo 分支
- 关键字段：
  - `nodes`
  - `edges`
  - `sector`
  - `tags`
  - `masteryScore`
- 预期结果：
  - 星图本身仍保留跨学科结构，不需要去掉技术节点
  - 艺术、人文、生命、智慧等星域应与技术星域共同存在
- 风险：
  - 星图节点名仍会出现技术内容，这是设计保留，不算回退

## 6. 星图节点详情

- 页面：节点详情页
- 数据来源：
  - `DemoDataService.getDemoNodeDetail`
- 关键字段：
  - `node`
  - `relations`
  - `relatedTasks`
  - `relatedPlans`
  - `userStats`
- 预期结果：
  - `relatedTasks` 应按节点语义匹配
    - 点开摄影节点，优先出现摄影/作品集/创作任务
    - 点开统计节点，优先出现统计/理工错题/抽样任务
    - 点开运动节点，优先出现恢复/运动/睡眠节律任务
  - `relatedPlans` 应按领域和计划任务内容匹配，而不是通用前几条
- 风险：
  - 如果节点没有明显关键词，匹配会退回到所属星域的领域推荐

## 7. 聊天页

- 页面：聊天历史、最近会话
- 数据来源：
  - `DemoDataService.demoChatHistory`
  - `ChatRepository` demo 分支
- 关键字段：
  - `conversationId`
  - `role`
  - `content`
  - `createdAt`
- 预期结果：
  - 会话主题不应只集中在技术问题
  - 至少可见：
    - 学习节奏
    - 语言输出
    - 摄影构图
    - 睡眠节律
    - 作品集/职业探索
- 风险：
  - 最近会话列表如果按 conversation 聚合异常，可能只看到部分主题

## 8. 认知胶囊

- 页面：胶囊列表、胶囊详情、收藏
- 数据来源：
  - `DemoDataService.demoCuriosityCapsules`
  - `CapsuleRepository` demo 分支
- 关键字段：
  - `title`
  - `relatedSubject`
  - `isRead`
  - `isFavorite`
  - `depthLevel`
- 预期结果：
  - 至少一半内容不是技术主题
  - 新增触点内容应可见：
    - 考证训练
    - 内容创作
    - 行动阻力
    - 恢复策略
- 风险：
  - 收藏、已读状态要能在 demo 快照里保持

  - `DemoDataService.demoErrorRecords`
  - `error_book_provider.dart`
- 关键字段：
  - `subject`
  - `question_text`
  - `user_answer`
  - `correct_answer`
  - `mastery_level`
  - `next_review_at`
- 预期结果：
  - 错题至少覆盖：
    - 高等数学
    - 统计学
    - 英语表达
    - 阅读理解
    - 摄影构图
- 风险：
  - 旧页面如果只识别技术学科图标，可能出现默认 icon

## 10. 专注页

- 页面：专注历史、热力图、统计
- 数据来源：
  - `DemoDataService.demoFocusSessions`
  - `FocusRepository` demo 分支
- 关键字段：
  - `task_id`
  - `duration_minutes`
  - `focus_type`
  - `status`

- 风险：
  - 如果关联的 task 被删改，历史页可能需要 fallback 处理

  - `DemoDataService.demoNotifications`

  - `type`

  - `is_read`

  - `recent_activity`

  - `initiatorGoal`

---

## 一致性总核对

- 首页推荐任务必须能在任务列表中找到
- 星图详情 `relatedTasks` 和 `relatedPlans` 必须与节点领域相符
- 聊天、通知、社区帖子里的主题必须能在任务/计划/胶囊里找到支撑
- 错题、胶囊、行为模式之间要能互相解释
- 责任伙伴、群组、排行榜人物画像要避免全员技术向
- 访客模式下的新增、修改、已读、打卡、头像更新要在当前快照中持续存在
