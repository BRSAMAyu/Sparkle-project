# 全功能全链路验收清单

更新时间：2026-03-20  
适用范围：`Sparkle-project` 全栈本地/服务器部署环境  
目标：把“功能存在”拆解为“前端可见、后端可用、网关可达、数据库有数据、真实用户可操作、异常时有反馈”的完整验收项。

---

## 1. 验收原则

每条链路都按以下 6 层检查：

1. 前端入口存在且可进入
2. API / WebSocket / gRPC / 后台任务链路可达
3. 数据库 / Redis / 向量库 / 图谱 / 对象存储状态正确
4. 真实用户操作可完成，不只是接口 200
5. 异常态有明确反馈，不会静默失败或卡死
6. 与上下游系统联动正常，不形成“孤岛功能”

验收结论分级：

- `PASS`：真实链路可用，体验可接受
- `PARTIAL`：主链可用，但仍有明显体验或边界缺口
- `FAIL`：主链不可用或高概率误导用户
- `PENDING`：本轮尚未实际跑通
