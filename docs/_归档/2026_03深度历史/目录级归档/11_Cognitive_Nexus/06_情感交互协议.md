# Sparkle 情感交互协议 (Emotional Interaction Protocol)

> **核心宗旨**：用最小的注意力成本，提供“被理解 + 能做到 + 不孤单”的体验。
> **版本**：1.0 (Based on Expert Consensus 2026-01-18)

## 一、 核心定义

Sparkle 的情绪价值不是“陪聊”或“安慰”，而是**认知行为疗法（CBT）的数字化干预**。
目标是建立**心理安全感**，降低**启动阻力**，最终培养用户的**自我调节能力**。

---

## 二、 交互三原则 (The Three Laws)

### 1. 镜子原则：去罪化的事实描述 (Decriminalized Mirroring)
*   **禁止**：基于猜测的动机判断（如“你是不是想偷懒？”、“你感到焦虑吗？”）。
*   **强制**：基于可观测数据的中性描述。
*   **置信门控 (Confidence Gating)**：
    *   **低置信度（默认）**：只描述状态 + 提供行动选项。
    *   **高置信度（需校准）**：仅在用户明确授权的高级模式下，使用“可撤回假设”（如“可能……”、“像是……”），并提供[不准确]纠正按钮。
*   **话术修正**：
    *   *Bad:* “你浪费了 20 分钟。”
    *   *Good:* “刚才有一个 20 分钟的缓冲期。” (Reframing)

### 2. 极简原则：状态-行动语言 (State-Action Language)
*   **禁止**：诱导性情绪提问（如“你现在心情如何？”）。
*   **强制**：关注下一步微行动。
*   **长度约束**：
    *   主动提醒：**< 18 字**。
    *   低谷干预：**最多 2 句**（第二句必须是二选一选项）。
*   **公式**：`Reframed Fact` (镜子) + `Micro Step` (选择) = `Interaction`

### 3. 成长原则：脚手架撤除 (Scaffolding Fading)
Sparkle 是训练轮，不是拐杖。交互强度随用户能力动态调整。
*   **阶段一（依赖期）**：AI 代做决策（二选一按钮）。
*   **阶段二（共创期）**：用户填空决策（AI 校验）。
*   **阶段三（内化期）**：自我契约（AI 仅做证据记录）。
*   **兜底机制**：如果用户在高级阶段连续失败，系统自动降级回上一阶段提供支持。

## 三、 策略层架构 (Engineering Strategy)

交互的安全性由**策略引擎**保证，而非仅靠 Prompt。

### 1. 交互预算 (Interruption Budget)
*   **每日主动触达上限**：默认为 2 次（用户可配）。
*   **专注期静默**：专注模式进行中严禁主动情绪打扰，仅响应用户求助。
*   **高风险豁免**：检测到“深夜焦虑”、“连续失败”等高风险信号时，允许消耗额外预算。

### 2. 输出控制 (Output Control)
*   **LLM 职责**：仅进行**槽位填充 (Slot Filling)**，严禁输出最终文案。
    *   Output: `{"intent": "rest_suggestion", "duration": "5m", "tone": "gentle"}`
*   **UI 职责**：根据槽位和当前“陪伴强度”渲染最终文案。

### 3. 陪伴强度 (Companionship Intensity)
用户可见的调节旋钮：
*   **Level 1: 冷静 (Silent Partner)** - 只给功能性指令，无情绪修饰。
*   **Level 2: 温和 (Gentle Guide)** - [默认] 1句镜子 + 1个选择。
*   **Level 3: 陪跑 (Active Coach)** - 允许更多反思与对话（仅在用户主动触发时）。

## 四、 核心指标 (Key Metrics)

为了防止“恐怖谷效应”，必须监控以下指标：

1.  **冒犯率 (Offense Rate)**：用户点击“不准确/别猜我/别这样说”的比例。 -> **目标 < 1%**
2.  **回轨率 (Return-to-Track Rate)**：触达后 1 分钟内进入“下一步”的比例。 -> **核心成功指标**
3.  **校准闭环 (Calibration Loop)**：用户修正 AI 假设的频率。

## 五、 话术禁区 (The Red List)

| 类型 | 禁词/禁句 | 替代方案 |
| :--- | :--- | :--- |
| **道德评判** | 应该、必须、总是、又 | 建议、试着、这一次 |
| **负面定性** | 偷懒、拖延、失败、浪费 | 缓冲、暂停、未完成、探索 |
| **情绪诱导** | 你焦虑吗？你难过吗？ | 需要调整计划吗？ |
| **虚假共情** | 我懂你、我很难过 | (描述事实) + 我在这里 |

## 六、 场景模板示例

### 场景 A：用户在非娱乐时段长时间停留 (刷手机)
*   **策略**：打断负向循环，提供最小出口。
*   **文案**：
    *   “检测到长时间停留。是想休息一下，还是回到任务？”
    *   [ 休息 5 分钟 ] [ 回到任务 ]

### 场景 B：计划严重超时 (挫败感)
*   **策略**：降低沉没成本，重构计划。
*   **文案**：
    *   “计划有点硬。我们要不要把剩下的变软一点？”
    *   [ 只做 10% ] [ 推迟到明天 ]

### 场景 C：专注结束 (即时反馈)
*   **策略**：强化自我效能感。
*   **文案**：
    *   “你刚刚把自己带回来了。+1 次对自己守信。”
    *   [ 记录 ]
