# A5. 数据与隐私合规要点（教育场景"可信"加分项）

## 一、数据最小化：只采集必要字段

### 1.1 必要字段采集清单

**用户注册**（✅采集 / ❌不采集）:
```
✅ 用户名/邮箱（身份认证）
✅ 密码哈希（bcrypt加密，单向）
✅ 设备信息（安全检测）

❌ 真实姓名、身份证号、手机号
❌ 家庭住址、银行卡信息
```

**学习数据**:
```
✅ 知识点掌握度（0-100分数）
✅ 学习时长（分钟数）
✅ 任务完成状态
✅ 聊天消息（AI辅导需要）
✅ 知识星图节点数据

❌ 生物识别信息（指纹、人脸）
❌ 精确定位（GPS坐标）
❌ 通讯录、相册（未授权）
```

### 1.2 数据保留期限

| 数据类型 | 保留期限 | 删除策略 |
|---------|---------|---------|
| 账号信息 | 账号存续期间 | 注销后30天内删除 |
| 聊天记录 | 180天 | 超期自动清理 |
| 学习数据 | 账号存续期间 | 用户可随时删除 |
| 知识星图 | 账号存续期间 | 可导出，删除后30天保留 |
| 日志数据 | 90天 | 超期自动清理 |
| 缓存数据 | 24小时 | 自动过期 |

## 二、可撤回：用户可删除/导出数据

### 2.1 三项核心权利

**✅ 数据访问权**: `GET /api/v1/user/data-export`
- 查看系统存储的所有个人数据
- 返回用户画像、学习数据、聊天记录、知识星图

**✅ 数据导出权**: `POST /api/v1/user/export`
- 导出格式：JSON / PDF可读报告
- 包含：学习统计、认知画像、任务计划
- 导出链接7天有效

**✅ 数据删除权**: `DELETE /api/v1/user/account`
- 30天冷静期（可反悔）
- 加密抹除（Crypto Shredding）
- 生成销毁证明，删除后不可恢复

### 2.2 删除流程

```
用户发起删除
    ↓
身份验证（密码+二次验证）
    ↓
数据导出提示（建议先导出）
    ↓
确认删除（30天冷静期）
    ↓
加密抹除（销毁DEK密钥）
    ↓
生成销毁证明
```

### 2.3 认知画像透明化

用户可查看自己的四维认知画像：
- **知识维度**: 平均掌握度、学习速度、知识点总数
- **认知维度**: 元认知能力、学习风格、认知负荷
- **动机维度**: 自我效能感、学习兴趣、成就动机

操作选项：导出画像数据 / 删除画像数据

## 三、安全：鉴权+加密+脱敏

### 3.1 JWT鉴权机制

**双Token设计**:
```
Access Token（30分钟有效）
    ↓ 过期自动刷新
Refresh Token（7天有效）
```

**安全特性**（`backend/app/core/security.py`）:
- HS256算法（HMAC-SHA256）
- 包含jti（JWT ID）用于撤销
- iss/aud声明验证
- 密钥环境变量存储，不硬编码

### 3.2 传输加密

**全链路加密**:
- **API通信**: HTTPS（TLS 1.3）
- **WebSocket**: WSS加密
- **密码套件**: TLS_AES_256_GCM_SHA384

**Flutter强制HTTPS**:
```dart
// Dio拦截器：非HTTPS拒绝连接
if (!options.uri.isHttps && !kDebugMode) {
  throw Exception("仅允许HTTPS连接");
}
```

### 3.3 敏感字段脱敏

**日志脱敏**:
```python
mask_email("user@example.com")  # → "us***@example.com"
mask_token("eyJhbGci...")        # → "eyJhbGci...jMzIn0"
```

**密码存储**（单向加密）:
```python
pwd_context.hash(password)  # bcrypt哈希，不可解密
```

**敏感数据加密**（双向加密）:
- 用户数据 → DEK（AES-256-GCM）加密
- DEK → 主密钥加密后存储
- 删除时销毁DEK，数据永久无法解密

### 3.4 访问控制

**RBAC权限管理**:
- USER：普通用户
- ADMIN：管理员
- MODERATOR：审核员

**跨租户隔离**:
- 所有查询强制user_id过滤
- 用户只能访问自己的数据

## 四、隐私说明草案（精简版）

**Sparkle（星火）AI学习助手 - 隐私政策**

**生效日期**: 2026年2月2日

### 一、数据收集

**我们收集**:
- 账号信息：用户名/邮箱、密码哈希、设备信息
- 学习数据：掌握度、学习时长、任务记录、聊天内容、知识星图

**我们不收集**:
- ❌ 真实姓名、身份证号、手机号、住址
- ❌ 生物识别信息（指纹、人脸）
- ❌ 精确定位（GPS坐标）、通讯录、相册

### 二、数据使用

**核心功能**:
- 生成个性化认知画像
- 提供智能学习建议
- 优化AI辅导效果

**我们承诺**:
- ❌ 不出售个人信息
- ❌ 不用于广告定向
- ❌ 不与第三方共享（法律强制除外）

### 三、数据安全

- **传输加密**: HTTPS/WSS（TLS 1.3）
- **存储加密**: bcrypt密码哈希 + AES-256-GCM数据加密
- **访问控制**: RBAC权限 + 跨租户隔离

### 四、您的权利

| 权利 | 说明 | API |
|------|------|-----|
| **数据访问权** | 查看所有个人数据 | `GET /api/v1/user/data-export` |

| **画像控制权** | 查看/修改/删除画像 | UI操作 |

### 五、数据保留

- 账号信息：账号存续期间，注销后30天删除
- 聊天记录：180天自动清理
- 学习数据：随时可删除
