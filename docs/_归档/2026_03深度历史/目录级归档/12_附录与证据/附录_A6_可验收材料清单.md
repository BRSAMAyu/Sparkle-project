## 一、端到端演示脚本（3～5分钟）

### 1.1 演示前准备

**环境检查清单**:
- [ ] Go Gateway 运行中 (`http://localhost:8080`)
- [ ] Python gRPC Server 运行中 (`localhost:50051`)
- [ ] PostgreSQL 数据库连接正常
- [ ] Redis 缓存服务正常
- [ ] Flutter App 已启动 (iOS 模拟器/真机)

**快速启动命令**:
```bash
# 一键启动所有服务
make dev-all

# 启动 Go Gateway
make gateway-dev

# 启动 Python gRPC Server
make grpc-server

# 启动 Flutter App
make mobile-run
```
