## 1 使用说明

本清单只保留能够支撑参赛文档关键判断的资料来源，优先级如下：

1. 官方帮助中心、FAQ、产品页、发布说明。
2. 官方博客或官方 PDF。
3. 必要时的官方 GitHub 仓库或公开技术白皮书。

以下材料主要支撑四类判断：

1. 当前主流学习 AI 的能力边界是什么。
2. 当前作业/解题辅助型产品的典型产品逻辑是什么。
3. 当前资料学习型产品的重心是什么。
4. 星火与这些产品相比的系统级差异在哪里。

## 2 通用学习对话型产品

### 2.1 ChatGPT Study Mode

来源名称：ChatGPT Study Mode - FAQ  
来源链接：[OpenAI Help Center](https://help.openai.com/en/articles/11780217-chatgpt-study-mode-faq)  
访问时间：2026-03-29

可引用事实：

1. Study mode 可在 ChatGPT 各计划中使用，并覆盖 iOS、Android 和 Web。
2. 其核心方式是通过 Socratic-style questions、分步讲解、基于历史聊天的个性化和基于上传材料的学习支持来帮助用户理解主题。
3. 它明确属于“学习体验”增强，而不是执行闭环产品。
4. 官方同时提醒该模式仍可能出错，需要用户自行核验。

在星火文档中的使用方式：

1. 用于说明当前主流学习对话型 AI 已开始从“直接回答”走向“互动式学习引导”。
2. 用于说明星火与其差异不在“会不会讲题”，而在“是否具备长期成长闭环、知识结构化与执行推进能力”。

### 2.2 Khanmigo

来源名称：Meet Khanmigo: Khan Academy's AI-powered teaching assistant & tutor  
来源链接：[Khanmigo 官方页面](https://khanmigo.ai)  
访问时间：2026-03-29

可引用事实：

1. Khanmigo 的官方定位是 AI-powered personal tutor and teaching assistant。
2. 它强调不会直接给答案，而是通过提问引导学习者自己找到答案。
3. 其优势之一是与 Khan Academy 的内容库整合，覆盖数学、科学、编程、历史和人文学科等。
4. 其产品边界明显偏“学习引导”和“教学支持”，而非长期任务执行闭环。

在星火文档中的使用方式：

1. 用于说明 Socratic 式 AI 学习辅导产品已经成熟到较高水平。
2. 用于凸显星火在知识图谱、执行闭环、成长沉淀和系统连续性上的进一步拓展。

## 3 作业 / 解题辅助型产品

### 3.1 StudyX

来源名称：Best AI Homework Helper Online  
来源链接：[StudyX 官方产品页](https://studyx.ai/ai-homework-helper)  
访问时间：2026-03-29

可引用事实：

1. StudyX 官方将自己定位为 all-in-one 的 AI homework helper。
2. 官方页面强调的核心能力包括：题目求解、AI Notes、AI Flashcards、AI Quiz、Lecture Note、PDF Summarizer、Video Summarizer 等。
3. 它支持文字、图片、PDF 上传等多种输入方式，并强调 step-by-step explanations。
4. 官方页面主打“解题、总结资料、整理学习材料和即时帮助”，更偏题目求解与学习资料辅助。

在星火文档中的使用方式：

1. 用于说明当下学生市场中的强需求集中在“即时求解、题目识别、资料整理和快速解释”。
2. 用于说明星火与其差异在于，星火不是以“解一道题”为组织核心，而是以“长期学习成长主链”为组织核心。

### 3.2 Gauth

来源名称：Gauth - Best AI Homework Helper for All School Subjects  
来源链接：[Gauth 官方首页](https://www.gauthmath.com/)  
访问时间：2026-03-29

可引用事实：

1. Gauth 的首页主定位是 AI Homework Helper。
2. 官方强调 step-by-step solving、detailed explanations、fast solutions 和多学科覆盖。
3. 官方同时突出 tutor service，说明其产品逻辑中包含 AI + expert support 的组合。
4. 它本质上更偏“即时作业辅助”和“问题求解服务”，而不是长期成长系统。

在星火文档中的使用方式：

1. 用于说明“拍照识别 + 逐步解题 + 人工/专家辅助”是作业辅助赛道的重要形态。
2. 用于说明星火并不与其在“搜题速度”上竞争，而是在“长期状态理解、知识结构化和执行闭环”上建立差异。

## 4 资料学习型产品

### 4.1 Quizlet Study Guides

来源名称：Studying with Study Guides  
来源链接：[Quizlet Help Center](https://help.quizlet.com/hc/en-ca/articles/18312306436365-Studying-with-Study-Guides)  
访问时间：2026-03-29

可引用事实：

1. Quizlet 支持用户上传或粘贴课程材料，自动生成 study guide。
2. 生成的学习指南中可包含 outline、flashcard set 等学习材料。
3. 该能力强调的是把已有材料转化成更易学习的内容组织形式。
4. 其核心价值在“资料转学习资源”，而非长期任务推进或成长系统。

在星火文档中的使用方式：

1. 用于说明“AI 帮助加工学习资料”已经成为资料学习型产品的重要方向。
2. 用于说明星火与其差异在于，星火不仅处理资料，还处理计划、任务、图谱、执行与成长反馈。

### 4.2 Quizlet Ask Quizlet

来源名称：Studying with Ask Quizlet  
来源链接：[Quizlet Help Center](https://help.quizlet.com/hc/en-us/articles/42790350723725-Studying-with-Ask-Quizlet)  
访问时间：2026-03-29

可引用事实：

1. Ask Quizlet 的官方定位是“a new way to study directly within Quizlet”。
2. 它支持 step-by-step explanations、查找相关 study sets、判断某个 set 是否适合当前学习、即时生成 flashcards。
3. 它强调的是围绕现有 Quizlet 学习材料展开的解释与延展，而不是外部执行或长期成长系统。
4. 官方说明当前该功能具有可用区域与年龄限制。

在星火文档中的使用方式：

1. 用于说明 Quizlet 当前已经从“资料容器”走向“资料内 AI 学习入口”。
2. 用于与星火的“知识结构 + 主链推进 + 执行闭环”形成区分。

### 4.3 Quizlet Q-Chat（历史路线参考）

来源名称：Studying with Q-Chat  
来源链接：[Quizlet Help Center](https://help.quizlet.com/hc/en-us/articles/18811152410125-Studying-with-Q-Chat)  
访问时间：2026-03-29

可引用事实：

1. Q-Chat 曾被官方定义为可帮助用户更深入理解学习材料的 AI tutor。
2. 官方帮助页明确说明，Q-Chat 已在 `2025-06-30` 后完全停止使用。
3. 因此，在当前竞品分析中，Q-Chat 只能作为 Quizlet 过往的学习对话路线参考，不能作为其当前主要对标主体。

在星火文档中的使用方式：

1. 用于说明 Quizlet 曾尝试学习对话型路线，但当前正式对标应转向 Study Guides 与 Ask Quizlet。
2. 用于增强竞品分析的时效性和准确性。

## 7 引用口径注意事项

1. 不要把外部产品写成“低级竞品”或“功能不行”，而应写成“擅长点不同、边界不同”。
2. 不要把 Q-Chat 当作 Quizlet 的当前主产品能力，应明确说明它已停用。
3. 对 ChatGPT Study Mode 的描述要准确到“学习体验增强”，不要误写成“执行系统”。
4. 对 StudyX / Gauth 的描述应聚焦题目求解、步骤讲解、资料辅助和专家服务，不要误写成长期成长系统。
5. 除非后续补充可靠来源，否则不在正式稿中引入未经核实的市场规模数字。
