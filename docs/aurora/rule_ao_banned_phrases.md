# Rule AO Banned Phrases

Rule AO blocks identity-style metacognition language.

## Blacklist Families

- Identity labels
  - `你是.*型`
  - `你是.*人格`
  - `你属于.*型`
  - `你属于.*人格`
- Personality claims
  - `你的性格.*`
  - `你很拖延`
  - `你很完美主义`
  - `你很焦虑`
  - `你很内向`
  - `你很外向`
- Absolutes
  - `你总是.*`
  - `你从不.*`

## Allowed Counterexamples

- 你过去 10 次对完成时间估得偏乐观 2.3 小时。
- 你在最近 24 次里有 18 次比预估花得更久。
- 样本不足，继续观察中。
