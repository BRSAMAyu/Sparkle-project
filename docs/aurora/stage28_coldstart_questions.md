# Stage 28 Coldstart Questions

更新时间：2026-04-21

## Q1
- 题目：开始新目标时，你更像哪种方式？
- 映射维度：`openness`、`conscientiousness`
- 选项：
  - `structured`：先搭结构再行动
  - `mixed`：先有框架，再边做边调
  - `explore`：先试试看，让方向自己浮现
  - `skip`：跳过

## Q2
- 题目：遇到难题时，你更容易从哪里补能量？
- 映射维度：`extraversion`、`agreeableness`
- 选项：
  - `solo`：先自己想清楚
  - `small_group`：找一两个人讨论
  - `group`：边聊边想最有感觉
  - `skip`：跳过

## Q3
- 题目：当计划被打乱时，你通常最先出现什么反应？
- 映射维度：`neuroticism`、`conscientiousness`
- 选项：
  - `replan`：马上重排，尽快回正
  - `pause`：会卡一下，但能慢慢拉回来
  - `swing`：情绪和节奏都会受影响
  - `skip`：跳过

## 说明
- 所有题目均提供 `skip`，不强制作答。
- 冷启动仅产生弱先验，单维初始 `confidence <= 0.2`。
- 表述仅描述行为倾向，不输出类型化判断标签。
