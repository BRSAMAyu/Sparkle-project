## 4 对外统一口径

### 4.1 一句话介绍

星火是一款面向大学生的 AI 学习成长系统，能够把学习目标转化为可推进的任务、知识路径与成长反馈。

### 4.2 评委易懂版介绍

星火不是只会聊天的 AI，也不是普通打卡软件。它会结合用户的学习目标、知识状态和执行情况，帮助用户做计划、拆任务、组织知识、推进执行，并把结果继续沉淀成后续学习策略。

### 4.3 技术表达版介绍

星火采用 Flutter + Go Gateway + Python AI Engine 的三层异构架构，通过双核编排、Mirofish 多 Agent 协作、GraphRAG 知识星图和 OpenClaw 执行闭环，构建一条“理解 - 规划 - 执行 - 反馈 - 成长沉淀”的连续主链。

### 4.4 不建议作为主标题的表述

以下说法可以在正文中解释，但不建议直接作为封面主标题：

1. 学习操作系统
2. AI 时间导演
3. 星火效率助手

原因是这些表述要么理解门槛偏高，要么过于偏向早期概念，不利于评委在短时间内抓住项目本质。
