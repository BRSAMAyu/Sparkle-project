# 大创计划（北京市赛→国赛）情报库

> 采集日期：2026-09-18。用途：指导路演 PPT、计划书在"大学生创新创业训练计划"体系下的立项/答辩打磨。后续新情报持续追加到本文件。

## 1. 体系定位（先搞清我们参加的到底是什么）

"大创"是**训练计划**（项目制），不是一次性比赛：立项 → 过程管理 → 结题验收 → 优秀成果推荐。层级分**校级 / 北京市级 / 国家级**三档立项。用户口中的"市赛"对应北京市级立项评审与市级展示，"国赛"对应**全国大学生创新创业年会**（第十九届为 2026 年）及优秀项目推荐。

**三类项目**（教育部《国家级大学生创新创业训练计划管理办法》教高函〔2019〕13 号）：
- 创新训练项目：本科生个人/团队在导师指导下自主完成创新性研究设计、实施、研究报告与学术交流
- 创业训练项目：完成商业计划书编制、可行性研究、模拟企业运行、创业报告
- 创业实践项目：真实创业落地

Sparkle 定位建议：按**创新训练项目**申报（有系统实现与工程验证，走"创新性研究"口径最稳），商业内容作为应用价值佐证而非主线。

## 2. 评审维度（官方口径）

### 北京市教委 2026 年通知（jw.beijing.gov.cn，2026-04-09）
- 组织专家对项目成果的**理论意义、学术价值、应用价值**进行评价
- 坚持**分类评价、绩效评价、过程评价**相结合

### 立项评审通用维度（各校自定权重，多校汇总）
| 维度 | 常见权重 |
|---|---|
| 选题创新性 | 25–30 分 |
| 方案可行性（技术路线） | 20–30 分 |
| 团队构成与分工 | 15–25 分 |
| 研究基础与条件 | 合并计入 |
| 预期成果价值 | 10–15 分 |
| 经费预算合理性 | 5–10 分 |

### 结题验收
- 北京理工大学机制：百分制，**70 分及格**，"项目内容管理"+"项目过程管理"双指标
- 北邮分值认定：**日常管理 / 过程表现 / 结题验收**三维度（yepeida.bupt.edu.cn）
- 厦门大学等级线：≥90 优秀，75–89 良好，60–74 通过

## 3. 北邮 2026 关键时间线

- 立项申报开放：**2026-05-21 至 2026-06-30**（win.bupt.edu.cn 通知）
- 流程：项目申报 → **学院评审** → 学校审核 → 立项公布（2025 年 534 项通过立项，jwbs.bupt.edu.cn）
- 申报在"北京市大学生创新创业训练计划平台"进行
- 团队：创新训练一般 3–5 人，每生每学年限主持/参与 1 项

## 4. 进阶路径（国赛 = 年会）

全国大学生创新创业年会（教育部）：
- 三条参与线：**学术论文交流**（第一作者须为本科生，优先已发表论文）、**改革成果项目展示**、**创业项目推介**
- 遴选流程：学科专家**初评** → "国创计划"专家工作组**复选** → 年会**现场展示答辩**
- 第十九届推荐要求（暨大通知，2026-05）：须为国家级立项项目（不含当年立项）、具备创新成果、论文学术水平较高或作品完善且展示性好
- 奖项含"最佳创意项目"等；优秀创业项目可直通中国国际大学生创新大赛（原"互联网+"）
- 部分高校（如北京印刷学院）要求获批大创项目须参加"互联网+"或"挑战杯"——Sparkle 多线参赛时注意材料口径分工

## 5. 对 Sparkle 材料的策略启示

1. **大创 ≠ 商业路演**：评审是"研究/训练"视角。现有鸿雁杯 PPT 的商业叙事（7 天救急、增长路径）要转译成研究叙事：**研究问题**（LLM 能力与普通人目标达成之间的鸿沟如何用系统工程弥合）→ **方法**（Aurora 自适应认知控制/双核路由/证据融合）→ **验证**（ExamSprintBench、24 场景、97.3% closeout）→ **产出**（系统原型 + 可复现基准 + 论文潜力）
2. **创新点要可考核**：把"三大引擎/Aurora/MirrorFish"等代号落到 2–3 条可验收的研究内容上，避免评委追问时代号无定义
3. **导师作用前置**：大创强调"导师指导下"，黄亚坤老师的指导角色要写实（研究方案把关、实验设计）
4. **材料矩阵**：立项申报书（主审材料）+ 答辩 PPT + 计划书（补充）；结题需研究报告/论文。PPT 措辞与申报书必须一致
5. **预算**：大创经费有限（市级通常数千至万元级），预算页若沿用商业 BP 的经营测算会失真，立项版预算应改为科研支出（算力/设备/资料/调研差旅）
