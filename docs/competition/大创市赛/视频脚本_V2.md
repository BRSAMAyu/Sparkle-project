## 3. 逐镜头脚本（S3 主体，D1-D8）

> 通用录屏规范：分辨率统一 1080p（真机 QuickTime 原生输出）、30fps、全程开触控高亮（模拟器：I/O → Touch Indicators）、录制期间开勿扰并清空通知栏、明暗模式全程一致。口播语速基准 4.2 字/秒，每条台词已按秒数预算控字。
> 演示账号：`demo_video_1789909590` / `DemoVideo2026!`（token 30 分钟过期，**每镜头开录前刷新**）。人设：北邮大二，备考离散数学。

### D1 登录 + 首页（0:40-0:48，8s）

- **操作**：① 登录页输入账号密码（预贴密码，输入过程 2s 内完成）→ ② 点击登录 → ③ 首页完整呈现：目标「离散数学期末复习」+ 3 任务（T1 已完成点亮）+ 火苗状态。
- **口播**（32 字 / 8s）：
  「打开 Sparkle——这是我的学习主页。目标、任务、火苗状态，一眼看清。」
- **录屏注意**：登录动效若超 3s，剪辑时从点击登录硬切首页定格；首页数据已预造，无需现场等待。
- **风险备选**：若首页加载翻车 → 切预录的"下拉刷新"素材（同一页面录两份）。

### D2 对话求助（0:48-1:08，20s）

- **操作**：① 进对话，新建会话 → ② 输入话术并发送：
  「图论完全跟不上，下周就考了，欧拉回路那块怎么都看不懂，怎么办？」
  → ③ 流式回答出现，**等 done 再切镜（R10 实测 13.6s）**。
- **口播**（82 字 / 20s，覆盖发送→流式全程）：
  「下周离散数学就考试了，图论完全跟不上。我不组织完美的问题，像跟学长求助一样，直接说——看，流式回答已经出来了。更重要的是，它一边回答，一边把我的困惑记进了它对我的理解。」
- **录屏注意**：done 已实测 13.6s，20s 预算内"输入 5s + 流式 13.6s + 收尾 1s"刚好装下，**无需剪掉等待**；保底方案仍是先录全（含等待），剪辑时若节奏拖沓，把流式中段 8 倍速快进、旁白覆盖。
- **风险备选**：若现场回答质量波动/超时 → 库内 R1 对话史兜底：重发同一话术再录一条；仍不行切预录素材。

### D3 上传材料 + 引用回答（1:08-1:38，30s）

- **操作**：① 打开材料库，展示已处理好的两条材料：《图论考前小结》（8 chunk，已 processed）、《命题逻辑小结》——**不做现场上传**（解析需 60-99s，见录屏注意）→ ② 回对话输入：
  「根据我上传的《图论考前小结》，欧拉图和哈密顿图到底怎么区分？」
  → ③ 回答带材料引用块：文件名 + 原文判定条件表 + relevance 1.00（R9 已实测通过）→ ④ 手指点开引用块，展示原文出处。
- **口播**（112 字 / 30s）：
  「光会聊天还不够，学习助手得基于我的资料回答。这是我已经上传的《图论考前小结》。现在我问它：欧拉图和哈密顿图，到底怎么区分？注意看——回答带着引用块，出处是我的文件原文，还有相关度评分。AI 不瞎编，每句话都能点回原文。这在学习场景，是底线。」
- **录屏注意**：「上传→解析完成」不可能直播等待（99s）。上传动效**单独补拍**：另传一份小文本，只拍 initiate→进度条前 10s，剪辑时硬切"已处理"状态；引用问答主镜头直接用库内已 processed 的材料 A，两段素材拼接。
- **风险备选**：若引用块渲染异常 → 改问材料 B（命题逻辑）重录一条；仍不行切 R9 预录素材。

### D4 记忆流 · 三天后（1:38-2:00，22s）

- **操作**：① 转场字幕「三天后」（后期加，1s 黑场白字）→ ② 新建会话，输入：
  「我复习到哪了？来点图论的，接着练。」
  → ③ 回答应提及图论困境 / Dijkstra / 考试临近（库内 R1-R5 对话史 + 251 条 episodic 支撑召回）。
- **口播**（85 字 / 22s）：
  「三天后，我回来继续复习。注意——我没有重新自我介绍，直接问：我复习到哪了？它记得我卡在图论，记得那道 Dijkstra，记得考试就在眼前。这就是记忆流：每一次对话，都在构建它对我的理解。」
- **录屏注意**：录制日多造几条新对话垫高"三天前"的史实感（消息时间戳在剪辑字幕上做文章即可，画面不必造假）；若召回口吻平淡，换问法「还记得我上次卡在哪吗」直接点名记忆。
- **风险备选**：若个性化召回不明显 → 兜底切对话历史列表画面（R1-R5 可见）+ 台词不变，画面证明"它存着这些记忆"。

### D5 Aurora「对我的理解」（2:00-2:26，26s，全场 wow 点）

- **操作**：① 首页进 Aurora 理解页 → ② 纵向漫游：知识状态 / 学习偏好 / 目标进度 / 校准卡区（库内已有 chip×2 + correction×1，显示"Aurora · 观察中"）→ ③ 停在 predicted-options（「今晚你真实可用的时间更接近哪个？」+ 选项）→ ④ 点开一条记忆条目，展示"查看来源 / 可纠正"。
- **口播**（95 字 / 26s）：
  「那 Sparkle 眼中的我，到底是什么样？打开 Aurora 理解页——知识状态、学习偏好、目标进度，还有它'还不确定'、主动请我校准的部分。这不是模糊印象，是可解释、可校准的理解。每一条，我都能看来源、能纠正。」
- **录屏注意**：本镜头配字幕强调（页面各区名称逐条浮出）。漫游节奏放慢，每区停 2-3s；优先拍 predicted-options——新用户也有真实内容，观感最稳。
- **风险备选**：若校准卡区空态入镜不好看 → 跳过该区直接停在 predicted-options；再不行切 control-surface 摘要画面。

### D6 删除即失忆（2:26-2:44，18s，信任红线）

- **操作**：① 留在理解页，选中一条**专用牺牲记忆**（录制前预造一条"可删"条目，正式数据不动）→ ② 点删除 → 确认弹窗 → ③ 回到对话，输入相关话题验证不再记得（如删偏好后问一个会被该偏好影响的问题）。
- **口播**（65 字 / 18s）：
  「理解之外，还有控制权。我删掉这条记忆——确认。删了，就是真的删了，版本化机制保证它不会'偷偷想起来'。回到对话验证——它，确实不记得了。」
- **录屏注意**：**路径尚未 UI 级实测**（盘点只有 forget API 200 的 API 级证据），录制日前必须用 demo 账号在真机/模拟器上实删一条走通全 UI 路径并掐表（超 18s 则台词拆两段覆盖）。删除是真实数据变更，牺牲记忆删了不可恢复——录坏重造即可，别删正式展示数据。
- **风险备选**：若 UI 删除路径不通 → 降级为理解页内"修改/纠错"操作演示（同页可录）；保底切后台日志画面（revoke + 检索硬过滤记录）+ 台词不变。

### D7 主动提醒（2:44-2:55，11s）

- **操作（录制日现场二选一，按可行性排序）**：
  - **方案 B（首选，需现场验证）**：录制前把「离散数学期末复习」的 deadline 改到当晚 → 等管线触发 → 实拍 live 通知弹出。注意 P-01 默认 shadow 模式（只记录不真发），**能否出 live 通知必须录制日提前半天实测**；若可切出真实通知，这是最有说服力的画面。
  - **方案 A（保底可行）**：拍 metrics 可观测画面——Prometheus 计数器 `PROACTIVE_PIPELINE_DECISIONS_TOTAL` 或 uvicorn 日志中管线决策记录 + `/dashboard/status` 画面，配台词讲"决策在后台持续运行、六层抑制"。
- **口播**（34 字 / 11s）：
  「它平时不刷存在感；但考试临近，它会主动开口。每一次触达，都有据可依。」
- **录屏注意**：方案 B 若采用，通知横幅出现时机不可控——录 30s 素材剪辑截取弹出瞬间；方案 A 的终端画面调大字号、只框选相关日志行。
- **风险备选**：方案 B 触发不出 → 直接切方案 A 素材（录制日同时备好两套）；两套都不行的极端情况 → 删掉本镜头，11s 还给 D8 慢镜头 + S4。

## 5. 录制日检查清单（开工顺序执行）

1. **服务健康**：三层全活（:8080/:8000/:50051）+ Docker（db/redis/minio）+ Celery worker 在跑 + 队列深度正常（验证员运维口径）。

7. **环境洁净**：勿扰开启、通知清空、充电线藏好（真机）、宿主通知关闭（模拟器）；录屏分辨率/帧率统一 1080p/30fps。
8. **收工**：按仓库磁盘纪律清理当次构建产物与临时进程；演示数据（库内）保留，不清理。
