## 2. 核心演示流程（S3 细化，2:40 内完成）

演示人设：备考离散数学的大二学生（贴评委认知，数据可提前造好）。

| # | 操作 | 展示点 | 台词草稿 | 时长 |
|---|---|---|---|---|
| D1 | 登录进入首页 | 产品门面/信息架构 | "打开 Sparkle，我的学习主页" | 10s |
| D2 | 对话求助："图论完全跟不上，下周就考试了" | 首次对话能力+阶段反馈 | "我先说出我的困境——不用组织完美的问题，像跟学长说话一样" | 25s |
| D3 | 上传一份课程资料 → 再问知识点 | **带引用回答**：回答旁标注 [S1]，点开可看原文出处 | "它基于我的资料回答，而且每句话都标了出处——AI 不瞎编，这在学习场景是底线" | 35s |
| D4 | 转场"三天后"，再开对话 | **记忆流**：AI 记得上次的困境与进度，接着聊不用重新解释 | "三天后我回来——它记得我卡在图论，记得我的复习节奏。这是记忆流引擎：每一次对话都在构建它对我的理解" | 30s |
| D5 | 打开 Aurora"Sparkle 对我的理解" | **画像可视化**（全场 wow 点）：知识状态/偏好/成长轨迹一屏 | "这是 Sparkle 眼中的我——不是模糊印象，是可解释、可校准的理解。我能纠正它、删除它记住的东西——删了就是真的删了" | 35s |
| D6 | 演示一次删除记忆→回到对话确认不再影响 | **删除即失忆**（信任红线，差异化最强） | "我说忘掉，它就真的忘掉——版本化缓存保证不会偷偷想起来" | 20s |
| D7 | 收到一条主动提醒（基于 deadline） | 事件驱动主动式 | "它不刷存在感，但在我真正需要的时候出现" | 15s |
| D8 | 成长星系图收尾 | 长期成长可视化 | "每一次学习都变成星系里的一颗星——这是 Sparkle 给我的、看得见的成长" | 20s |

风险项：D6 删除演示若 UI 路径长可降级为 Aurora 页内操作；D7 需提前造好触发条件（deadline 临近）；全部依赖盘点员回包确认链路。

## 3. 技术段台词（S4，三个壁垒一句话版）

1. **记忆流闭环**："从记忆的写入、校准、纠错到删除，全生命周期版本化管理——用户对 AI 记忆有完全的控制权，这是隐私信任的工程基础。"
2. **可验证引用**："每个基于材料的回答都携带可点击的证据锚点，检索、引用、支撑三级记录可审计——把 AI 回答从'信不信'变成'可验证'。"
3. **确定性智能**："北极星指标全部来自确定性 SQL 聚合，不让模型算数字；主动式触达由事件驱动加六层抑制链，杜绝骚扰。"
