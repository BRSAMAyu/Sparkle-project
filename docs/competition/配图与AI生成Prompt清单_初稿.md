## 使用原则

本清单服务于四份参赛 Word 成稿，目标不是“图多”，而是“图能得分、图能帮助评委理解”。

配图策略固定如下：

1. AI 概念图负责封面、场景、飞轮、定位矩阵、系统隐喻和品牌记忆点。
2. 手工图/真实图负责系统架构图、数据流图、数据库 ER 图、测试图、性能图和真实 UI 页面。
3. Word 正文中只保留图号、图题、图位和图说，不在正文直接塞长 prompt。
4. 所有 AI 图默认采用“白底或极浅背景 + 蓝橙灰主色 + 正式竞赛文档风格”，避免互联网海报感和花哨插画感。

统一禁用项：

- 不要卡通风。
- 不要二次元角色。
- 不要复杂霓虹背景。
- 不要夸张 3D 科幻大厅。
- 不要大面积深色背景。
- 不要加入与产品无关的人物特写。
- 不要塞入过多英文营销文案。

## 6 落图建议

1. 封面页优先使用 S1 或 S2，不叠太多文案。
2. 每份 Word 正文建议保留 2 到 4 张关键图，不要把文档做成图册。
3. 概念图放在章节开头或关键结论后，系统图放在技术解释最密集的位置。
4. UI 真实截图优先放在开发文档与最终演示材料中，不建议在设计报告中过多占版面。
5. 测试和性能类图尽量用真实数据图或手工图，不建议用 AI 生成代替。
