# Sparkle UI/UX 全面打磨方案 v1.0 Final

> **状态**: 已定稿 | **日期**: 2026-05-07 | **范围**: Phase 0–7
> **Phase 0–1 已完成** | **Phase 2–7 待执行**

---

## 总体目标

Sparkle 最终要呈现为一个"安静、温暖、有质感、可信赖"的成长型应用。它不应该像工具箱一样冰冷，也不应该像营销页一样炫技。用户打开它时，应感觉界面在轻轻接住自己：层次清楚、反馈细腻、阅读舒服、动效克制，每个状态都有回应，但没有任何多余打扰。

核心体验关键词：

- **温暖**：浅色模式偏柔和暖底，深色模式偏深邃但不压抑。
- **清晰**：颜色、层级、间距、排版都有统一规则，不靠临时调色。
- **克制**：动效服务于理解，不制造焦虑。
- **可靠**：错误、空状态、加载、网络失败都有明确反馈。
- **成长感**：任务、成就、进度、专注等关键瞬间有轻微仪式感。

## Phase 0：设计系统根基 ✅ 已完成

最终效果：全应用像由同一个设计系统长出来，而不是多个历史版本拼在一起。

执行标准：

- 全局只允许一个权威 `SparkleColors`，所有 UI 颜色必须通过语义 token 或 `context.colors` 获取。
- 不允许页面直接硬编码品牌色、任务色、背景色，除非是一次性插图或第三方图像适配。
- 旧蓝紫色板必须废弃，仅允许保留兼容入口，不作为新代码来源。
- 任务类型颜色应作为任务语义 token 融入主题体系，不再和通用 UI 色板争夺 `SparkleColors` 名称。
- 间距体系统一：`md = 16pt`，`sm = 8pt`，`xs = 4pt`，需要 12pt 时使用 `8 + 4` 的组合语义。
- 所有旧 `GlassCard` 表现统一迁移为标准卡片材质，玻璃感通过材料 token 表达，不再保留独立包装器。

验收标准：

- 搜索全局，不应存在多个不同定义的 `SparkleColors`。
- 新增 UI 不应 import 已废弃色板。
- 主要页面的间距看起来稳定一致，不出现 12/16 混乱造成的"卡片忽远忽近"。

## Phase 1：颜色与主题 ✅ 已完成

最终效果：浅色模式温暖、干净、亲近；深色模式有明确深浅层级，不糊成一片。切换主题时应像环境光变化，而不是屏幕瞬间翻页。

执行标准：

- 深色背景层级必须清楚：Ambient 最深，Primary 次之，Secondary 用于内容卡片，Tertiary 用于更高层容器或强调区。
- 深色卡片不能只靠阴影表达层级，必须使用低噪声边框或材质 rim light 表达轮廓。
- 暗色 glass/obsidian 材质的高光应带极弱品牌色，而不是纯白发亮。
- 浅色模式整体保持暖米色/陶瓷质感，冷蓝色只能作为辅助，不允许突兀压过暖底。
- `brandSecondary`、用户聊天气泡、信息色要保持冷暖协调。
- 高对比模式不是只换颜色：输入框、描边按钮、checkbox、focus ring、正文权重都要更清晰。
- 主题切换必须有不超过 300ms 的平滑过渡，并触发轻触觉反馈。

验收标准：

- 深色模式肉眼能分辨页面底、普通卡片、高层卡片。
- 浅色模式下蓝色按钮/气泡不显得"塑料感"或漂浮。
- 主题切换无闪白、闪黑、瞬间跳变。
- 高对比模式下输入框 focus 状态非常明确。

## Phase 2：字体排版

最终效果：中文阅读更舒展，标题和正文层级更明确。长文本不压迫，短标签不松散。

执行标准：

- 中文字体 fallback 顺序必须优先覆盖 iOS、Android、国产 Android 常见字体。
- 正文中文行高应偏舒适：大正文约 1.65-1.7，中正文约 1.6，小正文约 1.5。
- 标题行高要紧凑但不挤，避免中文标题上下贴边。
- `headingLarge / headingMedium / titleLarge` 必须有字重差异，不能全部 w600。
- `titleLarge` 更像温和小标题，`headingMedium` 才是结构标题。
- 全局字体缩放允许用户辅助需求，但上限控制在 1.35x，避免小屏布局崩坏。
- 关键数字，如计时器、进度、统计值，应使用等宽数字，避免跳动。

验收标准：

- 中文长消息连续阅读 3 屏不觉得拥挤。
- 1.35x 字体下主要按钮、卡片标题、导航栏不截断。
- 标题层级不用颜色也能看出主次。

## Phase 3：动效与触觉

最终效果：界面有生命感，但安静。动效让状态变化更容易理解，不抢注意力。

执行标准：

- 所有普通状态动画控制在 150-300ms。
- 页面级转场可到 260-320ms，但不能超过 400ms。
- loading skeleton 可以持续循环，但必须柔和，不刺眼。
- 列表入场动画应前几项快、后几项自然减弱，总延迟不超过 200ms。
- AttentionPulse 全局同时最多 2 个，超过后降级为静态高亮。
- 按钮点击使用轻触觉，tab 切换使用 selection，成功完成任务使用 success，删除/危险操作使用 warning。
- 成就、里程碑、连续打卡可以有更强反馈，但必须只在真正达成时触发。

验收标准：

- 快速操作 10 次不会感觉界面"抖"。
- 页面首次进入有轻微秩序感，但不拖慢使用。
- 触觉反馈能区分"普通点击、选择、成功、警告、成就"。

## Phase 4：核心屏幕

最终效果：最高频路径先变好，用户每天看到的地方最精致。

Chat Screen：

- 用户气泡和 AI 气泡必须有方向感知圆角。
- 用户气泡文字对比度达到 WCAG AA。
- 输入框 focus 必须有清楚但温和的品牌边框变化。
- 消息发送、送达、已读状态变化要有轻微图标过渡。
- 长消息展开/收起必须平滑，不能瞬间撑开。
- AI thinking 动效要克制，不能和 AttentionPulse 叠加造成焦虑。

Dashboard：

- 卡片间距严格遵守 DS 间距体系。
- 首屏卡片入场使用统一 stagger。
- 今日任务、目标进度、状态卡必须使用语义色，不允许临时色。
- 进度条数值变化要有轻微 count/tween 反馈。
- 问候区应根据早中晚有非常轻的氛围变化，但不能变成装饰大 banner。

Goal Creation：

- 步骤切换要稳定，用户知道自己处在哪一步。
- 继续按钮出现时轻微上滑，不突兀。
- 字数限制提示应从弱提示到警告再到错误逐级变化。

Achievement：

- 新成就才触发庆祝动画，历史成就不重复轰炸。
- 稀有度视觉要分层，legendary 可有 glow，但必须短暂。
- streak 数字、里程碑、奖章出现要有轻微仪式感。

Focus / Mindfulness：

- 专注模式进入应是沉浸式淡入，不使用普通侧滑。
- 计时数字必须稳定不跳宽。
- 背景使用主题里的 galaxy/mindfulness 语义色，不固定写死。

## Phase 5：状态与组件细节

最终效果：用户不会遇到"空白、不知道发生了什么、不知道怎么恢复"的状态。

执行标准：

- Empty State：图标 64pt，使用 textSecondary；标题用 titleLarge；描述最多 2 行；CTA 距离描述 24pt。
- Snackbar：成功、错误、警告、信息必须有颜色条和图标区分。
- 成功 Snackbar 约 2500ms，错误约 4000ms。
- 网络错误卡必须有重试按钮，点击后进入 loading，禁止重复点击。
- Bottom Sheet 必须统一顶部圆角、drag handle、遮罩透明度和进退场时长。
- 底部导航 active/inactive 图标状态要明显，badge 超过 9 显示 `9+`。
- 下拉刷新必须使用品牌色 Sparkle 自定义 indicator。

验收标准：

- 任意主要页面断网时都有明确恢复路径。
- 所有 bottom sheet 看起来来自同一套系统。
- Snackbar 不靠文字也能快速识别状态类型。

## Phase 6：明暗模式一致性

最终效果：同一页面在浅色和深色下都成立，不是简单反色。

执行标准：

- 深色模式下亮图需要轻微降亮，避免刺眼。
- SVG/插图不能有硬编码白底。
- 暗色卡片优先用边框和材质表达层级，不依赖不可见阴影。
- 品牌主色在暗色背景上必须满足文字/关键图标对比度。
- 情绪低刺激模式在暗色下应降低整体亮度，不制造偏绿/偏脏色温。

验收标准：

- 每个核心屏幕都做 light/dark parity 截图检查。
- 暗色下无刺眼白块，浅色下无发灰脏块。
- 品牌色在两种模式下都可读、不过度饱和。

## Phase 7：性能与流畅度

最终效果：高端机有质感，中端机稳定，低端机不掉帧。降级后仍然好看。

执行标准：

- 高性能设备允许 blur、noise、glow。
- 中端设备禁用重 blur 时，应使用纯色 surface + 细边框模拟质感。
- 低端设备应减少阴影和复杂动画，用边框表达层级。
- Skeleton、shimmer、持续动画必须隔离重绘区域。
- 路由动画在低性能档可降级为更简单转场。
- 所有交互动画优先保证 60fps，而不是追求复杂视觉。

验收标准：

- iPhone SE 小屏无溢出。
- iPad 大屏不空、不散、不像手机界面被拉宽。
- 低性能档仍然有清楚层级，不出现"裸 UI"。

## 最终总验收清单

- 浅色/深色主要文字对比度 ≥ 4.5:1。
- 深色层级清楚：Ambient < Primary < Secondary < Tertiary。
- 主题切换 ≤ 300ms，无闪屏。
- 常规动效 ≤ 300ms，所有动效 ≤ 400ms，skeleton 除外。
- 字体缩放 1.35x 不破坏主流程布局。
- 主要屏幕都有 loading、empty、error 三态。
- 所有关键交互有合适触觉反馈。
- 所有 Bottom Sheet 统一 drag handle、圆角、遮罩、进退场。
- 所有 Snackbar 有图标、颜色编码和合理展示时长。
- 核心屏幕必须分别通过 iPhone SE、标准 iPhone、iPad 三档视觉检查。
