### 新功能 Error 处理问题

`scenario_pack_service.dart` 的 4 个方法 **全部静默吞没异常**：

```dart
catch (_) { return const []; }      // listPacks
catch (_) { return null; }           // getPack
catch (_) { return false; }          // assignPack
catch (_) { return const JourneyProgress(); }  // getProgress
```

这是 P1 级别问题——当网络失败时，用户看不到任何错误提示，pack 列表悄无声息地变为空。
