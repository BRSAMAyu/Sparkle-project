## Design

### Data model

`CommunityStrategy` — simple class (no JSON serialization needed for v1):
- `title` (String) — strategy name
- `description` (String) — what the strategy entails
- `strategyType` (String) — e.g. 'accountability', 'sprint_group', 'friend_match'
- `icon` (IconData) — visual indicator
- `actionLabel` (String) — call-to-action button text
- `onAction` (VoidCallback?) — tap handler

### Widget

`CommunityStrategyCard` — ConsumerWidget displaying a single strategy recommendation.
Follows pattern from SimilarGoalPursuersCard + GroupRecommendationCard.

### Integration

Exported via `community.dart` barrel. Available for community main screen or dashboard slot.
Integration point: community_screen or dashboard community slot (TBD by product).

### i18n

Follows `isChinese ? '中文' : 'English'` pattern (not ARB — claude-A handles ARB migration).
