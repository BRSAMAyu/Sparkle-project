# Sparkle (星火) 项目全链路验收文档 (Final Acceptance Criteria)

本方案覆盖了从移动端 UI/UX 到后端微服务架构的完整链路，旨在确保 "Luminous Cognition" 版本的所有功能点达到生产级标准。

---

## 1. 用户认证与账户体系 (Authentication)
| 功能点 | 验收标准 | 验证状态 |
| :--- | :--- | :--- |
| **注册/登录** | 支持邮箱注册、JWT 签发；登录后 Token 自动持久化。 | [ ] |
| **安全退出** | 退出后清除本地缓存 (Hive) 和 Sensitive Data。 | [ ] |
| **Token 刷新** | 拦截 401 错误并尝试静默刷新或重定向登录。 | [ ] |
| **多端一致性** | 同一账号在不同模拟器/设备上的数据基础信息一致。 | [ ] |

## 2. 知识星系 (Knowledge Galaxy) - 核心视觉与逻辑
| 功能点 | 验收标准 | 验证状态 |
| :--- | :--- | :--- |
| **Galaxy 渲染** | 节点具备 Solid Core + Blur Halo 效果；背景具备星空视差。 | [ ] |
| **节点点火 (Spark)** | 点击节点展示详细信息；学习 2 次后触发 Spark 动画。 | [ ] |
| **自动扩展 (Expansion)** | 后端 `ExpansionWorker` 成功异步生成新节点；前端通过 SSE 实时更新。 | [ ] |
| **Luminous 视觉系统** | 使用 `SparkleMaterial` 和 `NeoGlass` 材质；性能自适应（PerformanceService）。 | [ ] |
| **交互性能** | 缩放、平移 Galaxy 视图时，主流设备帧率保持在 55-60 FPS。 | [ ] |

## 3. AI 交互与认知系统 (Cognitive & Chat)
| 功能点 | 验收标准 | 验证状态 |
| :--- | :--- | :--- |
| **OmniBar 对话** | 支持流式输出 (Stream)；UI 能够实时渲染 Markdown 格式。 | [ ] |
| **Prism 思维三棱镜** | 能够对当前学习状态进行多维度分析（深思/发散/归纳）。 | [ ] |
| **Focus-to-Prism 反射** | 在 Focus Mode 结束后，自动生成 Prism 总结建议。 | [ ] |
| **Reasoning 动效** | 对话生成过程中具备 Shimmer 闪烁动效，体现“思考中”状态。 | [ ] |
| **STT 指令** | 语音输入能够准确识别并转化为任务或对话文本。 | [ ] |

## 4. 任务管理 (Sprint & Focus)
| 功能点 | 验收标准 | 验证状态 |
| :--- | :--- | :--- |
| **任务全生命周期** | 创建、编辑、归档、删除功能正常；状态同步至后端。 | [ ] |
| **智能任务解析** | 后端 `/tasks/suggestions` 根据对话内容自动提取标题和截止日期。 | [ ] |
| **Focus Mode** | 计时器精准；支持背景运行通知；专注结束后的数据记录。 | [ ] |
| **任务关联** | 任务完成时，其关联的 Knowledge Node 活跃度 (Intensity) 提升。 | [ ] |

## 5. 架构质量与数据可靠性 (Data & Infra)
| 功能点 | 验收标准 | 验证状态 |
| :--- | :--- | :--- |
| **数据同步 (Sync)** | 离线创建的任务在恢复网络后通过 `SyncCognitiveRepository` 自动同步。 | [ ] |
| **离线支持** | 核心数据 (Nodes/Tasks) 缓存于 Hive；离线模式下 UI 正常展示。 | [ ] |
| **文件处理** | 支持图片/PDF 上传；网关具备 Rate Limiting 防护；具备 GC 清理。 | [ ] |
| **后端健壮性** | Python 服务与 Go Gateway 之间的 gRPC 通信具备重试机制。 | [ ] |

## 6. 非功能性需求 (Non-Functional)
| 功能点 | 验收标准 | 验证状态 |
| :--- | :--- | :--- |
| **性能自适应** | 开启节电模式或低端设备时，Galaxy 动画复杂度自动降低。 | [ ] |
| **安全性** | API 日志中不含明文密码；敏感 API 接口具备 Token 校验。 | [ ] |
| **错误处理** | 移动端具备全局 Error Boundary；后端崩溃不影响网关基础可用性。 | [ ] |
| **构建质量** | Flutter 静态代码检查无 Warning；后端单元测试通过率 100%。 | [ ] |
