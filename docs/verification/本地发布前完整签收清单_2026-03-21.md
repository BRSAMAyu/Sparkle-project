## 1. 当前宏观判断

当前状态不建议直接进入服务器部署和远程真机联调。

原因不是“系统主链不通”，而是“本地还没有完成最后一层发布前签收”：

- 大部分核心后端链路已打通
- 多数关键前端入口已补齐
- 但仍有部分模块停留在“真实 API 已通 / 编译通过 / 局部模拟通过”
- 还缺少系统性的模拟器点击签收、真机能力签收、性能基线签收、从零启动演练

当前建议顺序：

1. 先完成本地发布前签收
2. 再做部署准备与部署脚本收口
3. 最后做远程真机联调

---

## 2. 状态标记

- `PASS`：真实用户链路可完成，体验可接受，可进入下一阶段
- `PARTIAL`：主链可用，但仍有明显体验/边界/签收缺口
- `FAIL`：主链不可用或高概率误导用户
- `PENDING`：本轮尚未实际验收

建议额外记录：

- `证据`：接口返回、日志、截图、录屏、模拟器路径
- `责任人`：谁来修、谁来复验
- `下一步`：如果不是 `PASS`，明确还差什么

## 3. 出场门槛

- `门槛 C`：性能与稳定性基线无红项
