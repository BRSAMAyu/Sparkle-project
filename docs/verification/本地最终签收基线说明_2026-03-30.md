## 2. 推荐启动顺序

按以下顺序执行，不要跳步：

1. 基础设施
   - `docker compose up -d sparkle_db redis minio`
2. 后端依赖自检
   - `make env-check`
   - `make local-signoff-preflight`
3. 后端服务
   - Python gRPC `50051`
   - Python API `8000`
   - Go Gateway `8080`
4. 后端最小健康验证
   - `make smoke`
5. 演示/验收基线数据
   - `cd backend && ./.venv/bin/python scripts/seed_demo_user_enhanced.py`
6. Flutter 客户端
   - iOS / Android 模拟器启动
   - `flutter run`

关键原则：

- 先确认有效配置和端口，再相信服务状态
- 先确认 `8000/8080` 健康，再进入模拟器
- 先补 demo 基线数据，再做成就/视觉/社群/星图人工点击
- 本地默认数据库基线统一为 `127.0.0.1:5432`；若因端口冲突改动，必须同步更新仓库根 `.env`、`backend/.env`、`backend/gateway/.env`

## 3. 自检与 Smoke

### 3.1 统一自检

新增入口：

- `make local-signoff-preflight`

它会实际检查：

- 当前有效 `DATABASE_URL / REDIS_URL`
- 配置中的 PostgreSQL / Redis 端口是否真在监听
- `8000 / 8080 / health/cqrs` 是否可用
- `alembic current` 是否在 `head`
- `user_learning_profiles` 是否存在
- `idx:knowledge` 是否存在
- `node_relations` 中是否已有 `prerequisite` 基线

这一步通过后，才适合做最终人工签收。

### 3.2 最终 smoke 组合

新增入口：

- `make local-final-signoff`

它会跑：

- `make local-signoff-preflight`
- `make smoke`
- `cd backend/gateway && go test ./internal/handler ./internal/middleware`
- `ai_chat_multiturn_acceptance.py`
- `accountability_acceptance.py`
- `galaxy_plan_acceptance.py`
- `achievement_visual_acceptance.py`
- `seed_library_acceptance.py`
- `insights_acceptance.py`
- `cognitive_capsule_acceptance.py`
- 阶段 1 关键 Flutter 回归

建议在你每次“重拉环境后准备签收”时跑一遍。

补充说明：

- 如果本机 `6379` 上跑的是普通 Redis 而不是 Redis Stack，`local-signoff-preflight` 会给出 `redis_search_index` 的 `WARN`
- 这代表知识检索会走代码内建的降级路径，不再视为“阻断最终签收”的失败项
- `ai_chat_multiturn_acceptance.py` 现在会把外部模型偶发慢响应记为 `latency_warnings`
- 只有链路失败、无响应、空白、历史会话异常、卡片承接失败等真实功能问题才会阻断 `make local-final-signoff`

## 4. 双端人工点击基线

### 4.1 iOS / Android 都要点的核心主链

1. 访客进入
   - 预期：能进入首页，不报错，不白屏
2. 首页主壳切换
   - 首页 / 星图 / 对话 / 社群 / 我的
   - 预期：切换无明显卡顿，无长时间 skeleton
3. AI 对话
   - 发送消息
   - 查看历史对话
   - 切回当前会话
   - 点击任务卡 / 计划卡 / 学习路径卡 / 星图卡
   - 预期：不空白、不假成功、不误跳
4. 社群 / 责任伙伴
   - 进入工作台
   - 接受 / 拒绝邀请
   - 打卡 / 点赞 / 鼓励
   - 预期：状态刷新正常，落到真实工作台
5. 星图 / 学习路径
   - 打开节点详情
   - 生成候选节点
   - 生成学习路径
   - 生成任务卡并回流任务系统
6. 视觉元素
   - 推荐 / 全部 / 已解锁切换
   - 小屏滚动
   - 默认素材加载
   - 预期：不溢出、不空白、不因用户不同而内容消失

## 5. 若失败先看哪里

### 5.1 访客登录异常

优先检查：

- `make env-check`
- `make local-signoff-preflight`
- `DATABASE_URL` 指向的端口是否真在监听
- `8000` 和 `8080` 是否都健康
- 是否存在“根目录是 5432，但子目录 .env 还是 5433”的配置漂移

### 5.2 星图 / 学习路径失败

优先检查：

- `local-signoff-preflight` 是否通过 `knowledge_prerequisite_baseline`
- `galaxy_plan_acceptance.py` 是否通过

### 5.3 成就 / 视觉元素失败

优先检查：

- `seed_demo_user_enhanced.py` 是否已执行
- `achievement_visual_acceptance.py` 是否通过

### 5.4 页面切换或返回迟滞

优先检查：

- 是否是 Debug 模式
- 是否冷启动后立刻首轮进入页面
- 当前是否有旧的 Flutter runner / 模拟器残留进程

- 现在文档里不应再保留“已知代码断链项”
