## ✅ 实际存在的实现

### 1) 后端（Python）
- `backend/app/scaffolding/`：ScaffoldingFSM + CapabilityTracker + IntentGenerator
- `backend/app/services/template_registry.py` / `template_service.py`
- `backend/config/intervention_templates.yaml`（中文模板库）
- 新接口：`POST /api/v1/interventions/request`
- 反馈：`POST /api/v1/interventions/requests/{id}/feedback`
- 被动信号：`POST /api/v1/interventions/passive-signals`
- 行为结果：`POST /api/v1/interventions/outcomes`

### 2) 网关（Go）
- WebSocket 连接追踪 + `PushIntervention` 实现
- 内部推送接口：`POST /internal/interventions/push`
- `/api/v1/interventions/*` 代理到后端

### 3) 协议（Proto）
- `proto/websocket.proto` 新增 `InterventionPushMessage` 等消息
- Go/Python/Dart 代码已生成

### 4) 移动端（Flutter）
- WebSocket 处理 `intervention_push`
- Overlay 组件：`toast_intervention.dart` / `card_intervention.dart` / `modal_intervention.dart`
- Offline 队列：`SyncEngine` 新增干预请求/反馈/被动信号通道
- EdgeStateMonitor 引入 EdgeInferenceService 融合
