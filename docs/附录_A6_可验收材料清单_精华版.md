## 四、接口与模块清单

### 4.1 REST API（20+端点）

| 分类 | 端点示例 |
|------|---------|
| **健康检查** | `GET /health`, `GET /metrics` |
| **认证** | `POST /auth/google`, `POST /auth/wechat` |
| **用户** | `GET /users/:id`, `PUT /users/:id/preferences` |
| **计划** | `GET/POST /plans`, `POST /plans/:id/review` |
| **任务** | `GET/POST /tasks`, `POST /tasks/:id/complete` |
| **知识** | `GET /galaxy/nodes`, `PUT /galaxy/nodes/:id/mastery` |
| **社群** | `GET/POST /community/groups` |

### 4.2 WebSocket（5个端点）

| 端点 | 用途 |
|------|------|
| `/ws/chat` | AI对话流式响应（打字机效果） |
| `/ws/files` | 文件传输 |
| `/ws/stt` | 语音识别 |
| `/community/:id/ws` | 社群实时聊天 |

### 4.3 gRPC服务（3个proto）

| 服务 | RPC方法 |
|------|--------|
| **AgentService** | `StreamChat`（流式对话）<br>`SubmitPlanReview`（计划评审） |
| **GalaxyService** | `QueryKnowledgeGraph`（知识图谱）<br>`UpdateNodeMastery`（掌握度更新） |
| **ErrorBookService** | `CreateErrorRecord`（创建错题）<br>`GenerateReviewPlan`（复习计划） |

### 4.4 核心模块（14个）

| 层级 | 模块 | 技术栈 | 职责 |
|------|------|--------|------|
| **网关层** | Go Gateway | Go + Gin | WebSocket路由、认证、限流 |
| **编排层** | Orchestrator | Python + LangGraph | AI编排、状态机、工具调度 |
| **引擎层** | RAG Engine | Python + pgvector | 向量+图谱混合检索 |
| | Cognitive Engine | Python | 认知分析、画像更新 |
| | Tool Registry | Python | 工具注册、三层验证 |
| **客户端** | Chat Service | Dart + WebSocket | 对话UI、流式响应 |
| | Task Service | Dart | 任务管理、番茄钟 |
| | Galaxy Service | Dart + Shader | 星图可视化 |
| | Plan Service | Dart | 计划管理、评审UI |
| | Community Service | Dart | 社群、实时聊天 |
| | Focus Service | Dart | 专注模式、星空动画 |
