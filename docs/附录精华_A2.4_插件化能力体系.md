### 1.2 工具 Schema 示例

**示例：create_task 工具**

```python
# 工具定义
class CreateTaskTool(BaseTool):
    name = "create_task"
    description = "创建一个新的学习任务卡片"
    category = ToolCategory.TASK
    parameters_schema = CreateTaskParams  # Pydantic BaseModel

# 参数 Schema
class CreateTaskParams(BaseModel):
    title: str                    # 任务标题
    task_type: TaskTypeEnum        # 任务类型
    estimated_minutes: int         # 预估时间 (5-180分钟)
    priority: int                 # 优先级 (1=高, 2=中, 3=低)
    due_date: datetime | None      # 截止时间
    description: str | None        # 任务描述

# 输出格式
ToolResult(
    success=True,
    widget_type="task_card",       # 前端渲染类型
    widget_data={...}              # TaskCard 数据
)
```

## 二、新增工具流程（5分钟快速演示）

**目标**：从零创建新工具到上线使用

### Step 1: 创建工具类 (2分钟)

```python
# weather_tool.py
class WeatherTool(BaseTool):
    name = "get_weather"
    description = "查询指定城市的实时天气"
    category = ToolCategory.QUERY
    parameters_schema = WeatherParams

    async def execute(self, params, user_id, db_session, tool_call_id):
        data = fetch_weather(params.city)
        return ToolResult(
            success=True,
            widget_type="weather_card",
            widget_data=data
        )
```

### Step 2: 系统自动发现 (30秒)

```python
# 启动时自动扫描 app.tools 包
dynamic_tool_registry.register_from_package("app.tools", recursive=True)

# 控制台输出:
# ✅ 已注册 14 个工具 (包含新工具 get_weather)
```

### Step 3: LLM 自动获取 Schema (即时)

```python
# LLM 调用时自动获取所有工具的 OpenAI Function Calling Schema
tools_schema = dynamic_tool_registry.get_openai_tools_schema()
# 无需任何手动配置
```

### Step 4: 用户测试 (1分钟)

```
用户: "今天北京的天气怎么样？"
LLM: 自动决策调用 get_weather 工具
系统: 执行工具并渲染 WeatherCardWidget
```

### Step 5: 前端 Widget (可选, 1分钟)

```dart
class WeatherCardWidget extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Card(child: Text("${data['temperature']}°C"));
  }
}
```

**总耗时**: 4分30秒 ✅

## 三、多智能体协作样例

### 3.1 问题拆解 → 分工 → 合并结果

**场景**：`"帮我准备下周的机器学习期末考试"`

**协作工作流**: TaskDecompositionWorkflow

**执行轨迹**：

```
[Step 0] SearchExpert (245ms)
  └─ 检索背景知识: 机器学习考试常见知识点

[Step 1] StudyPlanner (892ms)
  └─ 分析学习状态, 制定整体计划
     ├─ 薄弱点: 梯度下降 (0.45), 反向传播 (0.38)
     ├─ 遗忘风险: SVM (10天未复习), 决策树 (15天)
     └─ 策略: 重点复习算法推导 + 代码实战

[Step 2] 专家并行 (634ms) ← 并行执行
  ├─ MathExpert (567ms): 生成【梯度下降、反向传播】练习
  ├─ CodeExpert (634ms): 设计【SVM、决策树】实战项目
  └─ WritingExpert (423ms): 创建学习笔记模板

[Step 3] Orchestrator (512ms)
  └─ 整合所有专家意见, 生成7天冲刺计划 (21个微任务)

总耗时: 3.2秒 (并行执行)
```

**最终输出**：

```
📚 机器学习期末考试冲刺计划 (7天)

第 1 天: 数学基础复习
  ✅ 复习梯度下降理论 (2小时) - MathExpert
  ✅ 反向传播算法 (1小时) - MathExpert

第 2 天: 算法实现
  ✅ 从零实现 SVM (2小时) - CodeExpert
  ✅ 决策树与集成学习 (1小时) - CodeExpert

... (后续 5 天)

📊 学习资料包:
  - 数学练习题集 (MathExpert)
  - 代码实战项目 (CodeExpert)
  - 学习笔记模板 (WritingExpert)
```

### 3.2 协作模式对比

| 协作模式 | 适用场景 | 参与智能体 |
|---------|---------|----------|
| **TaskDecomposition**<br>任务分解 | 复杂目标拆解<br>学习计划制定 | StudyPlanner<br>+ 专家并行<br>+ Orchestrator |
| **ProgressiveExploration**<br>渐进式探索 | 深入理解概念<br>知识体系构建 | SearchAgent<br>+ SubjectExpert<br>+ ConceptAnalyst |
| **ErrorDiagnosis**<br>错误诊断 | 错题分析<br>薄弱点诊断 | ErrorAnalyzer<br>+ RootCauseExpert<br>+ RemediationPlanner |

### 4.2 扩展效率对比
