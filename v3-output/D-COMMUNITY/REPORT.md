## ② 对标要点（来源链接在 DESIGN.md §2）

- **Duolingo**：30 人随机小池 + 周期重置可取；XP 刷分/作弊/榜底挫败是反面教材 → 榜分禁用行为量。
- **排行榜心理学**（Werbach & Hunter / 微积分实验 / BJET 2025 元分析）：榜只激励「接近上一名」者、异质竞争负效应、排行榜提分不提动机 → 只做同质小队榜 + 自我锚，全站榜隐藏是对的。
- **Kahoot**：正效应条件 = 同期同步限时局 + 用户自制内容 → 冲刺周限定，错题互助有依据。
- **Forest**：损失厌恶 + 共种临在 + 虚拟币换真实价值（200 万真树）→ 光子兑换 Pro 天数的范式原型；免费/付费奖励梯度是红线雷区。
- 取证申报：WebSearch 周配额 429（2026-09-24 重置），改用 WebFetch 取 Wikipedia 一手页面；B 站自习室条目为通识补充未溯源（DESIGN.md §6 已申报）。

## ③ 推荐组合与理由

**「期末冲刺周」价值包**：冲刺小队（社群）→ 进度双视图（小队完成度榜 + 自我 7 日锚，无 XP/光子分）→ 学出会员（合同/首胜/成就光子按有界汇率兑 Pro 7 天，月顶 1 次，复用 D-REDEEM 原子链路，transfer_in 不计入）。

理由：社群供 cohort（同质同期）、排行榜供健康比较（规避中尾生打击）、光子把冲刺沉淀为次月留存与口碑——三者服务同一个卖点而非三个孤立功能；全程符合 R1 entitlement 独立 / R2 D17 降权 / R3 D18 非公共广场；明确**否决**「光子解锁增值功能」定位（重演 is_pro 派生债 + 刷分诱导）。
