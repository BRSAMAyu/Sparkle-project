## 1. 学习效果代理指标（冻结定义）

记号：pre = 摸底卷 A 分数；post = Day7 模拟考卷 B 分数；retest = Day10 卷 A′ 分数；
T = 总学习投入小时（**含系统交互时间**——交互负担是成本不是免费）。

| # | 指标 | 定义（计算式） | 判定 | 说明 |
|---|---|---|---|---|
| M1 | 同卷提分 | ΔS = post − pre | ΔS ≥ **+15** | 42→57+。+15 为本轮 MDE 定标假设（见 §5 诚实边界），C 线实测后用功效分析重估 |
| M2 | 单位小时提分 | η = ΔS / T | η ≥ **1.5 分/小时** | 7 天 × ~2.75h ≈ 19h；η=1.5 ⇔ ΔS≈28。防「堆时间换分」解释 |
| M3 | 遗忘率 | F = (post − retest) / post | F ≤ **0.2** | 3 天衰减。F 高说明「冲刺分」是短期记忆泡沫；Sparkle 的间隔复习应压低 F |
| M4 | 加权覆盖率 | C = Σ exam_weight(covered∧passed) / Σ exam_weight | C ≥ **0.8**（Day6 末） | covered = 节点出现在计划卡；passed = 该节点 quiz/复习首答 ≥ 及格线 |
| M5 | 复习命中率 | R = 复习题首答对数 / 复习题总数 | R ≥ **0.7**（按日） | 直接反映间隔复习调度质量（遗忘曲线是否真在起作用） |
| M6 | 遗漏点率 | O = 从未被任何卡/quiz/复习覆盖的高频考点数 / 高频考点数 | O ≤ **0.08**（≤2/24） | 裸 Chatbot 无考纲账本，预期显著更差——这是结构性差异不是模型差异 |
| M7 | 认知负担 | NASA-TLX 简化 5 维 7 分量表，日均分 | 日均 ≤ **4.5** 且不逐日攀升（斜率 ≤ 0） | 真人自报，API 级推演 honest-unsupported |
| M8 | 校准误差 | E = mean(|星图 mastery − 模拟考逐节点得分率|) | E ≤ **0.15** | 星图 mastery 若与真实表现脱钩，则「覆盖/掌握」宣称全部失效（联动 GAIN_PROOFS GP-01/03） |
| M9 | 过考概率轨迹 | NorthStarMetrics `exam_pass_probability` 日更序列 | 单调不降且 Day7 ≥ 0.6 | 系统自估必须与实测 post 方向一致，否则判「仪表盘说谎」 |

主判定（北极星成立的最小充分集）：**M1、M2 达标，且 M3 ≤ 对照臂**，且 M6 严于两对照臂。
M4/M5/M8/M9 为机制指标（解释增益来源），M7 为体验护栏（增益不得以认知过载为代价）。

## 2. 对照组协议（三臂同状态）

### 2.1 臂定义

| 臂 | 配置 | 结构性能力 |
|---|---|---|
| A · Sparkle 完整闭环 | 全链路：星图 + 向量索引 + 记忆 + 画像 + 计划闭环 | 考纲账本、间隔复习、错题归因、自适应计划 |
| B · 裸 GPT | 通用 Chatbot（GPT 旗舰模型），仅系统提示「帮我在 7 天内备考大学离散数学期末考」，无任何 Sparkle 组件、无记忆跨 session 承诺 | 无 |
| C · 裸 DeepSeek | 同 B，换 DeepSeek 旗舰模型 | 无 |

**关键控制**：B/C 臂允许用户把课件粘贴给 Chatbot（材料获取公平）；但 B/C 无考纲节点账本、无复习调度、无错题本——这些是**产品结构**差异，正是北极星宣称的来源，不许替对照臂补齐。

### 2.2 同状态与等时间

1. **同起点**：同一 persona 状态（同 pre 分、同材料集、同每日时间窗 165 min）注入三臂；
2. **等时间**：三臂每日墙钟预算相同且超时即停；交互等待时间（打字、粘贴）计入该臂成本；
3. **同判卷**：三臂的 quiz/模考全部用同一确定性判卷器 + 同卷；LLM 只允许出现在「教学讲解」不允许出现在「判分」。

### 2.3 顺序效应控制（两档，按可行性选）

- **N-of-1 交叉（竞赛实测主档）**：同一真人按 ABBA / BAAB 顺序轮换臂，臂间洗脱 ≥ 14 天（换科目：离散→线性代数→概率论，科目 × 臂拉丁方），每臂一份等价卷（A/B/C 卷轮换，卷 × 臂解耦）；
- **小组间（若 ≥ 12 名被试）**：随机分三臂，等价卷，pre/post/retest 同规；报告均值差 + 置信区间，不做单人推断。

### 2.4 比较维度（三臂对照表输出）

| 维度 | 指标 | 预期方向（假设，待证） |
|---|---|---|
| 提分 | M1 ΔS | A > B ≈ C |
| 效率 | M2 η | A > B ≈ C |
| 保持 | M3 F | A < B ≈ C（裸 Chatbot 无间隔复习调度） |
| 遗漏点 | M6 O | A < B ≈ C（无考纲账本 → 结构性遗漏） |
| 认知负担 | M7 TLX | A ≤ B（Sparkle 减少组织成本；若 A 更高则计划系统在添乱） |
| 覆盖 | M4 C | A > B ≈ C |
| 校准 | M8 E | A 达标可判；B/C 无星图 → 该维记 N/A（不惩罚对照臂） |

## 3. 判定与证据规则

1. **主判定不得依赖 LLM-as-judge**：M1–M6、M8、M9 全部由确定性判卷与系统账本导出；M7 是唯一自报项，仅作护栏不作主证据；
2. **重复**：模型路径 case 至少 5 次/关键 case（协议 §3）；本框架中 quiz 抽样与计划生成属模型路径，C 线执行时按 5 次重复报告方差；
3. **每轮证据包**（协议 §5）：git SHA、app build、实际模型、seed/persona、case IDs、原始逐题得分、判卷日志、trace IDs——runner 骨架已按稳定 schema 落 evidence（`write_evidence` 同构 Q-01）；
4. **负结果照常入库**：任一指标反向（如 F(A) > F(B)）必须原样登记进 GAIN_PROOFS 靶子状态，禁止选择性报告。

## 5. 诚实边界

1. M1 的 +15、M2 的 1.5、M3 的 0.2 等阈值是**定标假设**（工程判断），不是统计功效分析的产物；C 线首轮实测后必须重估并在本文档登记版本变更；
2. runner 骨架中的臂效应参数是**假设先验**（hypothesis priors），用于打通测量管线与冒烟，**不构成增益证据**——增益证据只能来自 §2 协议的真实执行；
3. 单科目单 persona 的 N-of-1 结论外推有限；北极星宣称的最终版本必须至少覆盖 3 科目 × 3 persona；
4. 霍桑效应/新鲜度：交叉设计下洗脱期与科目轮换缓解但不消除；报告时必须披露执行顺序。
