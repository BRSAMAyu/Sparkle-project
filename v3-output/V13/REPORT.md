## 二、缺陷清单（按严重度）

### Blocker

**B-01 主聊天消息「发了但看不见」——核心对话闭环断裂（mobile+后端疑似复合）**
- 复现：注册新号 → 完成画像引导 → 建模访谈点「跳过」→ 主聊天发送任意消息（如北极星 prompt）。
- 现象：输入框清空、WS 日志 `📤 Attempting to send message, isConnected: true`，**但消息列表既不显示用户气泡、也不显示 AI 流式回复，亦无任何加载指示**；杀 app 重启后依然缺失。
- 取证（DB，`sparkle_db`）：
  - `chat_messages` 中该用户 2 条 USER「7天后考离散数学，最弱图论，每天2小时」+ 2 条 ASSISTANT「我按你的反馈把策略收紧了一版，你确认后我就开始生成任务卡。」（01:58:13 / 01:59:14）全部落库；
  - **`chat_sessions` 中该用户 0 行**（全表 253 行均属其他用户）——消息引用的 session_id `eec22e1e-…` 无父行，onboarding→chat 路径疑似未建 session 头，UI 历史加载依赖 session → 断链。另：同一条 prompt 因 UI 无反馈被实测员重复发送，**产生重复消息与重复计费回复**（无幂等/去重提示）。
- 影响：北极星主链在第一会话即断——用户永远看不到「确认后生成任务卡」，冲刺无法建立（本卡第 12 步被阻塞的直接原因）。
- 疑似层面：后端（session 行未落）为主因，mobile（发送后无乐观上屏、失败/成功均无反馈）为共因。
- 证据：39, 42, 43, 44, 47, 48, 49。

**B-02 建模访谈多消息回合停摆（引擎/orchestration）**
- 复现：访谈中回答「上过课但没复习，图论的迪杰斯特拉和最小生成树基本忘了」。
- 现象：Aurora 发出「我先把这次 7 天 离散数学 里最影响结果的瓶颈和推进策略整理出来…」后 **50s+ 无后续、无加载指示、无重试入口**，用户唯一出路是「跳过」。引擎无错误日志，疑似流被静默丢弃。
- 影响：新用户第一次深度交互即「被晾着」，跳过后冲刺上下文不完整。
- 证据：33, 34, 35, 36。

### Major

**M-01 `POST /api/v1/profile/onboarding` 服务端耗时 29s，压线 app 30s receiveTimeout——新用户首飞掷硬币**
- curl 实测 `time_total=28.996s`（HTTP 200）；app 内首次调用 30.000s 超时（DioException receive timeout，遥测 event_type=crash）。
- 疑似原因：`first_message` 同步走 LLM 生成，未流式/未缓存。
- 连带缺陷（mobile）：超时后 **无任何用户可见错误反馈**（try/finally 无 catch UI），按钮转圈 30s 后原地复活，用户不知道成功还是失败。
- 疑似层面：引擎（慢）+ mobile（静默）。证据：22, 23, 24；logcat 01:47:54。

**M-02 驾驶舱「本周成长趋势」对新注册用户展示完整 7 天曲线——诚实性红线**
- 账号当天创建、零学习行为，趋势图却有周一至周日完整波动数据（63 周一—周日全点亮）。违反「仪表数字必须有真源、空数据诚实空态」约束。疑似前端造数据/默认曲线。
- 证据：64。

**M-03 光子面无直接入口（API 通但 UI 深埋 3 层）**
- API：`GET /photons/balance`、`GET /photons/redeem-pro/status`（本卡实测均 200，数据结构完整、诚实空态 balance=0 / can_redeem=false）。
- UI：我的页/设置/账户全部无光子或钱包入口；代码唯一链路 `home metrics_row → /achievements → streak_details → context.push('/shop') → PhotonRoutes.redeemPro`（`streak_details_screen.dart:415`、`shop_screen.dart:58`），且新用户驾驶舱空态连 metrics 行都不渲染 → 实际不可达。D 线「光子只经学出会员出口变现」的功能对用户等于不存在。
- 疑似层面：mobile（信息架构）。证据：64, 65, 66。

### Minor

- **D-01 注册页「两次输入的密码不一致」错误提示不随修正消失**：主密码字段修正后错误仍显示（提示只监听确认字段）；提交仍可成功 → 纯视觉陈旧态。证据：13, 14, 15。
- **D-02 回退键在注册页直接丢表单**：键盘收起用系统返回时，第二次返回直接 pop 页面，已填 4 字段全丢（移动端惯例应先收键盘）。证据：08 vs 07。
- **D-03 AI 消息 Markdown 裸奔**：建模访谈首条消息中 `**当前重点**`、`- **具体场景**` 等以原文星号渲染（无 markdown 解析），新用户第一眼观感即破相。证据：25, 26。
- **D-04 控制串泄漏成用户气泡**：`_onboarding_skip_` 以斜体 `onboarding_skip` 显示为用户消息（DB 原始串，UI 未过滤内部控制消息 + markdown 斜体误渲染）。证据：47, 48。
- **D-05 发送消息后列表不自动滚动/不上屏**（B-01 的移动端面）：即使后续消息正常，输入框清空但视口无任何变化，用户无法确认「已发出」。
- **D-06 注册表单必填校验前置缺失**：未勾选两个同意框即可点注册（服务端/提交时才拦），且同意框点击热区随错误条出现而位移，实测多次点不中。证据：11, 12。
- **D-07 登录首屏「还没有账号?」注册入口折叠线以下**，新用户第一屏只见 登录/访客/三方登录。证据：01, 02。
- **D-08 首启即调 `/auth/logout` 吃 401**（无 token 也发请求），噪声遥测+无谓往返。logcat 09:37:53。
- **D-09 注册/引导表单 Enter(IME action) 不跳下一字段**，多字段输入全靠手动点，键盘遮挡下段落字段（确认密码/同意框）极易漏填。证据：09。
- **D-10 星图顶部统计（节点数 296 / 已解锁 2% / 掌握度 尚未开始）被「开始你的第一次学习」引导卡遮压截断**，数字下半被切。证据：51, 52, 55。
- **D-11 星图扇区标签 "Inspiration" 被右侧缩放控件面板截断为 "Inspiratio…"；解锁节点（2%）在星图上不可辨识（全图仅极暗星点）**。证据：55。
- **D-12 星图弹窗「我们从 OS.pdf 里找到了 5 颗知识星」对零上传新用户出现**（种子库数据），且未说明 OS.pdf 从何而来——真实用户会困惑。证据：51。
- **D-13 「创建社群」按钮为默认蓝紫色**，与全站棕色 accent 相悖（A 线 SPEC：唯一交互色）。小队详情页底部「任务/成员/进入聊天/打开知识库」按钮列亦有重叠裁切。证据：57, 60。
- **D-14 开发口吻文案泄漏到用户 UI**：社群入口卡「支持热度、最新、随机发现。这块可以长期收起，不再占用大段空间。」——「这块可以长期收起」是内部实现说明。证据：57。
- **D-15 建模访谈「Aurora 可能会连续发几条，你也可以直接插话」提示后无 typing 指示**（与 B-02 复合，用户无法区分「在想」与「断了」）。证据：33。
