# Competitive Thesis

## 不足以构成差异的能力
- 聊天；
- RAG；
- 长期 Memory；
- 自动任务规划；
- 日历重排；
- Tool use / Agent；
- 主动触发。

这些在 2026 已逐渐成为行业基线。

## Sparkle 要赢的窄问题
> **长期的个人成长目标中，如何在现实不断变化时，让 Human 与 AI 每一步做最合适的事情，并从结果中逐渐学会更好地帮助这个人？**

## 组合 moat
1. Goal trajectory 而非 conversation thread；
2. Experience memory 而非 persona dump；
3. Appropriate memory use 而非 maximum recall；
4. Dynamic human/AI allocation；
5. Action/outcome/knowledge/memory 同一数据闭环；
6. 用户可看到并纠正 AI 对自己的理解；
7. Proactive 有 NO_ACTION 能力；
8. Galaxy 把真实 outcome 转成长期可见成长图；
9. Trustworthy runtime 让 Agent 真正能做事而不撒谎。

## 防御性来源
这不是靠某个 provider/model 的独占。真正积累的是用户在长期使用中产生的：
`context → intervention → outcome` 数据，以及围绕它建立的正确 state/context/action infrastructure。

## 竞争边界
不要宣称通用能力超过通用大模型；争取在 self-directed builder 的 long-horizon goal progress 体验上明显更完整。
