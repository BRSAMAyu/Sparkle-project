# 42 Feature Portfolio — Desired V3 Role

| Feature | V3 role | User job | Product rule |
|---|---|---|---|
| `achievement` | SECONDARY | quietly acknowledge meaningful outcomes | only real outcome events; hidden in low-stimulation |
| `aurora` | CORE | adaptive decision + relationship layer | Why-this/correction/no-action |
| `auth` | CORE | secure low-friction account/session | no profile burden |
| `calendar` | CONTEXTUAL | schedule when time placement matters | not a main destination |
| `chat` | CORE | clarify, collaborate, execute | fast/deep/agent modes |
| `cognitive` | CORE | evidence-based understanding/reflection | no pseudo-psych scores |
| `community` | CORE_OPTIONAL | small-group accountability/artifact feedback | solo product remains complete |
| `document` | CONTEXTUAL | goal material ingestion | source of knowledge, not user memory |
| `documents` | CONTEXTUAL | browse/manage goal materials | contextual surface |
| `error_book` | CONTEXTUAL | turn errors into practice/evidence | root cause is hypothesis |
| `experience` | CONTEXTUAL | surface past helpful interventions/outcomes | not a separate persona system |
| `file` | CONTEXTUAL | artifact/material file operations | permission/version tracked |
| `focus` | CONTEXTUAL | help execute chosen human action | timer is not outcome |
| `galaxy` | CORE | visualize knowledge/outcome trajectory | evidence-aware mastery |
| `goal` | CORE | persistent context for desired outcome | primary organizing object |
| `home` | CORE | answer what matters now | one primary action |
| `insights` | CORE | convert evidence into useful reflection | fact→interpretation→uncertainty→action |
| `intent` | INTERNAL | route/categorize requests | no user-facing destination |
| `knowledge` | CONTEXTUAL | retrieve and use user/external knowledge | separate from memory |
| `leaderboard` | HIDDEN | none for V3 core | do not launch because code exists |
| `memory` | CORE | controlled longitudinal personalization | source/scope/revoke visible |
| `mirofish` | LABS | experimental only if proven | hidden by default |
| `notification_center` | CONTEXTUAL | surface high-value proactive events | burden caps |
| `onboarding` | CORE | reach first meaningful value quickly | progressive profiling |
| `openclaw` | INTERNAL_CAPABILITY | reuse execution/tool capabilities | not a second runtime/user center |
| `photon` | SECONDARY | optional lightweight reward | not entitlement |
| `plan` | CORE | maintain revisable route to goal | plan is mutable, not backlog burden |
| `reflection` | CONTEXTUAL | extract learning after outcome | evidence-bound |
| `report` | CONTEXTUAL | summarize verified progress | facts computed before LLM prose |
| `reviews` | CONTEXTUAL | review artifacts/knowledge/errors | source-linked |
| `seed_library` | LABS | developer/demo seeds | strict namespace |
| `settings` | CORE | privacy/agent/proactive/accessibility control | settings actually affect runtime |
| `shop` | SECONDARY | optional cosmetic/reward | not core, no fake value |
| `simulation` | LABS | experimental learning simulation | hidden by default |
| `splash` | CORE | fast trustworthy startup/recovery | no decorative delay |
| `task` | CORE | concrete action lifecycle | completion evidence |
| `theater` | LABS | experimental visualization | hidden by default |
| `tools` | CONTEXTUAL | capabilities used by Agent/actions | permissioned registry |
| `translation` | CONTEXTUAL | remove language friction for materials | only when needed |
| `user` | CORE | account + reflection/control surface | not another profile truth |
| `visual_elements` | LABS | shared visuals only if design-system owned | experiments hidden |
| `vocabulary` | CONTEXTUAL | practice vocabulary when goal requires | not separate primary app |
