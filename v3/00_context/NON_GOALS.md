# V3 Non-goals / 防跑偏清单

V3 不做以下事情作为成功条件：

1. 用重写技术栈证明“V3 很大”；
2. 新造第二套 User Profile / Memory DB / Agent Runtime / Task truth；
3. 把 42 个模块全部打磨成一级页面；
4. 追求所有历史 lint/mypy 债务归零而牺牲用户价值；
5. 让 RL/contextual bandit 成为 V3 前置；数据不足时先用可解释策略；
6. 大规模训练自有基础模型；
7. 通过隐藏失败、预录结果或 mock 统计制造产品成熟感；
8. 让 Agent 全自动替代学习/判断/创作中的人类 cognitive ownership；
9. 为了“主动”增加通知频率；
10. 为了“社交”建设公共广场；
11. 为了“个性化”在每个回复里提用户历史；
12. 为了“AI 思考”直接展示 chain-of-thought；
13. 把 demo 优化和长期产品基础设施混为一谈；
14. 通过堆更多 animation/particle/gradient 追求第一眼“炫”。
