# Day 0 → Day 14 价值累积模型

## Day 0 — Value before profile
目标：不要求用户“训练 AI”即可得到价值。
产物：1 个 Goal + 1 个 Action + 1 个明确 outcome。

## Day 1–2 — Calibration
系统通过自然发生的选择/纠正收集：
- explicit constraints；
- confirmed preferences；
- accepted/rejected interventions；
- outcome evidence。
不做大问卷。

## Day 3–5 — First Recognition
用户第一次感到“不用重复解释”：相关偏好/经验在正确 scope 被复用，并清楚地给出 why；无关场景保持安静。

## Day 5–7 — Recovery
至少一次计划失效/卡点被恢复。系统价值从“计划工具”升级为“现实变化后的恢复系统”。

## Day 7–10 — Proactive Value
只有达到 relevance threshold 时主动；建议必须比“你有任务没完成”更有信息量，例如根据历史有效 intervention 建议 rescope。

## Day 10–14 — Outcome Identity
用户能看到：
- 做成了什么；
- 哪些知识/能力形成；
- 哪些干预真正帮助；
- Sparkle 当前确认了哪些长期有用的信息。

长期留存的原因应是 **积累的真实 context + outcome + trust**，而不是 streak 恐惧。
