# Human / Agent / Hybrid Allocation

## 1. 为什么是核心能力
AI 能做 ≠ AI 应做。Sparkle 优化的是“人和 AI 如何共同推进一个人的目标”。

## 2. 分配维度
1. **Cognitive Ownership**：此步骤是否本身就是用户想获得的能力/判断/创作？
2. **Tool Advantage**：AI 是否能显著降低机械劳动？
3. **Risk / Irreversibility**：错误代价与撤销性；
4. **Embodiment / Social Presence**：必须由现实中的人完成吗？
5. **Privacy / Authority**：Agent 是否有权限；
6. **Confidence**：系统是否知道足够；
7. **Time/Cost**：让 AI 做是否反而更慢更贵；
8. **User Preference**：用户明确想自己做/委托。

## 3. 默认规则
- 学习、判断、反思、体验、关系沟通 → HUMAN/HYBRID 倾向；
- 检索、整理、格式转换、批处理、低风险工具调用 → AGENT 倾向；
- 论文/创作/项目 → HYBRID 优先；
- irreversible/high-risk → HUMAN approval 必须。

## 4. Hybrid Step
每一步必须有 handoff：
`Agent prepares → Human decides/creates → Agent checks/executes → Outcome`

UI 应清楚显示“现在轮到谁”。

## 5. 评测
使用 scenario set blind review：
- correct execution mode；
- cognitive deskilling risk；
- unnecessary manual work；
- unsafe autonomy；
- handoff clarity。
