# Chat / Aurora Conversation

## Job
Chat 是澄清、理解、协作与执行入口，不是产品全部。

## V3
- 保留 interrupt-preserve；
- 区分快问快答 / decision / agent run；
- deep 路径立即显示真实 stage，不显示 chain-of-thought；
- sources / memory why / proposal diff 可展开；
- action proposal 以卡片进入确认，不藏在长段落；
- model/tool failure 能重试或降级且不假成功；
- 长对话通过 compaction/context compiler 保持高信号。

## UI
聊天气泡减少装饰；工具/执行状态不是“AI 正在思考...”无限 spinner。

## Acceptance
多轮、长文本、中断、附件、断网、恢复、proposal、citation、memory correction 全部 journey。
