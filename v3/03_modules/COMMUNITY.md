# Community — Small-group Progress Network

## V3 role
不是公共 feed，而是小队/冲刺/成果 feedback 与 accountability。

## Core objects
Squad / Sprint / Check-in / Artifact / Feedback / Flame(群体热度，不等于付费)。

## Privacy
- 默认只分享用户主动选择的 Goal/Action/Artifact；
- private memory/profile 永不自动带入 group；
- Aurora 在群聊中只能访问群授权 context；
- 删除/退出/撤回要传播到 read model。

## Solo demo
seed group 明确标示演示；核心产品不依赖社群。

## Acceptance
两账户 realtime、重连、撤回、权限、check-in→goal evidence；WS 真实通过，无 mock 冒充 live。
