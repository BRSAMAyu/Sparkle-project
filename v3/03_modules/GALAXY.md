# Galaxy — Outcome & Knowledge Graph

## Job
视觉化“我已经形成了什么、它们怎样连接”，而不是装饰性星空。

## V3
节点可包括 knowledge / skill / artifact / milestone；关系必须来自真实 evidence。
掌握度不能仅由 study_minutes 线性点亮；引入 evidence confidence：quiz/performance/artifact/review/self-report 分开。

## UX
- 保留暗色宇宙作为品牌视觉锤；
- 默认聚焦当前 Goal 子图；
- 点击节点能回答“为什么点亮 / 来源 / 下一步”；
- Review now 与主交互不重叠；
- 无数据时不造假星空，给生成第一颗星的行动。

## Acceptance
真实 action/outcome 能新增/更新节点；删除材料/纠正 evidence 后图一致；跨端手势/性能通过。
