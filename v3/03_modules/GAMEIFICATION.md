# Achievement / Photon / Shop / Leaderboard

## 决策
- Achievement：保留轻量里程碑，奖励真实 outcome；
- Photon/Shop：从核心旅程降级，除非证明能促进 WVPL 且不操纵；
- Leaderboard：V3 主产品默认 HIDDEN，不因已有 1k+ 行代码上线；
- Flame：仅社群热度，不再承担 paid entitlement。

## 禁止
用 streak/金币惩罚休息；用 leaderboard 制造焦虑；用 seed 虚拟货币混淆商业计划。

## Acceptance
核心 journey 不依赖游戏化；低刺激模式可隐藏；所有奖励基于真实事件。
