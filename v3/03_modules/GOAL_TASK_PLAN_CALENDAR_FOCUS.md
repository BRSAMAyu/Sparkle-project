# Goal / Task / Plan / Calendar / Focus

## V3 model
Goal 是持续上下文；Plan 是可重算路径；Action 是此刻执行单位；Calendar/Focus 是按需 capability。

## Goal screen
- desired outcome / deadline；
- 当前 milestone；
- active action；
- recent evidence；
- blockers；
- timeline/trajectory；
- materials；
- `重新规划` / `我卡住了`。

## Task rules
- 每张 task 有 completion evidence；
- estimated ≠ actual；
- stale plan 可 rescope；
- overdue 不等于失败；
- focus timer 不等于学习成果。

## Calendar
只在 scheduling intervention 需要时出现；读写需权限/确认。

## Acceptance
创建→开始→focus(optional)→完成→artifact→goal update→calendar/context 回流完整闭环。
