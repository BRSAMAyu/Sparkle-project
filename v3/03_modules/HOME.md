# Home / Today Cockpit

## Job
回答：“我现在最值得做什么？”

## 信息层级
1. 一个 Primary Action；
2. Goal context + why now；
3. `我卡住了`；
4. 次要 upcoming / current run / proactive suggestion；
5. Aurora 的一条有用 understanding receipt，而不是仪表盘堆叠。

## 移除/降级
天气式 guide、过载风险、预测、连续天数等只有能改变行动才上首屏。避免 5 个系统同时抢 CTA。

## States
fresh/seed/active goal/no goal/stalled/agent running/awaiting user/offline/error。

## Acceptance
5 Persona screenshot 审查；首屏 5 秒测试；primary action 唯一；数据全有来源。
