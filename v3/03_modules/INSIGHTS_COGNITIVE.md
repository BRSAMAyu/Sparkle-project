# Insights / Cognitive / Predictive

## Job
把数据转成用户能采取行动的洞察，不做“AI 算命”。

## 洞察结构
- observed fact；
- interpretation；
- confidence/uncertainty；
- evidence refs；
- implication；
- optional next action。

## 禁止
“你是视觉型学习者”“记忆力 82 分”若无可靠定义和证据。

## V3 views
- Goal progress；
- Friction patterns；
- Interventions that helped；
- Effort vs outcomes；
- recent changes；
- predictions 仅在可校准时显示。

## Acceptance
每条洞察可溯源；mock=0；用户纠正能改变后续；预测与规则 fallback 明确区分。
