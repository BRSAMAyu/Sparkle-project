# Long-tail Feature Policy

## contextual capabilities
calendar / focus / vocabulary / translation / document / file / knowledge / reviews / reflection / report / tools 等优先作为 Goal/Action 内能力。

## Labs/HIDDEN 默认
mirofish / theater / simulation / experimental visual elements 等在未证明独特用户价值前移入 Labs 或隐藏。

## OpenClaw
若已有执行/tool能力，接入统一 Agent Runtime，不保留第二套用户可理解的“另一个 AI 中心”。

## Portfolio test
每个模块必须回答：
1. 哪个核心 JTBD？
2. 哪个 Journey 会自然进入？
3. 如果删除，WVPL 是否受损？
4. 是否有真实数据/状态完整性？
回答不了即降级/隐藏，而不是继续打磨。
