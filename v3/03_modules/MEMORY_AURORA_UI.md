# “Sparkle 对我的理解” UI

## 不是数据库管理器
用户看到四组：
- 你告诉我的
- 我从你的行动中观察到的
- 我还不确定的
- 对你有效过的方法

每项：内容、范围、来源、更新时间、状态、操作。

## Actions
修改 / 删除 / 仅此 Goal / 暂时不用 / 查看来源。

## Correction experience
从任何 `Why this?` receipt 可直接“这不对”；纠正后当前建议重新评估，并给出真实变化。

## Acceptance
错误 memory 纠正→Context 变化→Aurora decision 变化；删除后所有缓存/derived profile 不复活。
