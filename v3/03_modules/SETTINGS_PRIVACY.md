# Settings / Privacy / Transparency

## 必须用户可控
- Memory 总开关/分项控制；
- 主动提醒与 quiet hours；
- 数据导出/删除入口；
- Agent 自动执行权限；
- model/data usage 说明；
- accessibility / low-stimulation；
- account / entitlement。

## Transparency
不是技术日志倾倒；提供：“Sparkle 会记什么、为什么用、怎样删、哪些动作会先问你”。

## Acceptance
设置实际影响 runtime；删除/禁用不是 UI-only；跨设备一致；权限变化 in-flight run 被重新检查。
