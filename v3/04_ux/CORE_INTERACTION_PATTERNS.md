# Core Interaction Patterns

1. **Why this?**：个性化建议可展开依据，不打断主流程。
2. **Propose before mutate**：重要写操作先显示差异。
3. **One clarifying question**：一次问最有信息增益的问题。
4. **Turn ownership**：Hybrid run 明示“Sparkle 正在做 / 轮到你 / 等确认”。
5. **Recoverable wait**：长任务可离开，回来恢复。
6. **Inline correction**：从建议/Memory receipt 直接纠偏。
7. **Outcome capture**：完成动作时优先记录成果而非庆祝动画。
8. **Quiet proactive**：主动建议可一键今天忽略/以后别提醒此类。
9. **Source chip**：材料/Memory 来源轻量显示，可展开。
10. **Graceful unknown**：不知道就显示不知道 + 下一步，不造确定性。
