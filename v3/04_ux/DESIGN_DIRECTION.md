# V3 Design Direction

## Brand Character
Calm / Warm / Precise / Alive / Trustworthy。
参考气质是“纸感书院 + 现代 AI”，不是赛博控制台。Galaxy 作为独立视觉锤可进入 dark cosmic mode。

## Hierarchy
任何核心屏幕 5 秒内必须回答：
1. 我在哪里？
2. 现在最重要是什么？
3. 我可以做什么？
4. AI 为什么这样建议？

## Decorative Budget
现有大量 gradient/particle/glow/confetti 必须逐屏审查。规则：装饰对比度不得高于核心信息；同屏最多一个强视觉焦点。

## Components
收敛 Button/Card/Chip/Pill/Empty/Error/Loading/AI-state；不再 features 内各造一套。

## Motion
动效解释状态变化，不作为奖励噪声。支持 reduce motion/low stimulation。

## Typography
不使用 10/11px 作为普通可读正文；遵守 design tokens 与 WCAG；中文行距/字重单独目测。
