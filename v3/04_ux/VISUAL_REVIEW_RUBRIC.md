# Visual Review Rubric

Agent 每次 simulator screenshot review 按 0–2 评分：

1. **Hierarchy**：主任务是否一眼可见；
2. **Clarity**：内部术语/数字是否需要解释；
3. **Density**：信息是否过载；
4. **Spacing**：留白/对齐/节奏；
5. **Typography**：字号/字重/行高；
6. **Color/Contrast**：可读性与语义；
7. **Consistency**：组件/圆角/按钮/图标；
8. **Affordance**：可点击性与 disabled；
9. **State feedback**：loading/error/success；
10. **Brand fit**：是否 calm/warm/precise；
11. **Motion**：是否帮助理解；
12. **Platform fit**：Android/Web/macOS。

A issue：阻断、误导、不可读、错误主焦点；B：明显降低体验；C：微调。
V3 核心旅程 A/B = 0 才算过。
