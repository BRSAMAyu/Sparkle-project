# V3 Metric Tree

## North Star — Weekly Valuable Progress Loops (WVPL)
Active user 在 7 日窗口至少完成一次：
`goal-linked action → outcome/evidence → state update`。

必须同时保留分母，避免只报绝对数。

## Outcome metrics
- WVPL users / active users
- loops per WVPL user
- time-to-first-meaningful-value
- goal recovery time after stall
- action→outcome conversion

## AI quality
- stuck diagnosis accuracy
- intervention appropriateness
- execution allocation correctness
- personalization precision
- over-personalization rate
- conflict resolution accuracy
- citation faithfulness
- false-success rate

## Experience
- core journey completion
- unnecessary clarification rate
- proactive precision
- notification burden
- error recovery success
- visual A/B issue count

## System
- TTFT / time-to-first-useful-state
- total latency by cognition tier
- Agent run success/partial/unknown
- duplicate side effects
- cross-user isolation
- cost / WVPL
- context tokens / decision

## Understanding Depth（internal only）
Coverage / Correctness / Scope Precision / Freshness / Utility。
它用于 debug/evaluation，不作为神秘用户 score。
