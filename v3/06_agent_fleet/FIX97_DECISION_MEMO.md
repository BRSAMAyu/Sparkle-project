- **纠偏先行**：登记行「纠正永不触发」经 raw 重算需修正为「**无否认对象的会话面翻倍**」——修后 full 臂仍有 15 次纠正（chat 面 B1 非 tie 错位行动在喂回路），饿死的是「旅程面 B3 tie no_action」这一输入类：无行动卡点会话 20/59（34%）→ 38/67（57%），这类会话用户没有任何可否认的「被提名成因」，纠正 API 的产品语义（`correct(friction_type)`，friction_type 来自被纠正诊断）天然不可达。

## 问题陈述

纠正记忆回路的唯一入口是「先错位行动 → 用户否认该行动背后的成因」。FIX-50① B3 诚实化（平权 tie 不再猜）后，引擎从「错位行动」转向「不出面」，否认对象随之消失：full 臂无行动卡点会话占比 34%→57%，纠正链的目标序列劣化（skill→difficulty→dependency 字母序游走，10/15 次纠正后落 unknown→ask 死端，叠加 FIX-49 门 chat 面追问静默，3 会话预算内永不收敛）；p05_correction_loop persona full 臂 0/2（no_memory 1/2）；记忆面净收益由 +0.10（0.65 vs 0.55）翻为 −0.10（0.45 vs 0.55），效用 full −9.2 vs no_memory 0.0。诚实化是行为正确（移除平权偶然蒙对），但记忆回路需要一条不依赖「先犯错」的第二输入。

## 候选方案

**A · 二类自由纠正入口**（「都不是，其实是…」，与错位行动完全解耦）
- 机制：旅程 no_action 载荷附纠正入口；自由文本经封闭词牌表分类成 friction_type → 走既有 `correct()` → J1 垫后环照常。
- 收益：覆盖全部无行动形态（57% 会话面），修复最彻底。
- 风险：**第二真源**（用户自报类型）——WT393 评估协议明文规避（§6：不构造用户自报真值通道）；误纠正会垫后真型且 StuckJourneyCorrection 持久生效，伤面最大；词表分类复用现有词牌表，但 FIX-115 证明词表有洞。
- 代价：**2 卡**（分类函数+载荷面 / 契约测试+A-08 复跑）。

**B · B3 平权候选集低承诺出面**（「可能原因」清单，否定即纠正）
- 机制：B3 tie no_action 时把 `annotations.contenders`（引擎已算，零新计算）以「这些可能是原因吗？」低承诺清单随 no_action 出面；用户否定其一 → 既有 `correct(friction_type=被否定型)`；不点选即静默收敛，零预算消耗。
- 收益：直击饿死主体（B3 tie 正是 wt412 定位的输入类）；否认对象仍是引擎提名，**无第二真源**，产品语义零变更；correct API / J1 垫后环 / contenders 全复用。
- 风险：候选带宽分支可达 10 类（需按 margin ε 截 top-k，否则清单变问卷）；向用户暴露引擎不确定（但仅 tie 时出面，B3 修后本身就是小概率出口）。
- 代价：**1 卡**（`_build_payload` 扩面 + engine 触发条件扩展「无 main_intervention 但有否定候选」+ 红测 + A-08 局部复跑）。

**C · 无行动时主动邀请结构化纠正**（封闭类型选择器「更像哪种？」）
- 机制：unknown/无证据 no_action 时主动问一次封闭类型选择。
- 收益：覆盖面同 A（含零证据形态）。
- 风险：主动问 = 变相问卷，与 FIX-49 降噪目标正面冲突（侵入计数、问卷预算语义都要新裁）；开放选型器 = A 的第二真源风险 + C 的侵入风险叠加。
- 代价：**1.5–2 卡**（新交互面 + 侵入/预算口径 + 评估协议修订）。

## 推荐（明确排序）

**B > A > C。** B 唯一同时满足：不引入第二真源、复用全部既有环（correct/J1/contenders）、在门刻意保留的旅程面（用户主动入口，不受 FIX-49 约束）修复；1 卡代价直接对冲实测 −0.10 翻转的主输入类。A 仅在用户接受「自报类型为合法纠正输入」后作为 B 的并轨补强（修复零证据形态），否则关闭。C 建议否决：与降噪目标冲突最大、代价不低于 A、风险是 A+C 并集。裁决后落地卡需含 A-08 四臂复跑验收（预期：无行动会话的纠正触发率 >0、p05 类段 full 臂回升、侵入率保持 0）。

## 需要拍板

1. **纠正语义边界**：是否接受「用户自报类型」作为纠正输入（方案 A 的前提）？接受 → B 先行、A 并轨；不接受 → 只做 B，A 永久关闭。
2. **出面域**：B 的候选清单仅旅程面（chat 面维持 FIX-49 全静默）？建议仅旅程面。
