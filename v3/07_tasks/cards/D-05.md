## Work
1. 记录 intervention exposure/accept/edit/reject/start/outcome。
2. 按 goal/friction/execution_mode 切片；禁止用 chat reply 当 outcome。
3. 提供 conservative association summary 给 Experience projector。

## Acceptance
- [ ] 同一 intervention 不双计；未观察 outcome 标 censored/unknown。
- [ ] 能够生成 per-user/per-scope 的历史结果摘要。

## Required evidence
- base/final SHA
- targeted tests
- integration/simulator evidence
- review receipt

## Forbidden
- 不得重建已存在的权威真源
- 不得用 mock/seed 冒充真实行为
- 不得只通过静态代码阅读宣称用户体验通过
- 不得弱化既有安全/幂等/隔离/审计守卫

## Execution protocol
- 先复现/基线，再修改。
- Worker 只能提交 `READY_FOR_REVIEW / PARTIAL / BLOCKED`，不能自行 DONE。
- Reviewer 必须独立执行关键验收。
- 合并后在 integration HEAD 重跑相关检查。
