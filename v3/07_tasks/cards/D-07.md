## Work
1. 实现 fact→interpretation→uncertainty→evidence→implication 卡片。
2. 优先 friction pattern/interventions that helped/goal progress。
3. 删除/隐藏无定义能力分数和假精确预测。

## Acceptance
- [ ] 每条洞察可点来源；纠正错误解释后后续更新。
- [ ] 无数据时不生成人格结论。
- [ ] Simulator 能理解至少 3 条 insight 意义。

## Required evidence
- base/final SHA
- targeted tests
- integration/simulator evidence
- review receipt

## Forbidden
- 不得重建已存在的权威真源
- 不得用 mock/seed 冒充真实行为
- 不得只通过静态代码阅读宣称用户体验通过
- 不得弱化既有安全/幂等/隔离/审计守卫

## Execution protocol
- 先复现/基线，再修改。
- Worker 只能提交 `READY_FOR_REVIEW / PARTIAL / BLOCKED`，不能自行 DONE。
- Reviewer 必须独立执行关键验收。
- 合并后在 integration HEAD 重跑相关检查。
