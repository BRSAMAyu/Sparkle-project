## §5 主会话整合管线（agent 返回后的八步，顺序强制）

1. **取证**：`git -C <worktree> diff main...HEAD --stat`；生成补丁
   `git -C <worktree> diff main...HEAD --binary -- . ':(exclude)v3-output/<ID>/changes.patch' > /tmp/<wt>_fresh.patch`

2. **apply**：`git apply --3way /tmp/<wt>_fresh.patch`；冲突手解（语义冲突比文本冲突危险——见 §12 教训）
3. **冷缓存验证**：backend 改动必 `cd backend && rm -rf .mypy_cache && mypy app --ignore-missing-imports --no-error-summary | grep -c 'error:'`
   （热缓存会静默少报千条；数值=基线或更低才算过）
4. **定向回归**：pytest（先 `find tests -name` 拿真实路径，**别猜路径**）；mobile 则按 swap 门跑定向 flutter test
5. **ruff gauntlet**：被碰 backend 文件 `ruff check --fix`（合并态 I001 是 CI lint 三连击根因，主会话标准步）
6. **守卫门**：`bash scripts/run_all_rule_guards.sh` exit 0 必须**门住 commit 链**（守卫红着不许 commit）
7. **路径限定 commit**：`git commit -m "..." -- <精确路径>`（防吞组：apply --3way 会 staged，plain commit 会吞走别卡内容）
8. **删树+补位**：删树前 `git -C <wt> status --porcelain` 查遗留（untracked 交付物先抢救）；`git worktree remove` 裸判 exit；分支 `git branch -D`；**立即补位**（§13 池）

## §12 事故与教训账本（新会话必读，别再踩）

1. **zsh `===` 会触发 glob 报错**——echo 分隔符用 `'---x---'` 带引号
2. **`cmd | tail` 吞 exit code**——判 exit 用裸命令重定向文件再 `echo $?`
3. **shell cwd 漂移**（本会话反复犯）——每条命令前 `cd /Users/brsama/code/GitHub/Sparkle-project`；flutter 必须在 mobile/ 下跑
4. **二进制 diff**：生成端与打补丁端都要 `--binary`（.so/.png/.dylib）
5. **apply --3way 会 staged** → plain `git commit` 吞走别卡内容——一律路径限定 commit，commit 前核对 status
6. **测试路径别猜**——`find tests -name` 拿真实路径（"no tests ran"=路径错不是测试绿）
7. **mypy 热缓存**批量改动后静默少报千条——刷基线必冷缓存
8. **同锁先后两卡**（如 wt307↔wt312 同碰 community）：第二张必须在**合并态**做编译验证，worker 树内绿不算数
9. **worker 交付物必须 commit 进分支**（wt306 抢救/wt313 重建两事故）；删树前 `status --porcelain` 查 untracked
10. **删树命令裸判 exit**——wt303/wt307 的 remove 失败曾被管道吞，数小时后才巡检发现
11. **端口探活必须核监听进程 PID/启动时间**（僵尸 gateway_bin 事件）；agent 阵亡清点含后台进程
12. **机械编辑必须回归**——逗号编辑截断括号被定向回归当场抓住
13. **worker 声称的 lint/mypy 绿是树内口径**——合并态会漂移（ruff I001 三连击）；主会话 ruff gauntlet 是标准步
14. **压测脚本的理论值必须从运行时 config 解析**（S2 口径错位教训）
15. **run 在跑不推任何东西**（concurrency cancel 两次自伤）
16. **register 探针**必须带 `accepted_tos:true, accepted_privacy:true` + 邮箱用 example.com（.local 保留域被拒）
17. **env 文件多行值会炸 zsh source**——显式按 key grep+export 传参
18. **模拟器**：swiftshader 会熔断，用 `-gpu host` 重启续跑；JDK25 构建败，用 openjdk@17
19. **AskUserQuestion 深夜超时**≠拒绝——按预立纪律裁量（如 CI 冻结）并在台账留痕
