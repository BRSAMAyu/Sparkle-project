# 参考图逐层审查：保留气质，不复制布局

输入是用户提供的 `前端参考图.jpg`，属于方向示意，不是当前Sparkle实际页面或已授权上线资产。本文是视觉观察与设计判断，不声称做过眼动/真人测试。

## 应当保留
暖纸底色与低饱和像素自然物带来区别于玻璃渐变AI面板的识别度；阶梯角、细墨边、有限像素阴影可以形成组件语法；嫩芽、路径与远景能表达成长但无需每页讲新故事。正文采用可读中文字而非全像素字，这一点比“越复古越好”更重要。

## 必须修改
| 图中具体位置 | 观察 | V4处理 |
|---|---|---|
| 顶部头像/Explorer/英文手写口号/中文口号 | 装饰与自我介绍占首屏大量空间；真正行动晚出现 | 顶部压成品牌/日期/状态一行，主行动进入首个视口；口号仅空态或欢迎页 |
| 今日成长3/4勾选 | 任务完成数与成长混为一层 | 改为“今日行动3/4”，能力只由独立证据说明；未完成不变成失败人格 |
| 紫蓝渐变CTA | 与低饱和纸感体系不一致，按钮比内容更像营销Banner | 主CTA统一深苔绿/深墨，像素压印仅表示按压；渐变只给非关键装饰实验档 |
| 所有块都双边框/重圆角切阶 | 无主次，内容区边缘多次重复 | 一级主卡可双线，二级平面分隔，密集列表无装饰边；边框种类≤3 |
| 小号英文字母与底部口号 | 低优先信息仍占纵向空间，窄屏容易难读 | 非必要双语删掉；核心中文14–16sp以上；辅助英文不承担唯一意义 |
| 探索/成长同款罗盘 | 语义难区分 | 维持现有五Tab语义，任务/对话/星图用独立形状和文本标签 |
| 底部长景与大导航框 | 小屏与键盘打开时挤占有效空间 | Landscape仅视口有余量时出现、无交互、可关闭；导航原生SafeArea，不进截图背景画布 |
| 图中路线图START/BETTER YOU | 漂亮但不知道点是否有事实 | 每点必须可读具体成果；无成果显示空路线或引导，不伪造进步 |

## 风格冻结与探索边界
字体、色值、枝叶/星星形象、角切步长、音色暂定。状态语义、点击区域、文本层级、单一主动作、权限和回执不可为风格让路。原图中的可爱不是“强制每次鼓励”，像素不是“故意卡顿”。

## 同一设计如何覆盖不同密度
欢迎/空态：插画可以占20–30%可用区；主任务面≤15%；长文/代码/数据≤5%。这是设计预算，须实际截图调整。聊天回复不套巨大像素气泡嵌套四层；来源和操作只在相关段落出现。多人群聊先可读，再装饰。

本包 `prototype/DESIGN_LAB.html` 只验证这种克制方向的布局与交互，不能据此说“像素风已全端实施”。
