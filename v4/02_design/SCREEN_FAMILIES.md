# 页面家族：风格必须贯穿，而不是每页一套

## 首页 / 目标 / 任务 / 日历
首页按“当前目标→下一步→可选上下文”排序，不复刻参考图高头部。目标页顶部是结果标准和接续，不是大百分比。任务页以执行区为中心，完成按钮要求明确提交/自报语义。日历保留小时/日期普通排版，像素仅选中框与微图标；拖动有键盘/按钮替代。新建表单先目标与成果再可选字段，不为游戏化加角色、能量、职业问卷。

## 对话 / 卡住 / Hybrid / 运行台
对话平直纸面，不把每条长回答装双重边框。正文按段流式，增量不抢滚动；用户上滑后保持位置。工具阶段收在状态行，不能展示隐藏推理链当解释。卡住sheet先输入原因，再一个决策问题和提案；取消即回到原任务。Hybrid卡固定“Sparkle准备→你来做→共同检查”，每步的责任人和证据一目了然。运行台沿用OpenClaw路径与Run ID，不创建像素版独立Agent中心。

## 记忆 / Aurora / 我的理解
“我了解到的”按项目范围分组；事实、已确认偏好、待确认观察分开，不输出人格雷达图。每项有“来自…/仅用于…/更改/忘记”；复杂版本和epoch留开发诊断。纠正成功只代表该状态保存；本轮计划需另确认。记忆清空有明确说明和可查询进度，不被3次/天解释预算限制。

## 星图 / 学习 / 错题 / 资料
星图是一张可探索的证据路径，地图可像素化，标签与图表保持清楚。有线性列表模式、缩放+/-、键盘导航。材料、错题与词汇沿目标打开，主操作是继续当前动作；不回到空白搜索页丢上下文。来源badge能跳原文片段。OCR不支持时提供手输入；不假装图片已识别。题目示例与独立测验答案隔离；测试命题不能把答案塞进可被用户读出的UI状态。

## 洞察 / 复盘 / 报告
先一句可核验观察，再≤3条带来源记录，再一个可以采用的调整。“有3次相关记录；2次采用示例后开始了练习”是关联，不写“示例法使你提升67%”。没有数据就说明尚未形成结论。像素印章标记类型，不给AI推断盖“认证”章。统计图颜色语义和日期/单位一致，不能用pixel阶梯线捏造台阶趋势。

## 小队 / 自我锚 / 光子 / 成就
沿用D-COMM最新决定。邀请制学习小队先行动和共享成果，再火堆装饰；self-anchor是与过去自己比较，不是全站排行；光子兑换表达受限奖励不暗示付费身份由游戏等级决定。所有展示用真实账本，用户可关闭庆祝。小队头像/成就资产同一像素网格，不照搬第三方游戏素材。Shop等HIDDEN不为展示新皮肤擅自开启。

## 账号 / 设置 / 通知 / 异常 / 长尾
账号功能以原生输入和错误信息优先，品牌框不能遮键盘和勾选。设置提供动效、配乐、提示音、触觉分别开关，默认不自动播放。通知深链落在具体对象，对象已删或权限失效有可理解的替代页。404/离线/登录失效与模型失败不同，不全部跳“AI出错”。所有长尾模块按MODULE_MATRIX绑定一个页面家族，LABS/HIDDEN不改状态只是记录fallback。

## 每家族统一检查表
默认/空/加载/部分内容/模型失败/离线/恢复/取消/未知写入/过期版本/权限失效/200%字体/键盘遮挡/深链返回/减少动态。列表、表单、sheet与dialog均要截最上层实际画面，不能只取栈底RepaintBoundary复用“漂亮截图”。
