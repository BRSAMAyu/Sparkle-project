# V4-F06 — limitations

## 1. NOT_RUN / 边界面（如实登记，不冒充）

1. **真机读屏（TalkBack/VoiceOver）实际朗读**：本卡无真机/模拟器触达。交付的
   语义证据 = 语义树断言（label 逐字相等、liveRegion 旗标、button 标志、
   连接子句在场）与 dump 文本（真实中文标签），**不声称**真机朗读节奏/焦点
   环/手势路径已验证——归设备面卡。
2. **真机字体渲染**：截图为 tester Ahem 字体块（中文呈方块），有效面 =
   布局/轮廓/色板/状态形状与 200% 换行行为；真实字形归设备面（F02 同口径）。
3. **物理帧率**：语义清单连接子句计算随 overlay 按图缓存（不进每帧热路径），
   但未在真机 60Hz 帧统计下复测——V3 GALAXY-A11Y 性能基线测试（语义子树
   微秒级走查）在本卡改动后原样全绿，作为旁证。
4. **AQ/BG 守卫**：worktree 缺 gitignored 生成目录不可跑；主检出同脚本
   PASS 已核验（环境性，非回归）。
5. **sparkle-coordination-v2 a11y 锁租约**：本机未配置该私有远端，租约
   NOT_RUN；冲突面以 diff 自证（无 RF-06 三文件、无他卡在航文件交集）。
   有远端配置的会话请补登。

## 2. 已知取舍（实现面）

1. **200% 全通路穿透未放开**：app 壳字阶组合保持 A-SPEC6 N31 既定夹窗
   [0.85, 1.35] × in-app fontScale（≤1.4）→ 系统 200% + app 内最大档的
   有效上限 = 1.89×。组件族/星图在**直加 2.0 字阶**下零异常已断言
   （`composeAppTextScaler` 上限点也钉在 1.89）；放开夹窗到全 2.0 穿透是
   布局安全预算裁决，归规范 owner（R5），本卡不擅改已注册决策——已在
   `composeAppTextScaler` doc 注记与组装律测试上限点双登记。
2. **打字机口径对齐面为 0 消费点组件**：`TypingText`/`TypingRichText`/
   `_BlinkingCursor` 当前在 lib/ 内无产品调用点（仅 golden 资产引用）。
   口径对齐（platformDispatcher 直读 → MediaQuery 双源并集）属既有维护面
   修正，无行为调用点风险；若后续接线，其 reduce-motion 行为已与全 app
   单一口径一致。
3. **星图物理沉降（settle simulation）未纳入静态分支**：reduce-motion 分支
   静态化的是入场（620ms 模糊/缩放/渐显）与相机推近（1400ms）；节点布局
   沉降物理仿真属功能性布局收敛（重叠消解），与 V3「已播过入场」路径
   （refresh 路径无条件 `_startGraphSettleSimulation(0.28)`）同口径保留。
   前庭敏感用户的完全静止版星图装载是更大的交互裁决，留规范面。
4. **announce 链路不带连接子句**：键盘焦点播报（announceNodeSelection）保持
   V3 既有标签口径（名称+解锁态+掌握度+学习次数）；连接子句只在语义清单
   标签（线性遍历面）。播报长度与信息完整度的取舍由读屏面卡裁决。
5. **BlinkingCursor 中途切换**：减弱动效在航时 `stop()` 直落静态（value=1），
   从减弱切回不重启闪烁（保守：不重启已过内容）；像素成功徽章同理。
   双向热切换的完整状态机（减弱→恢复→补播）不在基础能力最小增量内。
6. **可取消锁存升级未做**（沿 F02 #15 判例）：本卡新增动画分支均为
   一次性短动效（650ms 内），无资源泄漏/悬挂面。

## 3. 测试口径注记

1. **~1 skip 均为既有**（galaxy/settings 域各一），本卡 24 新用例零 skip。
2. **failures_fixed 四轮全记录**于 test_results.json（探针修正/时序修正/
   字面量收敛/证据口径收敛），实现语义未为绿灯让步；DL-SPEC 一轮为真
   违规真修复（重复字面量去重）。
3. **控制组纪律**：每个零值/阈值断言（零异常、零 ticker、≥48dp、逐字相等、
   ≥4.5:1、progress==1.0、焦点保持）都有同探针反例面（溢出/在航/32dp/
   拼接/禁用灰/progress<1/模态对话框夺焦），证明断言非恒真。
4. **galaxy 证据无 PNG**：runAsync 真实异步窗会拉入 auth/网络插件链
   （MissingPluginException→UnimplementedError 级联），纯同步语义 dump 为
   该面证据载体；PNG 面由像素故事页证据承担（2 变体）。

## 4. 审查挑战点预登记

- **C1｜`composeAppTextScaler` 行为等价性**：app.dart 委托重构声称「逐字节
  等价」。审查可对照 `git diff fea3a4aa -- mobile/lib/app/app.dart`：夹窗
  参数、`scale(16)/16` 基准、乘式、三旗标 OR 律逐项同值；未装载分支原样。
  若判不等价即红——请优先变异核对（如 fontScale 乘序）。
- **C2｜连接子句的粒度裁决**：「连接有文本列表」实现为**节点条目内**连接
  名列举（复用 `_buildAdjacency`，图序去重、未知名端点跳过），而非独立的
  逐边语义条目清单。若审查判「每条连接一个语义条目」才是合同原意，差异
  点 = 边粒度遍历与节点粒度遍历的读屏动线；本实现的依据 = 节点已是个独立
  语义边界（GALAXY-A11Y 容器纪律），边清单会引入第二套 N-1 条目与遍历序
  仲裁。请裁决口径或在 receipt 注记。
- **C3｜200% 夹窗保留是否违反验收③字面**：验收③是「无零 duration 崩溃」
  而非「200% 全穿透」；本卡在组件族/星图直加 2.0 面全绿，app 壳夹窗为
  A-SPEC6 已注册决策（N31/N33 证据链）。若审查判卡面隐含「200% 有效穿透」，
  这是规范 owner 裁决面（R5），非实现缺口——请按 receipt 注记处置。
- **C4｜typing_text 0 消费点改动的必要性**：若判「无调用点不该动」，反方
  证据 = A-SPEC6 N32/AX-G5 统一令明令禁双源分裂直读、该文件是活维护面
  （golden 引用），且接线前对齐成本最低。请裁决保留或摘除（摘除不影响
  其余验收面）。

  判例一致、L10N-PARITY/I18N 守卫 PASS；若审查要求实跑 gen-l10n 比对，
