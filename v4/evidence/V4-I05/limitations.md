# V4-I05｜limitations

1. **影子对照的「收益判定」是相关性计数上的可解释规则，不是效果断言**：`benefit_verdict` 读 M-06 观察面的 n_positive/n_negative（共同出现计数，非因果），严格多数规则（prefer 需 pos>neg）是稀少样本下的保守可解释判定（EXPERIENCE_AND_LEARNING「稀少样本下先用可解释规则……避免自信 Bayesian 概率装饰」）；censored-only 显式不结论。四臂锚的 utility 数值比较仍归 B03 冻结协议的离线评测——本卡零「自适应优势」宣称。混合方向记录（正负皆有）按净多数判定，分布细节在 observation face 计数中保留（不删信息）。
2. **decision 面 precondition 事实的 chat 侧接线未做（本卡边界内决定）**：`patched_decision_inputs` +`decision_context` 参数就绪，但 `friction_chat_wiring`（I04 域文件）未改——生产 chat 链当前不传 `human_required_step` 等事实，live 门在生产路径的实际门出来源=窗口/结构性边界（门出测试全部走显式传参路径）。缺事实 = 相关 do_not_apply 键 fail-closed 不命中（不猜）；把 chat payload 的事实接进 `decision_context` 归后续 wiring 卡（涉 I04 域文件与 payload_ctx 形态盘点，避免本卡跨锁改文件）。
3. **撤回传播是显式服务入口，未挂 retraction.registered 事件消费**：D03 的 `retraction.registered` outbox 事件生产方 UI/FSM 入口按卡序归后续卡；本卡交付 `invalidate_on_source_withdrawal`（幂等可重放、三档一致、审计完整），事件总线监听器挂接与 D03 生产触发方同批接线（同一段基础设施缺口，非本卡新增）。当前手动/服务间调用即生效。
4. **「持续看负迁移→可回退」的在线 watch sweep 未做**：卡面验收第 3 条的「不静默启用」已由 live 收益门承载（admission 时点）；启用**后**窗口内负迁移的周期性复核（对 active patch 重算观察面→no_benefit 则 revoke）是独立 sweep 面，本卡未加 cron/worker——回退路径当前=用户 revoke（即时）+ 窗过期（72h 有界，窗过即 expired 收敛）。无限期 live 已被有界窗结构性排除。
5. **D04 未启动，「VERIFIED 才融合」为通道预留而非本卡实现**：tasks.json 中 D04（星图证据与参与足迹分离）PENDING——本卡策略启用效果零 galaxy/星图写路径（观察面只读 M-06/D-05 真源；对照工件 content-free 引用级），不存在绕过 D04 分类的融合行为；D04 落地后其 VERIFIED 通道自然承接策略效果的融合面（source_refs+evaluation_version 已使效果可溯源到策略版本）。
6. **I06 context receipt 联动未做**：影子对照审计走本卡自有内容寻址工件（`expshadow_`，重放恒同）+指标+结构化日志；与 `context_selection_receipt.v1` 的勾稽（如门出理由进 receipt 候选状态）归 receipt 消费卡。本卡未消费 I06 任何接口。
7. **shadow_report 每次 O(投影+重排) 现算，未缓存**：审计面显式调用（测试/运维），不进决策热路径；`patched_decision_inputs` 的 shadow 观察复用已加载的投影（projector 进程缓存）+ 既有重排（120s 决策缓存键含档位），热路径增量=每 cache-miss 一次逐卡谓词评估（无新增查询）。规模化（万级 patch 用户）未压测。
8. **precondition 值域 = 既有权威词表，无自由文本**：`goal_purpose` 的 legacy 行推导依赖 I07 `derive_goal_purpose`（X-02 同集）；无结构化声明时情境侧给不出 goal_purpose → `missing_fact` fail-closed 不启用（保守向，少启用不误启用）。「do_not_apply_when」三键为 v1 固定全量评估；更多键（如跨策略冲突、用户当日否决次数）归后续 bump（词表冻结纪律：需 bump EXPERIENCE_STRATEGY_VERSION 过 reviewer）。
9. **重复摘要折叠的边界=引用身份面**：折叠消除的是**同一引用重复出现**（同一 expmem/decision 真源行的重放伪影）；不同窗口/不同切片产生的不同 record_id 指向重叠事件集时，事件级 lineage 折叠需 D-05 事件身份贯通（本卡在 `observation_face_from_records` 已按 record_id 去重，同一次投影内同记录不双计；跨窗口重叠当前由投影单一窗口语义结构性避免——projector 每次调用单窗口）。事件级跨窗口折叠登记为 D-05 侧后续深化。
10. **mypy 全仓计数 59 与 I04 记录的 55 存在基线时点差**：fresh-cache 对照实验证实 main@ff02ec03 同口径同为 59（I04 的 55 为其 base 时点+旧缓存口径）；本卡改动文件 mypy 直查零错误，全仓唯一 main/wt 差异条目（policy_loader yaml-stub）为 main 检出陈旧缓存伪影（fresh cache 下 main 同样出现），非本卡引入。棘轮门 59 ≤ 77 exit 0。
