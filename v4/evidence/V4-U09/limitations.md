# V4-U09 已知限制（limitations）

1. **「重开恢复」的设备级边界**：杀进程→重开的恢复测试在 provider/widget
   层以 SharedPreferences 快照 + 新 notifier 实例模拟（等同进程重启的
   持久层事实）；真机杀进程、系统回收、多设备接续不在本卡证据面，归
   Q07（长期接续、离线与多账号组合回归，在航）。

2. **timer 计时的墙钟语义**：会话计时基于 `DateTime.now()` 墙钟差
   （切后台延续、暂停扣减 `accumulatedPaused`）。用户手动改系统时钟会
   影响读数——既有实现，本卡未改（改 NTP/monotonic 时钟属新机制，超出
   「只保留动作/计时/退出」的低刺激收口范围）；审查者如认为需钉，
   建议归 Q07 时间机制族。

3. **ambient 状态接入的深度**：按卡文「只接状态不做新音频机制」，本卡
   只做（a）会话暂停/恢复与 ambient 暂停/续播的状态同步（续播受
   U14 `ambient_enabled` 门控，默认不自动播放）；（b）页面零声音零动效
   完整可用的正例钉。未做：焦点页内的场景选择 UI（基线正念页本就没有
   场景选择器，接它反而违反「只保留动作/计时/退出」）；音频焦点/来电/
   耳机拔出状态机归 S02（在航）。

4. **失败路径的退出语义**：保存失败时按基线行为返回来源页（诚实错误
   提示 + R2-03 快照保留），而非停留页面原地重试——避免服务端持续不可
   用时把用户困在专注页的 trap。恢复动线（重开专注页续结）已由 widget
   生命周期场景覆盖。

5. **删除 reflection_dialog 的键残留**：被删组件的 l10n 键
   （focusReflectionTitle/Saved/SaveFailed 仍被新 sheet 复用外，
   无孤立键产生）——经核对被删文件的全部键均仍被引用或属共享键；
   「纯增量」纪律下未做键清理。

6. **截图证据的字体形态**：测试环境 CJK 为 Ahem 方块（F04/U01/U05/U08
   同先例）；结束面视觉在真机/桌面 preview 的外观归 Q05 视觉审查（在航），
   本卡截图证明的是「结构存在 + 文本语义 + 几何」，非美观审批。

7. **执行期间 main 前进 24 commit**：本卡基线 4152266c，main 已含
   U02/U11/U12/P01/S02 收口与 backend 通知面改动（与本卡触碰面零交集，
   HEAD 为 main 祖先）；集成复验随合并跑，arb 生成文件预计需合并侧
   gen-l10n 再生解碰撞（双方均为纯增量键）。
