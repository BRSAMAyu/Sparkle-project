# 暖纸像素交互草图

打开 DESIGN_LAB.html。页面可切换纸昼、暮色、低刺激；五个导航可点；可体验“卡住→范围选择→变化预览→本地回执→示例成果→撤回”。允许试听提示音默认关闭；打开后仅在成功的本地演示回执之后发出两段短合成音。不播放背景音乐，不调用振动接口。

这是系统交互语法和候选色板的**草图**，不是高保真定稿，不是当前 Sparkle 的运行截图。像素插画、角色、声音资产、原生组件以及最终布局仍需设计取舍。所有内容为显式示例：没有模型、后端、用户数据和真实记忆写入，也没有模型“看懂”输入框；输入框用于展示预设场景的交互位置。

关闭等待中的草图弹窗会取消本地模拟计时器。这只属于本地演示；产品中的取消必须遵守真实命令状态及回执，不能简单取消计时器冒充撤销已发生的提交。

`evidence/preview_*.png` 是本轮用Chromium运行本草图生成的截图，不是用户已有App截图。该草图无需网络，未打包字体或第三方图形资源；页内SVG为本轮程序绘制的简易符号。
