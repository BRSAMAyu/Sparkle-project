## [Audit] 证据

`GalaxyRepository.getGalaxyEventsStream()`（galaxy_repository.dart:63-72）：

```dart
Stream<SSEEvent> getGalaxyEventsStream() {
    if (DemoDataService.isDemoMode) {
      return const Stream.empty();
    }
    // 🔧 后端未实现galaxy/events端点，返回空流避免404错误
    debugPrint('🌌 Galaxy events stream: endpoint not implemented, returning empty stream');
    return const Stream.empty();
  }
```

注释明确说"后端未实现"。这意味着：
- Flutter 客户端无法通过 SSE 接收实时星图更新
- 掌握度变化、节点创建、错误惩罚等事件不会实时推送
- 用户只能通过手动刷新或重新进入页面看到更新

**预期**: Galaxy SSE 端点实现后，Flutter 通过事件流接收实时更新。

**实际**: 永久返回空流，无实时更新能力。

## [Audit] 建议修复方向

1. 后端实现 `/galaxy/events` SSE 端点，监听 `galaxy.node.updated` 等事件
2. 或利用已有 WebSocket 连接推送 galaxy 事件（复用 chat WS 通道）
3. 短期可在 `get_galaxy_graph` 返回时设置较短的客户端轮询间隔

## [Audit] 潜在副作用

- SSE 端点需限流和认证
- Flutter provider 可能已依赖空流行为，需适配
- 与 Go Gateway WebSocket 通道可能需要协调
