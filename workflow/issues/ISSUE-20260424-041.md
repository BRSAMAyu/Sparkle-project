# ISSUE-20260424-041 · P2

## Title

`search_messages` 群消息和私聊 LIKE 通配符未转义，用户输入 `%` 或 `_` 可匹配非预期结果

## Slice

07 — community_accountability

## Evidence

- `backend/app/services/community_service.py:1384`：`GroupMessage.content.ilike(f"%{keyword}%")`
- `backend/app/services/community_service.py:2138`：`PrivateMessage.content.ilike(f"%{keyword}%")`
- `backend/app/services/community_service.py:466-470`（`search_groups`）：`Group.name.ilike(f"%{keyword}%")`
- `backend/app/services/community_service.py:2422-2424`（`search_users`）：`User.username.ilike(f"%{query}%")` 等 3 处

所有 `ilike` 调用均未对 keyword 中的 `%`、`_` 进行转义。

## Impact

- 用户搜索 `%` 可匹配所有内容（信息泄露）
- 搜索 `_` 匹配任意单字符
- 功能性错误：搜索包含 `%` 的内容无法精确匹配

## Suggested Fix

添加 helper 函数转义 LIKE 特殊字符：
```python
def _escape_like(s: str) -> str:
    return s.replace("\\", "\\\\").replace("%", "\\%").replace("_", "\\_")
```
然后将所有 `f"%{keyword}%"` 替换为 `f"%{_escape_like(keyword)}%"`。

## 7D Classification

④ auth/rate-limit — 搜索输入未净化可导致信息泄露
