# ISSUE-20260424-044 · P2

## Title

`broadcast_achievement_unlock` 使用 `__import__("json")` 代替正常 import

## Slice

07 — community_accountability

## Evidence

- `backend/app/services/community_signal_bridge.py:225`：
  ```python
  __import__("json").dumps(payload, ensure_ascii=False),
  ```
- 文件顶部没有任何 `import json` 语句。

## Impact

- 代码可读性差，违反 PEP 8 import 规范
- `__import__` 在某些优化环境（如 PyInstaller frozen binary）中行为可能不同
- 静态分析工具（linter、IDE）无法识别此依赖关系
- 功能性无影响（`__import__("json")` 在标准 CPython 中等效于 `import json`），但作为代码质量问题应修复

## Suggested Fix

在文件顶部添加 `import json`，将 `__import__("json").dumps(...)` 替换为 `json.dumps(...)`。

## 7D Classification

③ logging/observability — 代码质量影响可维护性
