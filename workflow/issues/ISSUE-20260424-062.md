# ISSUE-20260424-062 · achievement_photon_visual · P2

## 标题

ContractService.update_daily_progress 无日期守卫，单日可获多天契约积分

## 证据

**文件**: `backend/app/services/achievement_engine.py`
**行号**: 2262-2273

```python
async def update_daily_progress(self, user_id: str, study_minutes: int):
    contract = await self._get_active_contract(user_id)
    if not contract:
        return

    contract.current_minutes += study_minutes
    if contract.current_minutes >= contract.target_study_minutes:
        contract.current_days += 1
        contract.current_minutes = 0  # 重置当日分钟数

    await self.db.commit()
    await self.check_contract_status(user_id)
```

## 问题分析

无日期校验：不检查 `current_days` 是否已在今天被计入。

攻击/误用场景：
1. 契约目标: 60 min/天 × 7 天
2. 用户一天内学习 420 分钟
3. 每次 `update_daily_progress` 被调用时:
   - 第 1 次: current_minutes=60 → current_days=1, reset=0
   - 第 2 次: current_minutes=60 → current_days=2, reset=0
   - ... 第 7 次: current_days=7 → 契约完成
4. 用户在一天内完成了 7 天契约，获得全部奖励

Flutter 端每次专注会话结束调用此接口，高频使用场景下容易触发。

## 修复建议

添加日期守卫：记录 last_day_credited_at，若当天已计入则只累加 current_minutes 不增加 current_days。
