# ISSUE-20260424-063 · achievement_photon_visual · P2

## 标题

`check_daily_first` get-then-set TOCTOU 竞态，用户可获双倍首胜奖励

## 证据

**文件**: `backend/app/services/achievement_engine.py`
**行号**: 2011-2045

```python
async def check_daily_first(self, user_id: str, db: AsyncSession) -> dict[str, Any] | None:
    today = date.today()
    cache_key = f"{settings.APP_NAME}:daily_first:{user_id}:{today.isoformat()}"

    # 检查今天是否已领取
    if await cache_service.get(cache_key):
        return None

    # 标记为已领取
    await cache_service.set(cache_key, True, ttl=86400)

    # ...返回奖励数据 (30 光子 + 可能的连胜保护卡)
```

## 问题分析

`cache_service.get` 和 `cache_service.set` 不是原子操作。两个并发请求（如用户同时完成两个任务）可在 `get` 返回 None 后、`set` 之前都通过检查。

**竞态窗口**:
```
Request A: get(key) → None
Request B: get(key) → None      ← 仍在 set 之前
Request A: set(key, True)       ← 第一次领取
Request B: set(key, True)       ← 第二次领取（覆盖）
```

两个请求都返回奖励数据，用户获得双倍（60 光子 + 2 张保护卡）。

## 修复建议

使用 `cache_service.set_nx`（Redis SETNX）原子操作，或使用 Lua 脚本保证 check-and-set 原子性。
