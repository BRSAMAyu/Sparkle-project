# ISSUE-20260424-070 · calendar_notification · P2

## 标题

calendar.py get_event_summary 使用 `__import__("datetime")` 代替正常 import

## 证据

**文件**: `backend/app/api/v1/calendar.py`
**行号**: 182

```python
upcoming_end = now.replace(hour=23, minute=59, second=59) + __import__("datetime").timedelta(days=7)
```

文件头部已有 `from datetime import date, datetime, UTC`，但未导入 `timedelta`。

## 问题分析

同 ISSUE-044（community `__import__("json")`），属于同一反模式。`__import__` 绕过静态分析、影响可读性、每次调用触发 import 查找。

文件顶部应添加 `from datetime import timedelta` 并替换为 `timedelta(days=7)`。
