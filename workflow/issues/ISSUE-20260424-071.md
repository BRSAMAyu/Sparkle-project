# ISSUE-20260424-071 · calendar_notification · P2

## 标题

Flutter `_cancelReminders` 硬编码最多取消 5 个提醒，超出部分永不取消

## 证据

**文件**: `mobile/lib/features/calendar/data/repositories/calendar_repository.dart`
**行号**: 397-401

```dart
Future<void> _cancelReminders(String eventId) async {
  final baseId = eventId.hashCode;
  for (var i = 0; i < 5; i++) {           // <-- 硬编码 5
    await _notificationService.cancelNotification(baseId + i);
  }
}
```

对比 `_scheduleReminders`（行 368-395）：

```dart
for (var i = 0; i < event.reminderMinutes.length; i++) {  // <-- 动态长度
  // ...
  await _notificationService.scheduleNotification(
    id: baseId + i,     // notification id = baseId + i
    // ...
  );
}
```

## 问题分析

`_cancelReminders` 最多取消 5 个 notification ID（baseId+0 到 baseId+4），但 `_scheduleReminders` 按 `event.reminderMinutes.length` 调度。

若用户设置 `reminderMinutes = [0, 5, 10, 15, 30, 60]`（6 个提醒），第 6 个提醒（id = baseId+5）永远不会被取消。

**复现场景**：
1. 创建日历事件，设置 6 个 reminderMinutes
2. 6 个本地通知被调度
3. 更新或删除该事件
4. `_cancelReminders` 只取消前 5 个
5. 第 6 个通知在原定时间仍然弹出（幽灵提醒）

## 修复建议

`_cancelReminders` 应接受 reminderCount 参数，或从本地存储读取事件的 reminderMinutes 列表长度。
