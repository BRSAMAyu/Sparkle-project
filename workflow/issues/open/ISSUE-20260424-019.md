## Title

_validate_feasibility 硬编码 "liberal_arts" 背景判断，不适用于多元用户画像

## Evidence

`backend/app/orchestration/plan_review_service.py`:

- **Line 646**: `user_background = user_context.get("user_background", "")`
- **Line 673**: `if user_background == "liberal_arts" and daily_hours < 3:` — 精确匹配 "liberal_arts"
- **Line 700**: `if user_background == "liberal_arts" or "文科" in str(user_background):` — 混合匹配策略

问题：
1. `user_background` 字段来源不明，无枚举约束 — 可能是 "文科生"、"Liberal Arts"、"liberal_arts" 等多种格式
2. 只对 "liberal_arts" / "文科" 做特殊处理，其他背景（艺术、体育、医学生等）无对应逻辑
3. Line 673 用 `==` 精确匹配，Line 700 用 `in` 模糊匹配 — 逻辑不一致
4. 对文科生的额外限制（expert+technical 需 >= 3h/day）缺乏数据支撑，可能造成不当歧视

- **Lines 661-664**: 难度判断从 title 关键词推断（"精通"/"专家"/"expert"/"master"），但只覆盖中英文各两个词

## Impact

- 文科生被额外限制可能影响用户体验和公平性
- 其他特殊背景用户无对应可行性检查
- 关键词匹配不完整可能导致漏检

## Suggested Fix

1. 统一 `user_background` 为枚举值，在 `user_profile` 或 `context_manager` 中标准化
2. 将背景特定逻辑抽象为 `BackgroundFeasibilityRule`，支持多背景注册
3. 添加 rule 注释说明决策依据和阈值来源
