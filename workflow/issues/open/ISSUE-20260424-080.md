## 标题

`get_patterns` API 无分页、不过滤 `is_archived`，返回全量行为定式含已归档

## 证据

**文件**: `backend/app/api/v1/cognitive.py:110-125`

```python
@router.get("/patterns", response_model=list[BehaviorPatternResponse])
async def get_patterns(...):
    stmt = (
        select(BehaviorPattern)
        .where(BehaviorPattern.user_id == current_user.id)
        .order_by(desc(BehaviorPattern.created_at))
    )
    result = await db.execute(stmt)
    return list(result.scalars().all())
```

**问题**:
1. 无 `limit`/`offset` 参数 — 随用户积累，模式越来越多，响应体无限增长
2. 无 `.where(BehaviorPattern.is_archived == False)` — 已归档（用户已克服）的模式也被返回
3. Flutter 端 `pattern_list_screen.dart` 直接展示全部结果，无客户端分页

**对比**: `get_fragments` (line 91-108) 有 `limit` 和 `skip` 参数，`list_capsules` 也有分页。唯独 `get_patterns` 遗漏。

## 修复建议

1. 添加 `limit: int = Query(20, ge=1, le=100)` 和 `offset: int = Query(0, ge=0)` 参数
2. 添加 `.where(BehaviorPattern.is_archived == False)` 默认过滤
3. 可选添加 `include_archived: bool = Query(False)` 参数供高级查询
