## 标题

`list_libraries` search LIKE 通配符未转义，`%` 和 `_` 可匹配不相关库

## 证据

**文件**: `backend/app/services/seed_library_service.py:568-575`

```python
search_term = f"%{params.search}%"
conditions.append(
    or_(
        SeedLibrary.name.ilike(search_term),
        SeedLibrary.description.ilike(search_term),
    )
)
```

`params.search` 直接拼入 LIKE 模式，未对 `%`、`_`、`\` 做转义。

**复现**: 搜索 `%` 可匹配所有库（等效 `%%` 即无条件）；搜索 `_` 可匹配任意单字符；搜索 `\` 在某些 DB 配置下可导致语法错误。

**同类 ISSUE**: ISSUE-041 (community), ISSUE-048 (error_book) — 同一系统性问题在不同模块。

## 修复建议

1. 添加 `_escape_like(term: str) -> str` 转义 `%`、`_`、`\` → `\%`、`\_`、`\\\\`
2. 使用 `escape_char='\\'` 参数传递给 `.ilike()`
3. 或统一使用全文搜索替代 LIKE
