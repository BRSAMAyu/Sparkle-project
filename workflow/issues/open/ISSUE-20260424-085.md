## 标题

`findMySubscriptionForLibrary` 客户端分页扫描查找单个订阅，O(N/P) 次 API 调用

## 证据

**文件**: `mobile/lib/features/seed_library/data/repositories/seed_library_repository.dart:469-490`

```dart
Future<UserLibrarySubscription?> findMySubscriptionForLibrary(
    String libraryId,
) async {
  var page = 1;
  const pageSize = 100;

  while (true) {
    final response = await getMySubscriptions(
      page: page,
      pageSize: pageSize,
    );
    for (final subscription in response.items) {
      if (subscription.libraryId == libraryId) {
        return subscription;
      }
    }
    if (page >= response.totalPages) {
      return null;
    }
    page += 1;
  }
}
```

**问题**:
1. 查找单个订阅需要遍历全部页面，每页一次 HTTP 请求
2. 订阅数 N，每页 P=100，则最坏 N/100 次 API 调用
3. 在 `subscribeToLibrary` (line 345-349) 和 `updateSubscription` (line 384-389) 中作为 response.data==null 时的 fallback 调用

**后端 API**: `GET /seed-libraries/subscriptions/me` 不支持 `library_id` 过滤参数，无法直接查询单个库的订阅状态。

## 修复建议

1. 后端 `get_my_subscriptions` 添加 `library_id: UUID | None` 查询参数
2. Flutter 端 `findMySubscriptionForLibrary` 使用新参数直接查询
3. 或添加专用 `GET /seed-libraries/{library_id}/subscription` 端点
