## 标题

`rate_library` 并发提交触发 IntegrityError 未处理，用户收到 400 而非成功

## 证据

**文件**: `backend/app/services/seed_library_service.py:268-287`

```python
existing = await db.execute(
    select(SeedLibraryRating).where(...)
)
rating = existing.scalar_one_or_none()
if rating is None:
    rating = SeedLibraryRating(...)
    db.add(rating)
else:
    rating.score = score
    ...
await db.flush()
```

**模型层有保护**: `seed_content.py:327-329` — `UniqueConstraint("user_id", "library_id")` 防止重复数据。

**竞态场景**: 用户快速双击提交评分 → 两个请求同时 SELECT 返回 None → 两个都 INSERT → 第二个触发 `IntegrityError`。API 层 `seed_libraries.py:588-589` 的 except 捕获后 rollback 并返回 HTTP 400 "Library not found" — 这是误导性错误消息。

**预期**: 两次提交都应成功（幂等 upsert），而非第二次返回 400。

## 修复建议

1. 使用 `INSERT ... ON CONFLICT (user_id, library_id) DO UPDATE SET score=EXCLUDED.score, comment=EXCLUDED.comment`
2. 或在 SELECT 阶段使用 `with_for_update()` 行锁
3. 或在 API 层捕获 IntegrityError 并 retry/re-fetch
