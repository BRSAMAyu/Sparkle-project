## Title

adopt_prediction bare `except Exception: pass` silently swallows cognitive fragment creation errors

## Evidence

`backend/app/services/theater/prediction_theater_service.py:1407-1408`:

```python
        except Exception:
            pass
```

Inside `adopt_prediction()` (lines 1296-1460), after creating a Plan + Tasks from the selected theater route, the code attempts to create a cognitive fragment. This bare `except ... pass` silently swallows all errors including DB constraint violations, connection failures, and data integrity issues.

No logging, no metrics counter, no retry. The user gets no indication that the fragment was not created.

## Impact

Cognitive fragments linking the adopted prediction to the user's cognitive profile are silently dropped. Over time, the cognitive-to-execution feedback loop accumulates invisible gaps.

## Fix Direction

Add `logger.warning(...)` inside the except block. Consider adding a Prometheus counter for dropped fragment creations.
